## 1. 目的

現役高専生を含む一般公開向けに、「高専の数学1」の章・問題番号に準拠した**独自解説**サイトを提供する。手元の解答PDFは執筆時の参照用とし、サイトやリポジトリには掲載しない。

## 2. プロダクト定義

| 項目 | 内容 |
|------|------|
| サイト名 | 高専の数学解説 |
| 技術スラッグ | `kosen-math` |
| 本番URL | `https://kosen-math.r31bn1z.com` |
| 初期フォールバック | Cloudflare Pages の `*.pages.dev`（カスタムドメイン接続前） |
| 準拠教科書 | 高専の数学1（サイト上で明示） |
| 対象学年（MVP） | 1年生のみ |
| コンテンツ方針 | 自分の言葉で書き下ろす。PDF文言・図のコピー禁止 |

## 3. 非目標（MVP外）

- 2・3年生の解説本文
- ヒントの段階表示、関連問題レコメンド
- 全文検索、コメント、ログイン、CMS
- 解答PDFのホスティング・再配布
- 暗色テーマ・印刷最適化（必要なら後続）

## 4. アーキテクチャ

### 4.1 スタック

- **Astro**（静的サイト生成）
- **MDX**（問題解説の本文）
- **KaTeX**（数式）
- **Cloudflare Pages**（ホスティング・Git 連携デプロイ）
- DNS: ゾーン `r31bn1z.com` に CNAME（または Pages カスタムドメイン）で `kosen-math` サブドメインを紐付け

### 4.2 コンテンツとビルド

```
content/math1/
  ch01/
    meta.md           # 章メタ（タイトル、order）
    s02/
      meta.md         # 節メタ
      q03.mdx         # 問題解説（draft 可）
```

- `draft: true` の MDX は本番ビルドから除外する
- 未執筆の問題は一覧に出さない
- 解答PDFはリポジトリに含めない（`.gitignore` で明示）。ローカル参照のみ

### 4.3 URL 設計

| パス | 役割 |
|------|------|
| `/` | トップ（サイト名・導線・短い説明） |
| `/1/` | 1年生 章一覧 |
| `/1/ch01/` | 第1章 節一覧 |
| `/1/ch01/s02/` | §2 問題一覧 |
| `/1/ch01/s02/q03/` | 問題ページ（解説本文） |
| `/about/` | 準拠・免責・使い方 |

パンくず: `1年 > 第1章 > §2 > 問3`  
問題ページ下部: 同一節内の前の問 / 次の問

## 5. 問題ページ（MVP）

載せるもの:

1. 見出し（例: 第1章 §2 問3）
2. 「高専の数学1」準拠の短い注記
3. 解説本文（方針 → 途中式 → 答え）
4. 前へ / 次へ

数式は `$...$` / `$$...$$`（KaTeX）。共通 UI コンポーネントは最小限（必要なら最終答用の軽いマークアップ程度）。

## 6. 著作権・免責

- 各問題ページおよび `/about` に、教科書問題番号に準拠した**独自解説**であること、公式解答・PDFの再配布ではないことを明記する
- 学習補助であり、試験対策の完全代替ではない旨を `/about` に置く
- 市販解答PDFをソースとして公開しない運用を前提とする

## 7. デプロイ

1. Git リポジトリを Cloudflare Pages プロジェクト `kosen-math` に接続
2. `main` への push で本番ビルド
3. PR ごとに Preview デプロイ
4. カスタムドメイン `kosen-math.r31bn1z.com` を Pages に設定（ゾーンはアカウント内で確認済み）

実装フェーズで Cloudflare API / MCP を用い、ドメイン紐付けとビルド設定を行う。

## 8. 品質・エラー

- ビルド時: frontmatter 必須項目の検証（欠落で fail）
- 隣接リンク（前後問）は生成時に解決し、壊れた内部リンクを避ける
- 存在しない URL は 404（1年トップへの導線）
- 自動テストは最小（コンテンツ収集・draft 除外など）。E2E は後回し
- 代表ページで KaTeX の目視確認

## 9. UI 方針（概要）

- サイト名「高専の数学解説」を第一画面でヒーロー級に示す
- 読みやすさ優先（本文幅・数式まわりの余白）
- ライト基調。カード多用やダッシュボード感は避ける
- 詳細なビジュアルデザインは実装計画・実装時に詰める

## 10. 成功基準（MVP）

- `https://kosen-math.r31bn1z.com` でトップ・about・1年の階層ナビが公開されている
- 少なくとも1章のうち数問の独自解説が問題単位 URL で読める
- 数式が正しくレンダリングされる
- PDF・解答本文のコピーがリポジトリに含まれていない
- 準拠・免責がユーザーから確認できる

## 11. 後続候補（明示的に後回し）

- 独自ドメイン以外の運用改善（キャッシュ、分析など）
