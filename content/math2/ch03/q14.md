### (1)
$$y = \frac{1}{3}x^3 + x^2 - 2$$

$$y' = x^2 + 2x$$

傾きが $3$ なので$y' = 3$となる

$$3 = x^2 + 2x \qquad x^2 + 2x - 3 = 0 \qquad (x+3)(x-1) = 0 \qquad x = 1, -3$$

$x = 1$ のとき $y = \dfrac{1}{3} + 1 - 2 = -\dfrac{2}{3}$   $\left(1, -\dfrac{2}{3}\right)$

$x = -3$ のとき $y = -9 + 9 - 2 = -2$   $(-3, -2)$

### (2)
x 軸と平衡なので傾きは $0$ である

(1)から$y' = 0$ となればよいので

$$0 = x^2 + 2x \qquad 0 = x(x+2) \qquad x = 0, -2$$

$x = 0$ のとき $y = 0 + 0 - 2 = -2$   $(0, -2)$

$x = -2$ のとき $y = -\dfrac{8}{3} + 4 - 2 = -\dfrac{2}{3}$   $\left(-2, -\dfrac{2}{3}\right)$

### (3)
接線の傾きが正なので

(1)から$y' > 0$となればよいので

$$0 < x^2 + 2x \qquad 0 < x(x+2) \qquad x < -2 \quad 0 < x$$
