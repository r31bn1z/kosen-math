### (1)
$$\lim_{x \to 3} \frac{ax^2 + bx}{x - 3} = 1$$

$x \to 3$ のとき分母が $0$ となるので、式を成り立たせるためには

少なくとも $x \to 3$ において分子も $0$ となる必要がある

これから

$$ax^2 + bx = 9a + 3b = 0 \qquad b = -3a \qquad \text{これを与式に代入して}$$

$$\lim_{x \to 3} \frac{ax^2 - 3ax}{x - 3} = \lim_{x \to 3} \frac{ax(x - 3)}{x - 3} = \lim_{x \to 3} ax = 3a = 1 \qquad a = \frac{1}{3} \qquad b = -1$$

### (2)
$$\lim_{x \to -1} \frac{x^2 + ax - 3}{x + 1} = b$$

(1)と同様に考えて

$$x^2 + ax - 3 = 1 - a - 3 = 0 \qquad a = -2 \qquad \text{これを与式に代入して}$$

$$\lim_{x \to -1} \frac{x^2 - 2x - 3}{x + 1} = \lim_{x \to -1} \frac{(x - 3)(x + 1)}{x + 1} = \lim_{x \to -1} (x - 3) = -4 = b \qquad a = -2 \qquad b = -4$$

### (3)
$$\lim_{x \to 2} \frac{x^2 + ax + b}{x - 2} = 5$$

(1)と同様に考えて

$$x^2 + ax + b = 4 + 2a + b = 0 \qquad b = -2a - 4 \qquad \text{これを与式に代入して}$$

$$\lim_{x \to 2} \frac{x^2 + ax - 2a - 4}{x - 2} = \lim_{x \to 2} \frac{(x - 2)(x + a + 2)}{x - 2} = \lim_{x \to 2} (x + a + 2) = a + 4 = 5 \qquad a = 1 \qquad b = -6$$

### (4)
$$\lim_{x \to 2} \frac{x^2 + ax + b}{x^2 - 4} = 2$$

(1)と同様に考えて

$$x^2 + ax + b = 4 + 2a + b = 0 \qquad b = -2a - 4 \qquad \text{これを与式に代入して}$$

$$\lim_{x \to 2} \frac{x^2 + ax - 2a - 4}{x^2 - 4} = \lim_{x \to 2} \frac{(x - 2)(x + a + 2)}{(x - 2)(x + 2)} = \lim_{x \to 2} \frac{x + a + 2}{x + 2} = \frac{a + 4}{4} = 2 \qquad a = 4 \qquad b = -12$$
