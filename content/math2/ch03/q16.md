$y = x^3$

$y' = 3x^2$

$x = a$のとき $y' = 3a^2$ よって $x=a$ において接線の傾きは$3a^2$となる これから接線の方程式は

$$y = 3a^2x + b$$

点 $P(a, a^3)$を通るので $a^3 = 3a^3 + b$ $b = -2a^3$ これから

$$y = 3a^2x - 2a^3$$

$y$ 軸との交点は $x = 0$ から $y = -2a^3$

$x$ 軸との交点は $y = 0$ から $x = \dfrac{2}{3}a$ これから $Q\left(\dfrac{2}{3}a, 0\right)$ $R(0, -2a^3)$ となる

$$PQ = \sqrt{\left(a - \frac{2}{3}a\right)^2 + (a^3 - 0)^2} = \sqrt{\frac{1}{9}a^2 + a^6} = \frac{\sqrt{1 - 9a^4}}{3}a = \frac{a}{3}\sqrt{1 - 9a^4}$$

$$QR = \sqrt{\left(0 - \frac{2}{3}a\right)^2 + (-2a^3 - 0)^2} = \sqrt{\frac{4}{9}a^2 + 4a^6} = \frac{2a}{3}\sqrt{1 - 9a^4}$$

これから

$$PQ:QR = \frac{a}{3}\sqrt{1 - 9a^4} : \frac{2a}{3}\sqrt{1 - 9a^4} = 1:2$$
