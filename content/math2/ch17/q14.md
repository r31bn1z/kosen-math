### (1)

$A$の固有多項式は

$$|A - \lambda E| = 0$$

となる

$B$の固有多項式は$B = P^{-1}AP$の式より

$$|B - \lambda E| = |P^{-1}AP - \lambda E| = |P^{-1}AP - P^{-1}\lambda EP| = |P^{-1}(AP - \lambda EP)| = |P^{-1}(A - \lambda E)P| = |P^{-1}||A - \lambda E||P|$$

（上式の解説）$P^{-1}\lambda EP = \lambda E$ 行列の分配則 行列の分配則 行列式の性質(p95)

$$= |P^{-1}||P||A - \lambda E| = |P^{-1}P||A - \lambda E| = |E||A - \lambda E| = |A - \lambda E|$$

行列式は数値より入替可能 行列式の性質(p95) 逆行列の関係

これより固有多項式が同一となる事から同じ固有値を持つ

### (2)

$B = P^{-1}AP$ 両辺に$P^{-1}AP$を右から掛けると

$BP^{-1}AP = P^{-1}APP^{-1}AP$ $BB = P^{-1}AEAP$ $B^2 = P^{-1}A^2P$ よって成り立つ

$B^k = P^{-1}A^kP$が成り立つと仮定して 両辺に$P^{-1}AP$を右から掛けると

$B^kP^{-1}AP = P^{-1}A^kPP^{-1}AP$ $B^{k}B = P^{-1}A^kEAP$ $B^{k+1} = P^{-1}A^{k+1}P$

$k+1$のときにも成り立つので $B^n = P^{-1}A^nP$ は成り立つ
