1次結合の等式は

$$\vec{0} = x_1\vec{a_1} + x_2(\vec{a_1} + \vec{a_2}) + x_3(\vec{a_1} + \vec{a_2} + \vec{a_3}) + \cdots + x_n(\vec{a_1} + \vec{a_2} + \cdots + \vec{a_n})$$

$$= (x_1 + x_2 + \cdots + x_n)\vec{a_1} + (x_2 + \cdots + x_n)\vec{a_2} + \cdots + x_n\vec{a_n}$$

$\vec{a_1}, \vec{a_2}, \vec{a_3}, \ldots, \vec{a_n}$ は1次独立であるので

$$x_1 + x_2 + \cdots + x_n = 0$$
$$x_2 + x_3 + \cdots + x_n = 0$$
$$\vdots$$
$$x_n = 0$$

これから $x_1 = x_2 = x_3 = \cdots = x_n = 0$

よって $\vec{a_1}, (\vec{a_1} + \vec{a_2}), (\vec{a_1} + \vec{a_2} + \vec{a_3}), \cdots, (\vec{a_1} + \vec{a_2} + \cdots + \vec{a_n})$ は1次独立である
