1次結合の等式は

$$\bar{0} = x(\bar{a} + \bar{b}) + y(\bar{b} + \bar{c}) + z(\bar{c} + \bar{a})$$

$$= (x + z)\bar{a} + (x + y)\bar{b} + (y + z)\bar{c}$$

$\bar{a}, \bar{b}, \bar{c}$ は1次独立なので $x + z = x + y = y + z = 0$  $\therefore x = y = z = 0$

よって $(\bar{a} + \bar{b}), (\bar{b} + \bar{c}), (\bar{c} + \bar{a})$ は1次独立となる
