$\alpha(x, y)$ $\beta(x', y')$ とする

$$y = \sqrt{3}x \qquad \sqrt{3}x - y = 0 \qquad \text{方向ベクトルは} (1, \sqrt{3}) \text{となる}$$

これから

$$\alpha\beta \perp (1, \sqrt{3}) \text{より} \quad (x' - x, y' - y) \cdot (1, \sqrt{3}) = 0 \qquad x' - x + \sqrt{3}y' - \sqrt{3}y = 0$$

また、$\alpha$ と $\beta$ の中点 $\gamma\left(\dfrac{x'+x}{2}, \dfrac{y'+y}{2}\right)$ は $y = \sqrt{3}x$ の直線上にある事から

$$\frac{y'+y}{2} = \sqrt{3}\,\frac{(x'+x)}{2} \qquad y' + y = \sqrt{3}x' + \sqrt{3}x$$

これより

$$x' = \frac{1 - \sqrt{3}^2}{1 + \sqrt{3}^2}x + \frac{2\sqrt{3}}{1 + \sqrt{3}^2}y = -\frac{1}{2}x + \frac{\sqrt{3}}{2}y$$

$$y' = \frac{2\sqrt{3}}{1 + \sqrt{3}^2}x - \frac{1 - \sqrt{3}^2}{1 + \sqrt{3}^2}y = \frac{\sqrt{3}}{2}x + \frac{1}{2}y$$

よって一次変換の行列 $A$ は

$$A = \begin{pmatrix} -\dfrac{1}{2} & \dfrac{\sqrt{3}}{2} \\ \dfrac{\sqrt{3}}{2} & \dfrac{1}{2} \end{pmatrix}$$
