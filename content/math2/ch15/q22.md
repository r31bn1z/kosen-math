$$p = \binom{p_1}{p_2} \qquad q = \binom{q_1}{q_2}$$

ベクトル $p,q$ が作る平行四辺形の面積 $S$ は

$$S^2 = |p|^2|q|^2 - (p \cdot q)^2 = (p_1^2+p_2^2)(q_1^2+q_2^2) - (p_1q_1+p_2q_2)^2$$

$$= p_1^2q_1^2 + p_1^2q_2^2 + p_2^2q_1^2 + p_2^2q_2^2 - p_1^2q_1^2 - 2p_1q_1p_2q_2 - p_2^2q_2^2$$

$$= p_1^2q_2^2 + p_2^2q_1^2 - 2p_1q_1p_2q_2 = (p_1q_2 - p_2q_1)^2$$

$$S = |p_1q_2 - p_2q_1|$$

$$Ap = \binom{ap_1 + bp_2}{cp_1 + dp_2} \qquad Aq = \binom{aq_1 + bq_2}{cq_1 + dq_2}$$

同様に面積 $S$ を考えると

$$S = |(ap_1+bp_2)(cq_1+dq_2) - (cp_1+dp_2)(aq_1+bq_2)| = |(ad-bc)p_1q_2 - (ad-bc)p_2q_1|$$

これから $(ad-bc) = \pm 1$ であればよいので

$$|A| = \pm 1 \text{ となる}$$
