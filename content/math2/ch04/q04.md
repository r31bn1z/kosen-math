### (1)
$y = x^2 - 2x + 5$  $y' = 2x - 2$  $y' = 0$のとき  $2x - 2 = 0$  $x = 1$

| x | $-3$ | ・・・ | 1 | ・・・ | 4 |
|---|---|---|---|---|---|
| y' | | + | 0 | − | |
| y | 20 | | 4 | | 13 |

これから$x = -3$のとき最大値$20$  $x = 1$のとき最小値$4$

### (2)
$y = x^3 - 6x$  $y' = 3x^2 - 6$  $y' = 0$のとき  $3x^2 - 6 = 0$  $x = \pm\sqrt{2}$  $(-\sqrt{2}$は範囲外$)$

| x | $-1$ | ・・・ | $\sqrt{2}$ | ・・・ | 3 |
|---|---|---|---|---|---|
| y' | | − | 0 | + | |
| y | 5 | | $-4\sqrt{2}$ | | 9 |

これから$x = 3$のとき最大値$9$  $x = \sqrt{2}$のとき最小値$-4\sqrt{2}$

### (3)
$y = x^3 - 3x$  $y' = 3x^2 - 3$  $y' = 0$のとき  $3x^2 - 3 = 0$  $x = \pm 1$  $(-1$は範囲外$)$

| x | 0 | ・・・ | 1 | ・・・ | 3 |
|---|---|---|---|---|---|
| y' | | − | 0 | + | |
| y | 0 | | $-2$ | | 18 |

これから$x = 3$のとき最大値$18$  $x = 1$のとき最小値$-2$

### (4)
$y = x^4 - 2x^2 + 1$  $y' = 4x^3 - 4x$  $y' = 0$のとき  $4x^3 - 4x = 4x(x^2 - 1) = 0$  $x = 0, \pm 1$

| x | $-1$ | ・・・ | 0 | ・・・ | 1 | ・・・ | 2 |
|---|---|---|---|---|---|---|---|
| y' | 0 | + | 0 | − | 0 | + | |
| y | 0 | | 1 | | 0 | | 9 |

これから$x = 2$のとき最大値$9$  $x = \pm 1$のとき最小値$0$

### (5)
$y = x^3 - 3x^2 - 24x + 40$  $y' = 3x^2 - 6x - 24$  $y' = 0$のとき  $3x^2 - 6x - 24 = 3(x - 4)(x + 2) = 0$

$x = -2, 4$  $(-2$は範囲外$)$

| x | 0 | ・・・ | 4 | ・・・ | 5 |
|---|---|---|---|---|---|
| y' | | − | 0 | + | |
| y | 40 | | $-40$ | | $-30$ |

これから$x = 0$のとき最大値$40$  $x = 4$のとき最小値$-40$
