$$y = x^3 - 3x^2 + 2$$

$$y' = 3x^2 - 6x$$

$y' = 0$のとき

$$3x^2 - 6x = 3x(x - 2) = 0 \qquad \therefore x = 0, 2$$

$x = 0$のとき $y = 2$ 極大

$x = 2$のとき $y = -2$ 極小

| x | ・・・ | 0 | ・・・ | 2 | ・・・ |
|---|---|---|---|---|---|
| y' | + | 0 | − | 0 | + |
| y |  | 2 |  | −2 |  |

これから右図のようなグラフが描ける。

$y = -2$となるのは  $-2 = x^3 - 3x^2 + 2$  $0 = x^3 - 3x^2 + 4$  $0 = (x + 1)(x - 2)^2$  $\therefore x = -1, 2$

$y = 2$となるのは    $2 = x^3 - 3x^2 + 2$  $0 = x^3 - 3x^2 = x^2(x - 3)$  $\therefore x = 0, 3$

よって

$0 < a < 2$のとき

最大値は$x = 0$の時で $y = 2$  最小値は$x = a$のときで $y = a^3 - 3a^2 + 2$

$2 \leq a \leq 3$のとき

最大値は$x = 0, 3$の時で $y = 2$  最小値は$x = 2$のときで $y = -2$

$3 < a$のとき

最大値は$x = a$の時で $y = a^3 - 3a^2 + 2$  最小値は$x = 2$のときで $y = -2$
