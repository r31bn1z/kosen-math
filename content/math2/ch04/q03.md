$$f = x^3 + ax^2 + bx + c \qquad ①$$

$$f' = 3x^2 + 2ax + b$$

$f' = 0$ のとき

$$3x^2 + 2ax + b = 0 \qquad x^2 + \frac{2}{3}ax + \frac{1}{3}b = 0$$

$x = -1, 2$ で極値をとるので $f' = 0$ のとき

$$f' = (x+1)(x-2) = 0$$

となる

これから

$$x^2 + \frac{2}{3}ax + \frac{1}{3}b = (x+1)(x-2) = x^2 - x - 2$$

$$\frac{2}{3}a = -1 \qquad a = -\frac{3}{2} \qquad \frac{1}{3}b = -2 \qquad b = -6$$

これを $x = -1$ のとき $f = 5$ となる①に代入して

$$5 = (-1)^3 + \left(-\frac{3}{2}\right)\cdot(-1)^2 + (-6)\cdot(-1) + c \qquad 5 = -1 - \frac{3}{2} + 6 + c \qquad c = \frac{3}{2}$$

よって $a = -\dfrac{3}{2} \qquad b = -6 \qquad c = \dfrac{3}{2}$

最小値は $x = 2$ のとき

$$f = 2^3 - \frac{3}{2}\cdot 2^2 - 6\cdot 2 + \frac{3}{2} = 8 - 6 - 12 + \frac{3}{2} = -\frac{17}{2}$$
