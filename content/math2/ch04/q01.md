この問の図は変換原稿に含まれていません。

### (1)

$y = x^3 - 6x^2 + 9x$  $y' = 3x^2 - 12x + 9$

$y'=0$のとき $3x^2-12x+9=3(x-3)(x-1)=0$ $x=1,3$

| $x$ | ... | 1 | ... | 3 | ... |
|---|---|---|---|---|---|
| $y'$ | + | 0 | − | 0 | + |
| $y$ |  | 4 |  | 0 |  |

$x$軸との交点は $x^3-6x^2+9x=x(x^2-6x+9)=x(x-3)^2=0$ よって$x=0,3$

### (2)

$y=-x^3+3x$  $y'=-3x^2+3$  $y'=0$のとき $-3x^2+3=0$ $x=\pm1$

| $x$ | ... | −1 | ... | 1 | ... |
|---|---|---|---|---|---|
| $y'$ | − | 0 | + | 0 | − |
| $y$ |  | −2 |  | 2 |  |

$x$軸との交点は $-x^3+3x=-x(x^2-3)=0$ よって$x=0,\pm\sqrt{3}$

### (3)

$y=x^3-3x^2-9x+11$  $y'=3x^2-6x-9$

$y'=0$のとき $3x^2-6x-9=3(x-3)(x+1)=0$ $x=-1,3$

| $x$ | ... | −1 | ... | 3 | ... |
|---|---|---|---|---|---|
| $y'$ | + | 0 | − | 0 | + |
| $y$ |  | 16 |  | −16 |  |

$x$軸との交点は $x^3-3x^2-9x+11=(x-1)(x^2-2x-11)=0$ よって$x=1,1\pm2\sqrt{3}$

### (4)

$y=x^4-2x^3+1$  $y'=4x^3-6x^2$  $y'=0$のとき $4x^3-6x^2=2x^2(2x-3)=0$ $x=0,\dfrac{3}{2}$

| $x$ | ... | 0 | ... | $\dfrac{3}{2}$ | ... |
|---|---|---|---|---|---|
| $y'$ | − | 0 | − | 0 | + |
| $y$ |  | 1 |  | $-\dfrac{11}{16}$ |  |

$x$軸との交点は $x^4-2x^3+1=(x-1)(x^3-x^2-x-1)=0$ よって$x=1,(x^3-x^2-x-1)=0$

### (5)

$$y = -x^4+x^2 \qquad y' = -4x^3+2x \qquad y'=0 \text{ のとき } \quad -4x^3+2x=2x(1-2x^2)=0 \qquad x=0,\pm\dfrac{1}{\sqrt{2}}$$

| x | ・・・ | $-\dfrac{1}{\sqrt{2}}$ | ・・・ | $0$ | ・・・ | $\dfrac{1}{\sqrt{2}}$ | ・・・ |
|---|---|---|---|---|---|---|---|
| y' | ＋ | 0 | － | 0 | ＋ | 0 | － |
| y |  | $\dfrac{1}{4}$ |  | 0 |  | $\dfrac{1}{4}$ |  |

x 軸との交点は $-x^4+x^2=-x^2(x^2-1)=0$ よって $x=0,\pm1$

### (6)

$$y = x^4-10x^2+9 \qquad y' = 4x^3-20x \qquad y'=0 \text{のとき} \quad 4x^3-20x=4x(x^2-5)=0 \qquad x=0,\pm\sqrt{5}$$

| x | ・・・ | $-\sqrt{5}$ | ・・・ | $0$ | ・・・ | $\sqrt{5}$ | ・・・ |
|---|---|---|---|---|---|---|---|
| y' | － | 0 | ＋ | 0 | － | 0 | ＋ |
| y |  | $-16$ |  | $9$ |  | $16$ |  |

x 軸との交点は $x^4-10x^2+9=(x^2-9)(x^2-1)=0$ よって $x=\pm1,\pm3$
