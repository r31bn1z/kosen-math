$y = ax^3 - 6ax^2 + b$

$y' = 3ax^2 - 12ax$

$y' = 0$のとき

$$3ax(x - 4) = 0 \qquad x = 0, 4$$

$x = 0$ のとき $y = b$

$x = 4$ のとき $y = 64a - 96a + b$

$-1 \leq x \leq 2$ から $x = 0$ がそれぞれ極大値又は極小値となる

$x = 0$ で最大値 $10$ のとき $y = b = 10$

このとき$x = 2$ で最小値 $-6$ をとり $-6 = a \cdot 8 - 6a \cdot 4 + 10$ $-6 = 8a - 24a + 10$ $a = 1$

$x = 0$ で最小値 $-6$ のとき $y = b = -6$

このとき$x = 2$ で最大値 $10$ をとり $10 = 8a - 24a - 6$ $a = -1$

よって $b = 10$、$a = 1$ 又は $b = -6$、$a = -1$

$a = 1, b = 10$

$a = -1$、$b = -6$
