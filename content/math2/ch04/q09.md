### (1)
$y = -x^3 + 3x^2 - 1$    $y' = -3x^2 + 6x$

$y' = 0$ のとき   $-3x^2 + 6x = -3x(x-2) = 0$    $x = 0, 2$

これから

| x | ・・・ | 0 | ・・・ | 2 | ・・・ |
|---|---|---|---|---|---|
| y' | − | 0 | + | 0 | − |
| y | | −1 | | 3 | |

### (2)
$y = 2x^3 - 9x^2 + 12x - 1$    $y' = 6x^2 - 18x + 12$

$y' = 0$ のとき    $6x^2 - 18x + 12 = 6(x^2 - 3x + 2) = 6(x-2)(x-1) = 0$    $x = 2, 1$

これから

| x | ・・・ | 1 | ・・・ | 2 | ・・・ |
|---|---|---|---|---|---|
| y' | + | 0 | − | 0 | + |
| y | | 4 | | 3 | |

### (3)
$y = -x^3 - x$    $y' = -3x^2 - 1$

$y' = 0$ のとき $-3x^2 - 1 = 0$    $x^2 = -\dfrac{1}{3}$    $x = \sqrt{\dfrac{1}{3}}\,i$

これからこの関数は極値をとらない

| x | $-\infty$ | ・・・ | $\infty$ |
|---|---|---|---|
| y | $\infty$ | | $-\infty$ |

### (4)
$y = x^3 - 3x^2 - 6x + 5$    $y' = 3x^2 - 6x - 6$

$y' = 0$ のとき    $3x^2 - 6x - 6 = 3(x^2 - 2x - 2) = 0$    $x = 1 \pm \sqrt{1+2} = 1 \pm \sqrt{3}$

これから

| x | ・・・ | $1-\sqrt{3}$ | ・・・ | $1+\sqrt{3}$ | ・・・ |
|---|---|---|---|---|---|
| y' | + | 0 | − | 0 | + |
| y | | $-3+6\sqrt{3}$ | | $-3-6\sqrt{3}$ | |

### (5)
$y = x^4 - 5x^2 + 4$    $y' = 4x^3 - 10x$

$y' = 0$ のとき  $4x^3 - 10x = 2x(2x^2 - 5) = 0$   $x = 0, \pm\dfrac{\sqrt{5}}{\sqrt{2}}$

これから

| x  | ・・・ | $-\dfrac{\sqrt{5}}{\sqrt{2}}$ | ・・・ | 0   | ・・・ | $\dfrac{\sqrt{5}}{\sqrt{2}}$ | ・・・ |
|----|--------|-------------------------------|--------|-----|--------|-------------------------------|--------|
| y' | −      | 0                             | +      | 0   | −      | 0                              | +      |
| y  |        | $-\dfrac{9}{4}$               |        | 4   |        | $-\dfrac{9}{4}$                |        |

### (6)
$y = |x^3 - 1|$

y は負の値を取らないので

まず $y = x^3 - 1$ において $y < 0$ となる範囲を考える。

$x^3 - 1 < 0$   $x^3 < 1$   $x < 1$  これから

$x < 1$ のとき $y = -x^3 + 1$   $x > 1$ のとき $y = x^3 - 1$  と考えて計算する

$x < 1$ のとき $y' = -3x^2$   $y' = 0$ のとき $x = 0$

$x > 1$ のとき $y' = 3x^2$   $y' = 0$ のとき $x = 0$  これは $x > 1$ ではないので極値なし

これから

| x  | $-\infty$ | ・・・ | 0   | ・・・ | 1   | ・・・ | $\infty$ |
|----|-----------|--------|-----|--------|-----|--------|----------|
| y' | −         | −      | 0   | −      | ／  | +      | +        |
| y  | $\infty$  |        | 1   |        | 0   |        | $\infty$ |
