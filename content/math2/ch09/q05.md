### (1)

$$\int_0^{\frac{\pi}{2}} x\sin x\,dx = \Big[x(-\cos x)\Big]_0^{\frac{\pi}{2}} + \int_0^{\frac{\pi}{2}} \cos x\,dx = 0 + \Big[\sin x\Big]_0^{\frac{\pi}{2}} = 1$$

### (2)

$$\int_1^2 (x+1)e^x\,dx = \Big[(x+1)e^x\Big]_1^2 - \int_1^2 e^x\,dx = 3e^2 - 2e - \Big[e^x\Big]_1^2 = 3e^2 - 2e - e^2 + e = 2e^2 - e$$

### (3)

$$\int_0^{\pi} e^{-x}\sin x\,dx = \Big[-e^{-x}\sin x\Big]_0^{\pi} + \int_0^{\pi} e^{-x}\cos x\,dx = 0 + \Big[-e^{-x}\cos x\Big]_0^{\pi} - \int_0^{\pi} e^{-x}\sin x\,dx$$

$$2\int_0^{\pi} e^{-x}\sin x\,dx = e^{-\pi} + 1 \qquad \int_0^{\pi} e^{-x}\sin x\,dx = \frac{1}{2}(e^{-\pi}+1)$$

### (4)

$$\int_0^{\frac{\pi}{2}} x^2\sin x\,dx = \Big[x^2(-\cos x)\Big]_0^{\frac{\pi}{2}} + \int_0^{\frac{\pi}{2}} 2x\cdot\cos x\,dx = 0 + \Big[2x\cdot\sin x\Big]_0^{\frac{\pi}{2}} - 2\int_0^{\frac{\pi}{2}} \sin x\,dx$$

$$= \pi - 2\Big[-\cos x\Big]_0^{\frac{\pi}{2}} = \pi - 2$$

### (5)

$$\int_0^{\frac{\pi}{2}} e^{-x}\cos x\,dx = \Big[-e^{-x}\cos x\Big]_0^{\frac{\pi}{2}} + \int_0^{\frac{\pi}{2}} e^{-x}(-\sin x)\,dx = 1 - \Big[-e^{-x}\sin x\Big]_0^{\frac{\pi}{2}} - \int_0^{\frac{\pi}{2}} e^{-x}\sin x\,dx$$

$$2\int_0^{\frac{\pi}{2}} e^{-x}(-\sin x)\,dx = 1 + e^{-\frac{\pi}{2}} \qquad \int_0^{\frac{\pi}{2}} e^{-x}(-\sin x)\,dx = \frac{1}{2}\left(1+e^{-\frac{\pi}{2}}\right)$$
