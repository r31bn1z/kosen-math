点 P が線分 AB を m:n に内分する点であるとすると

$$\vec{p} = \frac{m\vec{b} + n\vec{a}}{m+n} = \frac{n}{m+n}\vec{a} + \frac{m}{m+n}\vec{b} = \left(1 - \frac{m}{m+n}\right)\vec{a} + \frac{m}{m+n}\vec{b}$$

$\dfrac{m}{m+n} = t$ とおくと $\vec{p} = (1-t)\vec{a} + t\vec{b}$

### (1)

$$\vec{p} = (1-0)\vec{a} + 0 = \vec{a} \qquad \therefore \text{点 A}$$

### (2)

$$\vec{p} = \left(1 - \frac{1}{2}\right)\vec{a} + \frac{1}{2}\vec{b} = \frac{1}{2}\vec{a} + \frac{1}{2}\vec{b} \qquad \therefore \text{AB \text{の中点}}$$

### (3)

$$\vec{p} = \left(1 - \frac{2}{3}\right)\vec{a} + \frac{2}{3}\vec{b} = \frac{1}{3}\vec{a} + \frac{2}{3}\vec{b} \qquad \therefore \text{AB \text{を} 2:1 \text{に内分する点}}$$

### (4)

$$\vec{p} = (1-2)\vec{a} + 2\vec{b} = -\vec{a} + 2\vec{b} \qquad \therefore \text{AB \text{を} 2:1 \text{に外分する点}}$$

### (5)

$$\vec{p} = (1+2)\vec{a} - 2\vec{b} = 3\vec{a} - 2\vec{b} \qquad \therefore \text{AB \text{を} 2:3 \text{に外分する点}}$$

より明らかである

### (2)
(1)より

$$\vec{p} = s\vec{a} + t\vec{b} \qquad s\vec{a} + t\vec{b} - \vec{p} = \vec{0}$$

$s = k$ 、 $t = l$ 、 $-1 = m \ (m \neq 0)$ とすれば

$$k\vec{a} + l\vec{b} + m\vec{p} = 0$$

また $s + t = 1$ より $k + l = -m$  $k + l + m = 0$
