$\vec{a}$を$x$軸方向に取ると

$$\vec{b} = 2\left(-\frac{1}{2}+\frac{\sqrt{3}}{2}i\right) = -1+\sqrt{3}i$$

これから

$$|\vec{a}+2\vec{b}| = |3+2(-1+\sqrt{3}i)| = |1+2\sqrt{3}i| = \sqrt{1+12} = \sqrt{13}$$

$|\vec{a}+t\vec{b}| = y$ とおくと

$$y = |\vec{a}+t\vec{b}| = |3+t(-1+\sqrt{3}i)| = \sqrt{(3-t)^2+3t^2} = \sqrt{9-6t+t^2+3t^2} = \sqrt{4t^2-6t+9}$$

$$y' = \frac{8t-6}{2\sqrt{4t^2-6t+9}}$$

$y'=0$ のとき $t=\dfrac{3}{4}$

$t=\dfrac{3}{4}$のとき

$$y = \sqrt{4\left(\frac{3}{4}\right)^2-6\left(\frac{3}{4}\right)+9} = \sqrt{\frac{9-18+36}{4}} = \frac{3\sqrt{3}}{2}$$

これから

$t=\dfrac{3}{4}$ のとき最小値 $\dfrac{3\sqrt{3}}{2}$
