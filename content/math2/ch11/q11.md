$$\overrightarrow{AL} = \overrightarrow{AB} + \frac{m}{m+n}\overrightarrow{BC}$$

$$\overrightarrow{BM} = \overrightarrow{BC} + \frac{m}{m+n}\overrightarrow{CA} = \overrightarrow{BC} + \frac{m}{m+n}\left(-\overrightarrow{BC} - \overrightarrow{AB}\right) = -\frac{m}{m+n}\overrightarrow{AB} + \frac{n}{m+n}\overrightarrow{BC}$$

$$\overrightarrow{CN} = -\overrightarrow{BC} - \frac{n}{m+n}\overrightarrow{AB}$$

$$\therefore \overrightarrow{AL} + \overrightarrow{BM} + \overrightarrow{CN} = \overrightarrow{AB} + \frac{m}{m+n}\overrightarrow{BC} - \frac{m}{m+n}\overrightarrow{AB} + \frac{n}{m+n}\overrightarrow{BC} - \overrightarrow{BC} - \frac{n}{m+n}\overrightarrow{AB} = \vec{0}$$
