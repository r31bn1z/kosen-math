### (1)

$2\overrightarrow{AP}+3\overrightarrow{BP}+4\overrightarrow{CP}=0$ より

$$\overrightarrow{AP} = -\frac{3}{2}\overrightarrow{BP} - 2\overrightarrow{CP} = -\frac{3}{2}(-\overrightarrow{AB}+\overrightarrow{AP}) - 2(-\overrightarrow{AC}+\overrightarrow{AP}) = \frac{3}{2}\overrightarrow{AB} - \frac{7}{2}\overrightarrow{AP} + 2\overrightarrow{AC}$$

$$\frac{9}{2}\overrightarrow{AP} = \frac{3}{2}\overrightarrow{AB} + 2\overrightarrow{AC} \qquad \overrightarrow{AP} = \frac{1}{3}\overrightarrow{AB} + \frac{4}{9}\overrightarrow{AC}$$

### (2)

$$\overrightarrow{AQ} = k\overrightarrow{AP} = k\left(\frac{1}{3}\overrightarrow{AB}+\frac{4}{9}\overrightarrow{AC}\right) = k\frac{3\overrightarrow{AB}+4\overrightarrow{AC}}{9} = \frac{7}{9}k\frac{3\overrightarrow{AB}+4\overrightarrow{AC}}{7}$$

公式 $$\vec{p} = \dfrac{n\vec{b} + m\vec{c}}{m+n}$$

と比較すると点 Q は線分 BC を 4:3 に内分する ∴ $BQ:QC = 4:3$

このとき $\overrightarrow{AQ} = \dfrac{3\overrightarrow{AB}+4\overrightarrow{AC}}{7}$ なので $\dfrac{7}{9}k = 1$ $k = \dfrac{9}{7}$ → $\overrightarrow{AQ} = \dfrac{9}{7}\overrightarrow{AP}$

これより $AP:PQ = 7:2$

### (3)

$BQ:QC = 4:3$ より $\triangle BQA:\triangle CQA = \triangle BQP:\triangle CQP = 4:3$

$\triangle BQA = x$、$\triangle BQP = y$ とおくと

$$\triangle PAB = x - y \qquad \triangle PCA = \frac{3}{4}x - \frac{3}{4}y = \frac{3}{4}(x-y) = \frac{3}{4}\triangle PAB$$

また $AP:PQ = 7:2$ より $\triangle PBC = \dfrac{2}{9}\triangle ABC$ $\triangle ABC:\triangle PBC = 9:2$

$$\triangle ABC - \triangle PBC : \triangle PBC = 7:2$$

 $\triangle PAB + \triangle PCA : \triangle PBC = 7:2$ $\triangle PAB:\triangle PCA:\triangle PBC = 4:3:2$

$\triangle PAB:\triangle PBC:\triangle PCA = 4:2:3$
