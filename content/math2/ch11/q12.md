$$\overrightarrow{\mathrm{BC}} = k\overrightarrow{\mathrm{AD}} = k\vec{a}$$

$$\overrightarrow{\mathrm{AM}} = \frac{1}{2}\vec{b}$$

$$\overrightarrow{\mathrm{AN}} = \vec{a} + \frac{1}{2}\overrightarrow{\mathrm{DN}} = \vec{a} + \frac{1}{2}\left(-\vec{a} + \vec{b} + k\vec{a}\right) = \frac{1+k}{2}\vec{a} + \frac{1}{2}\vec{b}$$

$$\overrightarrow{\mathrm{MN}} = -\frac{1}{2}\overrightarrow{\mathrm{AB}} + \overrightarrow{\mathrm{AN}} = -\frac{1}{2}\vec{b} + \frac{1+k}{2}\vec{a} + \frac{1}{2}\vec{b} = \frac{1+k}{2}\vec{a}$$

これは$\vec{a}$の整数倍なので$\overrightarrow{\mathrm{MN}} \parallel \overrightarrow{\mathrm{AD}}$
