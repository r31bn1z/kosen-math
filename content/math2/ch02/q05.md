### (1)

$$0.\dot{3} = 0.3 + 0.03 + 0.003 + \cdots$$

$a = 0.3$  $r = 0.1$ の公比無限級数となっているので

$$0.\dot{3} = \sum_{n=1}^{\infty} a_n = \frac{a}{1-r} = \frac{0.3}{1-0.1} = \frac{1}{3}$$

### (2)

$$0.\dot{1}2\dot{3} = 0.123 + 0.000123 + \cdots$$

$a = 0.123$  $r = 0.001$の公比無限級数となっているので

$$0.\dot{1}2\dot{3} = \frac{0.123}{1-0.001} = \frac{123}{999} = \frac{41}{333}$$

### (3)

$$0.0\dot{4}\dot{5} = 0.045 + 0.00045 + \cdots$$

$a = 0.045$  $r = 0.01$の公比無限級数となっているので

$$0.0\dot{4}\dot{5} = \frac{0.045}{1-0.01} = \frac{45}{990} = \frac{1}{22}$$

### (4)

$$0.28\dot{7}\dot{2} = 0.28 + (0.0072 + 0.000072 + \cdots)$$

$a = 0.0072$  $r = 0.01$の公比無限級数となっているので

$$0.28\dot{7}\dot{2} = 0.28 + \frac{0.0072}{1-0.01} = \frac{7}{25} + \frac{72}{9900} = \frac{77+2}{275} = \frac{79}{275}$$
