### (1)

公比 $r = x(1-x)$ なので、収束するには $|r| < 1$ の必要があるため

$$|x(1-x)| < 1$$

$$x(1-x) < 1 \qquad x - x^2 - 1 < 0 \qquad x^2 - x + 1 > 0 \qquad \therefore x < \frac{1-\sqrt{3}i}{2}, \frac{1+\sqrt{3}i}{2} < x$$

この場合虚数なので存在しない

$$-x(1-x) < 1 \qquad -x + x^2 - 1 < 0 \qquad x^2 - x - 1 < 0 \qquad \therefore \frac{1-\sqrt{5}}{2} < x < \frac{1+\sqrt{5}}{2}$$

よって $x$ の範囲は $\dfrac{1-\sqrt{5}}{2} < x < \dfrac{1+\sqrt{5}}{2}$

### (2)

$$S = \frac{a}{1-r} = \frac{1}{1-x(1-x)} = \frac{1}{x^2-x+1}$$

$x = \dfrac{1\pm\sqrt{5}}{2}$ を代入すると $S = \dfrac{1}{2}$

(1)での $x^2 - x - 1 = 0$ での極値 $x = \dfrac{1}{2}$ を代入すると $S = \dfrac{4}{3}$

$$\therefore \frac{1}{2} < S \leq \frac{4}{3}$$
