### (1)

$$\int \frac{1}{\sqrt{x}+\sqrt{1+x}}dx = \int \frac{\sqrt{x}-\sqrt{1+x}}{(\sqrt{x}+\sqrt{1+x})(\sqrt{x}-\sqrt{1+x})}dx = \int \frac{\sqrt{x}-\sqrt{1+x}}{x-(1+x)}dx = \int(\sqrt{x}-\sqrt{1+x})dx$$

$$=\frac{2}{3}\left\{\sqrt{(1+x)^3}-\sqrt{x^3}\right\}$$

### (2)

$$\int \frac{x-1}{\sqrt{2-x}}dx$$

$\sqrt{2-x}=t$ とおくと $2-x=t^2$ $dx=-2tdt$ これから

$$=\int \frac{1-t^2}{t}\cdot(-2t)dt=\int 2(t^2-1)dt=2\left(\frac{1}{3}t^3-t\right)=2t\left(\frac{1}{3}t^2-1\right)$$ 元に戻して

$$=2\sqrt{2-x}\left\{\frac{1}{3}(2-x)-1\right\}=2\sqrt{2-x}\left\{\frac{1}{3}(-1-x)\right\}=-\frac{2}{3}(x+1)\sqrt{2-x}$$

### (3)

$$\int \frac{1}{x^2(1-x)^2}dx = \int\left(\frac{A}{x^2}+\frac{B}{x}+\frac{C}{(1-x)^2}+\frac{D}{1-x}\right)dx$$

ここで $A(1-x)^2+Bx(1-x)^2+Cx^2+Dx^2(1-x)=1$ から

$A=1$、$B=2$、$C=1$、$D=2$が導かれる。 これから

$$=\int\left(\frac{1}{x^2}+\frac{2}{x}+\frac{1}{(1-x)^2}+\frac{2}{1-x}\right)dx=-\frac{1}{x}+2\log|x|+\frac{1}{1-x}-2\log|1-x|=\frac{2x-1}{x(1-x)}+2\log\left|\frac{x}{1-x}\right|$$

### (4)

$$\int x^2\log x\,dx=\frac{1}{3}x^3\log x-\frac{1}{3}\int x^3\cdot\frac{1}{x}dx=\frac{1}{3}x^3\log x-\frac{1}{3}\int x^2 dx=\frac{1}{3}x^3\log x-\frac{1}{9}x^3=\frac{1}{3}x^3\left(\log x-\frac{1}{3}\right)$$

### (5)

$$\int \frac{\log x}{(x+1)^2} dx = \int \log x \cdot \frac{1}{(x+1)^2} dx = -\frac{1}{x+1}\log x + \int \frac{1}{x(x+1)} dx = -\frac{1}{x+1}\log x + \int \left( \frac{1}{x} - \frac{1}{x+1} \right) dx$$

$$= -\frac{1}{x+1}\log x + \log x - \log(x+1) = \left(1 - \frac{1}{x+1}\right)\log x - \log(x+1) = \frac{x}{x+1}\log x - \log(x+1)$$

### (6)

$$\int \cos(5x) \cdot \cos x \, dx = \int \frac{1}{2}\{\cos(6x) + \cos(4x)\} dx = \frac{1}{2}\left\{\frac{1}{6}\sin(6x) + \frac{1}{4}\sin(4x)\right\} = \frac{1}{12}\sin 6x + \frac{1}{8}\sin 4x$$

・(3)の A,B,C,D の求め方

部分分数分解した値は分解前の解と等しくなければならないので

$$\frac{1}{x^2(1-x)^2} = \frac{A}{x^2} + \frac{B}{x} + \frac{C}{(1-x)^2} + \frac{D}{1-x} = \frac{A(1-x)^2 + Bx(1-x)^2 + cx^2 + Dx^2(1-x)}{x^2(1-x)^2}$$

となる必要がある。 よって分子が等しくなるためには

$$A(1-x)^2 + Bx(1-x)^2 + cx^2 + Dx^2(1-x) = 1 \quad \text{を満たす必要がある。}$$

右辺 $= A(1-2x+x^2) + Bx(1-2x+x^2) + Cx^2 + Dx^2 - Dx^3$

$$= (B-D)x^3 + (A-2B+C+D)x^2 + (-2A+B)x + A = 1 = \text{左辺}$$

これから $B-D=0$ $A-2B+C+D=0$ $-2A+B=0$ $A=1$ となる必要がある

この4つの式より $A=1$、$B=2$、$C=1$、$D=2$ が導かれる。
