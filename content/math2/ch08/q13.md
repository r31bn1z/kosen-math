### (1)
左辺=Iとおくと

$$I = \int e^{ax} \cdot \cos bx \, dx = \frac{1}{a}e^{ax}\cdot\cos bx + \int \frac{1}{a}e^{ax}\cdot b \cdot \sin bx\, dx$$

$$= \frac{1}{a}e^{ax}\cdot\cos bx + + \frac{b}{a}\cdot\frac{1}{a}\cdot e^{ax}\cdot\sin bx - \int \frac{b}{a}\cdot\frac{1}{a}\cdot b \cdot e^{ax}\cos bx\,dx + C$$

$$= \frac{1}{a}e^{ax}\cdot\cos bx + \frac{1}{a}\cdot\frac{b}{a}\cdot e^{ax}\cdot\sin bx - \frac{b^2}{a^2}I + C$$

$$I\left(1+\frac{b^2}{a^2}\right) = \frac{1}{a^2}\cdot e^{ax}(a\cdot\cos bx + b\cdot\sin xb) + C$$

$$I(a^2+b^2) = e^{ax}(a\cdot\cos bx + b\cdot\sin bx) + C$$

$$I = \frac{1}{a^2+b^2}\cdot e^{ax}(a\cdot\cos bx + b\cdot\sin bx) + C = (\text{右辺})$$

### (2)
左辺=Iとおくと

$$I = \int e^{ax}\cdot\sin bx\,dx = \frac{1}{a}\cdot e^{ax}\cdot\sin bx - \frac{1}{a}\int e^{ax}\cdot b\cdot\cos bx\,dx$$

$$= \frac{1}{a}\cdot e^{ax}\cdot\sin bx - \frac{1}{a^2}\cdot b\cdot e^{ax}\cdot\cos bx + \frac{1}{a^2}\cdot b\int e^{ax}(-b\cdot\sin bx)\,dx$$

$$= \frac{1}{a}\cdot e^{ax}\cdot\sin bx - \frac{b}{a^2}\cdot e^{ax}\cdot\cos bx - \frac{b^2}{a^2}I + C$$

$$I\left(1+\frac{b^2}{a^2}\right) = \frac{1}{a}\cdot e^{ax}\cdot\sin bx - \frac{b}{a^2}\cdot e^{ax}\cdot\cos bx + C$$

$$I(a^2+b^2) = e^{ax}(a\cdot\sin bx - b\cdot\cos bx) + C$$

$$I = \frac{1}{a^2+b^2}\cdot e^{ax}(a\cdot\sin bx - b\cdot\cos bx) + C = (\text{右辺})$$
