### (1)
$$\int x\sqrt{1-x}\,dx = x\cdot\left(-\frac{2}{3}\right)(1-x)^{\frac{3}{2}} + \int \frac{2}{3}(1-x)^{\frac{3}{2}}dx = -\frac{2}{3}x(1-x)^{\frac{3}{2}} - \frac{2}{3}\cdot\frac{2}{5}(1-x)^{\frac{5}{2}} + C$$

$$= -\frac{2}{15}\{5x(1-x)+2(1-x)^2\}\sqrt{1-x} + C = -\frac{2}{15}\{5x-5x^2+2-4x+2x^2\}\sqrt{1-x}+C$$

$$= -\frac{2}{15}(-3x^2+x+2)\sqrt{1-x}+C = \frac{2}{15}(3x^2-x-2)\sqrt{1-x}+C \qquad (C\text{は積分定数})$$

### (2)
$$\int (\log x)^2 dx = x(\log x)^2 - \int x\cdot 2\log x\cdot\frac{1}{x}dx = x(\log x)^2 - 2(x\log x - x) + C = x(\log x)^2 - 2x\cdot\log x + 2x + C$$

$$(C\text{は積分定数})$$

### (3)
$$\int x\cdot\tan^2 x\,dx$$

$$\int \tan^2 x\,dx = \int \frac{\sin^2 x}{\cos^2 x}dx = \int \frac{1-\cos^2 x}{\cos^2 x}dx = \int \frac{1}{\cos^2 x}dx - \int dx = \tan x - x + C$$

これから

$$\int x\cdot\tan^2 x\,dx = x(\tan x - x) - \int (\tan x - x)dx = x\cdot\tan x - x^2 - \int \tan x\,dx + \int x\,dx$$

$$= x\cdot\tan x - x^2 + \int \frac{\sin x}{\cos x}dx + \frac{1}{2}x^2 = x\cdot\tan x - x^2 + \log|\cos x| + \frac{1}{2}x^2 + C$$

$$= -\frac{1}{2}x^2 + x\cdot\tan x + \log|\cos x| + C \qquad (C\text{は積分定数})$$

### (4)
$$\int x\cdot\cos x\cdot\sin x\,dx = \int x\cdot\frac{1}{2}\sin 2x\,dx = \frac{1}{2}\cdot\frac{1}{2}x(-\cos 2x) + \int \frac{1}{4}\cos 2x\,dx = -\frac{1}{4}x\cdot\cos 2x + \frac{1}{4}\cdot\frac{1}{2}\sin 2x + C$$

$$= \frac{1}{8}(-2x\cos 2x + \sin 2x) + C \qquad (C\text{は積分定数})$$

### (5)
$$\int \frac{\tan^4 x}{\cos^2 x}dx \qquad \tan x = t\text{ とおくと }\frac{1}{\cos^2 x}dx = dt\text{ となるので}$$

$$= \int \tan^4 x\cdot\frac{1}{\cos^2 x}dx = \int t^4 dt = \frac{1}{5}t^5 + C = \frac{1}{5}\tan^5 x + C \qquad (C\text{は積分定数})$$

### (6)

$$\int \frac{1}{\sin x \cdot \cos x}\, dx$$

$\sin x = t$ とおくと $\cos x\, dx = dt$ となるので

$$= \int \frac{\cos x}{\sin x \cdot \cos^2 x}\, dx = \int \frac{1}{\sin x(1-\sin^2 x)}\cos x\, dx = \int \frac{1}{t(1-t^2)}\, dt = \int \left(\frac{1}{t} + \frac{t}{1-t^2}\right) dt$$

$$= \int \frac{1}{t}\, dt + \frac{1}{2}\int \frac{2t}{1-t^2}\, dt = \log|t| - \frac{1}{2}\log|1-t^2| + C$$

元に戻して

$$= \log|\sin x| - \frac{1}{2}\log|1-\sin^2 x| + C = \log|\sin x| - \log|\cos x| + C = \log\left|\frac{\sin x}{\cos x}\right| + C = \log|\tan x| + C$$

（Cは積分定数）

### (7)

$$\int \frac{3x}{x^2 - x - 2}\, dx = \int \frac{3x}{(x-2)(x+1)}\, dx = \int \left(\frac{2}{x-2} + \frac{1}{x+1}\right) dx = 2\log|x-2| + \log|x+1| + C$$

$$= \log (x-2)^2|x+1| + C$$

（Cは積分定数）

### (8)

$$\int e^x \{x - \log(e^x+2)\}\, dx$$

$e^x = t$ とおくと $x = \log t$、$e^x dx = dt$ から

$$= \int \{\log t - \log(t+2)\}\, dt = t \cdot \log t - t - \{(t+2)\cdot \log(t+2) - (t-2)\} + C$$

$$= t \cdot \log t - (t+2)\cdot \log(t+2) + C = e^x \cdot x - (e^x+2)\cdot \log(e^x+2) + C = xe^x - (e^x+2)\log(e^x+2) + C$$

（Cは積分定数）
