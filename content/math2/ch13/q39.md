### (1)

$$\overrightarrow{BA} = (3-2,0+1,-3-1) = (1,1,-4) \qquad \overrightarrow{BC} = (1-2,1+1,-1-1) = (-1,2,-2)$$

$$\cos(\angle B) = \frac{\overrightarrow{BA}\cdot\overrightarrow{BC}}{\left|\overrightarrow{BA}\right|\left|\overrightarrow{BC}\right|} = \frac{1\cdot(-1)+1\cdot2+(-4)\cdot(-2)}{\sqrt{1^2+1^2+(-4)^2}\sqrt{(-1)^2+2^2+(-2)^2}} = \frac{9}{\sqrt{18}\cdot 3} = \frac{1}{\sqrt{2}}$$

$$\angle B = 45°$$

### (2)

$$\overrightarrow{BA} = (1+1,0-3,1-0) = (2,-3,1) \qquad \overrightarrow{BC} = (2+1,2-3,-2-0) = (3,-1,-2)$$

$$\cos(\angle B) = \frac{\overrightarrow{BA}\cdot\overrightarrow{BC}}{\left|\overrightarrow{BA}\right|\left|\overrightarrow{BC}\right|} = \frac{2\cdot3+(-3)\cdot(-1)+1\cdot(-2)}{\sqrt{2^2+(-3)^2+1^2}\sqrt{3^2+(-1)^2+(-2)^2}} = \frac{7}{\sqrt{14}\sqrt{14}} = \frac{1}{2}$$

$$\angle B = 60°$$
