### (1)

右図から$\overrightarrow{OM} = \dfrac{1}{2}\overrightarrow{OA} = \dfrac{1}{2}\vec{a}$  $\overrightarrow{ON} = \dfrac{1}{2}\overrightarrow{OB} = \dfrac{1}{2}\vec{b}$

$$\overrightarrow{MN} = \overrightarrow{MO} + \overrightarrow{ON} = -\dfrac{1}{2}\vec{a} + \dfrac{1}{2}\vec{b} = \dfrac{\vec{b} - \vec{a}}{2}$$

よって方向ベクトルは$\dfrac{\vec{b} - \vec{a}}{2}$となる

これから問題集 p59 の直線のベクトル方程式より

$$\vec{p} = \dfrac{\vec{a}}{2} + t\dfrac{\vec{b} - \vec{a}}{2}$$

### (2)

$$\overrightarrow{AN} = \overrightarrow{AO} + \overrightarrow{ON} = -\vec{a} + \dfrac{1}{2}\vec{b}$$

よって方向ベクトルは$-\vec{a} + \dfrac{1}{2}\vec{b}$となる

これから $\vec{p} = \vec{a} + t\left(-\vec{a} + \dfrac{1}{2}\vec{b}\right)$

### (3)

$$\overrightarrow{AB} = \overrightarrow{AO} + \overrightarrow{OB} = -\vec{a} + \vec{b}$$

よって方向ベクトルは$-\vec{a} + \vec{b}$となる

$\overrightarrow{OC} = \overrightarrow{OA} + \overrightarrow{OB} = \vec{a} + \vec{b}$なので

これから $\vec{p} = \vec{a} + \vec{b} + t(-\vec{a} + \vec{b})$
