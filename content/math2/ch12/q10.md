２点$(a_1, a_2), (b_1, b_2)$を通る直線は、傾きが$\dfrac{b_2-a_2}{b_1-a_1}$となるので

$$y = \frac{b_2-a_2}{b_1-a_1}x + C$$

またこの直線が$(a_1, a_2)$を通ることから C を求めると

$$a_2 = \frac{b_2-a_2}{b_1-a_1}a_1 + C \qquad C = a_2 - \frac{b_2-a_2}{b_1-a_1}a_1 = \frac{a_2b_1-a_1a_2-a_1b_2+a_1a_2}{b_1-a_1} = \frac{a_1b_2-a_2b_1}{a_1-b_1}$$

これから

$$y = \frac{b_2-a_2}{b_1-a_1}x + \frac{a_1b_2-a_2b_1}{a_1-b_1}$$

### (1)

上式より $y = \dfrac{5-3}{5-2}x + \dfrac{2\cdot5-3\cdot5}{2-5} = \dfrac{2}{3}x + \dfrac{5}{3}$  $2x-3y+5=0$

### (2)

上式より $y = \dfrac{-3-3}{1+2}x + \dfrac{-2\cdot(-3)-3\cdot1}{-2-1} = -2x-1$  $2x+y+1=0$

### (3)

上式より $y = \dfrac{2-0}{0-3}x + \dfrac{3\cdot2+0}{3-0} = -\dfrac{2}{3}x+2$  $2x+3y-6=0$

### (4)

x一定なので $x = 3$
