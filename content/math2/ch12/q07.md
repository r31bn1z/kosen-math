### (1)
$$a + 2b = (3,-1) + 2(2,4) = (7,7)$$

### (2)
$$a + \frac{3}{2}b + 2c = (3,-1) + \frac{3}{2}(2,4) + 2(-2,1) = (2,7)$$

### (3)
$$|a| = \sqrt{3^2+(-1)^2} = \sqrt{10}$$

### (4)
$$|b+2c| = |(2,4)+2(-2,1)| = |(-2,6)| = \sqrt{(-2)^2+6^2} = \sqrt{40} = 2\sqrt{10}$$

### (5)
$$a\cdot b = 3\cdot 2 + (-1)\cdot 4 = 2$$

### (6)
$$(a+b)\cdot c = \{(3,-1)+(2,4)\}\cdot(-2,1) = (5,3)\cdot(-2,1) = 5\cdot(-2)+3\cdot 1 = -10+3 = -7$$
