### (1)

$x\vec{a} + y\vec{b} = \vec{c}$ となればよいので

$$x\begin{pmatrix}1\\3\end{pmatrix} + y\begin{pmatrix}4\\2\end{pmatrix} = \begin{pmatrix}3\\2\end{pmatrix}$$

$$\begin{cases} x + 4y = 3 \\ 3x + 2y = 2 \end{cases}$$

これから $x = \dfrac{1}{5}$ $y = \dfrac{7}{10}$

よって $\dfrac{1}{5}\vec{a} + \dfrac{7}{10}\vec{b} = \vec{c}$

### (2)

$x\vec{a} + y\vec{b} = \vec{d}$ となればよいので

$$x\begin{pmatrix}1\\3\end{pmatrix} + y\begin{pmatrix}4\\2\end{pmatrix} = \begin{pmatrix}-5\\5\end{pmatrix}$$

$$\begin{cases} x + 4y = -5 \\ 3x + 2y = 5 \end{cases}$$

これから $x = 3$ $y = -2$

よって $3\vec{a} - 2\vec{b} = \vec{d}$
