この問の図は変換原稿に含まれていません。

### (1)

$$y = \dfrac{x^2 - 3}{x - 2}$$  定義域は $x \neq 2$

$$y' = \dfrac{2x(x-2) - (x^2-3)}{(x-2)^2} = \dfrac{2x^2 - 4x - x^2 + 3}{(x-2)^2} = \dfrac{x^2 - 4x + 3}{(x-2)^2} = \dfrac{(x-3)(x-1)}{(x-2)^2}$$

$y' = 0$ になるのは $x = 1, 3$ のとき

| x  | ・・・ | 1 | ・・・ | 2 | ・・・ | 3 | ・・・ |
|----|--------|---|--------|---|--------|---|--------|
| y' | ＋     | 0 | －     | ／ | －     | 0 | ＋     |
| y  |        | 2 |        | ／ |        | 6 |        |

### (2)

$$y = \dfrac{x^2}{2(x-3)}$$

$$y' = \dfrac{1}{2} \cdot \dfrac{2x \cdot (x-3) - x^2}{(x-3)^2} = \dfrac{2x^2 - 6x - x^2}{2(x-3)^2} = \dfrac{x^2 - 6x}{2(x-3)^2} = \dfrac{x(x-6)}{2(x-3)^2}$$

$y' = 0$ になるのは $x = 0, 6$ のとき。またこの関数の定義域は $x = 3$ を除く実数全体。

$x = 0$ のとき $y = \dfrac{0^2}{2(0-3)} = 0$

$x = 6$ のとき $y = \dfrac{6^2}{2(6-3)} = 6$

| x  | ・・・ | 0 | ・・・ | 3 | ・・・ | 6 | ・・・ |
|----|--------|---|--------|---|--------|---|--------|
| y' | ＋     | 0 | －     | ／ | －     | 0 | ＋     |
| y  |        | 0 |        | ／ |        | 6 |        |

### (3)

$$y = x - 2\sqrt{x}$$  定義域は $x \geq 0$

$$y' = 1 - \dfrac{1}{\sqrt{x}} = \dfrac{\sqrt{x} - 1}{\sqrt{x}}$$

$y' = 0$ になるのは $x = 1$ のとき

| x  | 0 | ・・・ | 1  | ・・・ |
|----|---|--------|----|--------|
| y' |   | －     | 0  | ＋     |
| y  | 0 |        | -1 |        |

### (4)

$y = x\sqrt{3-x}$ 定義域は $x \le 3$

$$y' = \sqrt{3-x} + x\dfrac{-1}{2\sqrt{3-x}} = \dfrac{2(3-x)-x}{2\sqrt{3-x}} = \dfrac{6-2x-x}{2\sqrt{3-x}} = \dfrac{-3(x-2)}{2\sqrt{3-x}}$$

$y' = 0$ になるのは $x = 2$ のとき

| x | ・・・ | 2 | ・・・ | 3 |
|---|---|---|---|---|
| y' | + | 0 | − | ／ |
| y |  | 2 |  | ／ |

### (5)

$y = x\sqrt{8-x^2}$ 定義域は $|x| \le 2\sqrt{2}$

$$y' = \sqrt{8-x^2} + x\dfrac{-2x}{2\sqrt{8-x^2}} = \dfrac{8-x^2-x^2}{\sqrt{8-x^2}} = \dfrac{-2(x^2-4)}{\sqrt{8-x^2}} = \dfrac{-2(x-2)(x+2)}{\sqrt{8-x^2}}$$

$y' = 0$ になるのは $x = \pm 2$ のとき

| x | $-2\sqrt{2}$ | ・・・ | −2 | ・・・ | 2 | ・・・ | $2\sqrt{2}$ |
|---|---|---|---|---|---|---|---|
| y' | ／ | − | 0 | + | 0 | − | ／ |
| y | ／ |  | -4 |  | 4 |  | ／ |

### (6)

$y = \log(2-x^2)$ 定義域は $|x| \le \sqrt{2}$

$$y' = \dfrac{-2x}{2-x^2}$$

$y' = 0$ になるのは $x = 0$ のとき

| x | $-\sqrt{2}$ | ・・・ | 0 | ・・・ | $\sqrt{2}$ |
|---|---|---|---|---|---|
| y' | ／ | + | 0 | − | ／ |
| y | ／ |  | $\log 2$ |  | ／ |
