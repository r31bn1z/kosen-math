### (1)
$$y = x + \frac{4}{x-1}$$

$$y' = 1 + \frac{-4}{(x-1)^2} = \frac{(x-1)^2-4}{(x-1)^2} = \frac{x^2-2x-3}{(x-1)^2} = \frac{(x-3)(x+1)}{(x-1)^2}$$

$y' = 0$ のとき $x = -1, 3$

$x = 3$ のとき $y = 3+2 = 5$  $x = 2$ のとき $y = 2+4 = 6$  $x = 4$ のとき $y = 4+\dfrac{4}{3} = \dfrac{16}{3}$

これから $x = 2$ のとき最小値 $5$  $x = 2$ のとき最大値 $6$

### (2)
$$y = x\sqrt{3-x}$$

$$y' = \sqrt{3-x} + x\cdot\frac{-1}{2\sqrt{3-x}} = \frac{2(3-x)-x}{2\sqrt{3-x}} = \frac{6-2x-x}{2\sqrt{3-x}} = \frac{-3(x-2)}{2\sqrt{3-x}}$$

$y' = 0$ のとき $x = 2$

$x = 2$ のとき $y = 2$  $x = -1$ のとき $y = -2$  $x = 3$ のとき $y = 0$

これから $x = -1$ のとき最小値 $-2$  $x = 2$ のとき最大値 $2$

### (3)
$$y = (x^2-8)e^x$$

$$y' = 2xe^x + (x^2-8)e^x = e^x(x^2+2x-8) = e^x(x+4)(x-2)$$

$y' = 0$ のとき $x = -4, 2$

$x = 2$ のとき $y = -4e^2$  $x = -3$ のとき $y = e^{-3}$  $x = 3$ のとき $y = e^3$

これから $x = 2$ のとき最小値 $-4e^2$  $x = 3$ のとき最大値 $e^3$

### (4)
$y = \log x + 2\log(3-x)$

$$y' = \frac{1}{x} + \frac{-2}{3-x} = \frac{3-x-2x}{x(3-x)} = \frac{-3(x-1)}{x(3-x)}$$

$y'=0$ のとき $x=1$

$x=1$ のとき $y = 2\log 2$     $x=0$ のとき $-\infty$     $x=3$ のとき $y=-\infty$

これから最小値はなし $x=1$ のとき最大値 $2\log 2$

### (5)
$y = x\cos x - \sin x$

$$y' = \cos x - x\sin x - \cos x = -x\sin x$$

$y'=0$ のとき $x = 0, \pi, 2\pi$

$x=0$ のとき $y=0$     $x=\pi$ のとき $y=-\pi$     $x=2\pi$ のとき $y=2\pi$

これから $x=\pi$ のとき最小値 $-\pi$   $x=2\pi$ のとき最大値 $2\pi$

### (6)
$y = x + 2\sin x$

$$y' = 1 + 2\cos x$$

$y'=0$ のとき  $\cos x = -\dfrac{1}{2}$   $x = \dfrac{2}{3}\pi$

$x=\dfrac{2}{3}\pi$ のとき $y = \dfrac{2}{3}\pi + \sqrt{3}$     $x=0$ のとき $y=0$     $x=\pi$ のとき $y=\pi$

これから $x=0$ のとき最小値 $0$  $x=\dfrac{2}{3}\pi$ のとき最大値 $\dfrac{2}{3}\pi + \sqrt{3}$
