x 軸の正の部分を動く点 P の座標を(x,0)とする。

AP の長さは$\mathrm{AP} = \sqrt{x^2+a^2}$ BP の長さは$\mathrm{BP} = \sqrt{x^2+b^2}$

∠APB の大きさは ∠APB＝∠APO－∠BPO

∠APB＝θ とおくと

$$\cos\theta = \cos(\angle APO - \angle BPO)$$

$$= \cos(\angle APO)\cos(\angle BPO) + \sin(\angle APO)\sin(\angle BPO)$$

$$= \frac{OP}{AP}\cdot\frac{OP}{BP} + \frac{AO}{AP}\cdot\frac{BO}{BP} = \frac{x}{\sqrt{x^2+a^2}}\cdot\frac{x}{\sqrt{x^2+b^2}} + \frac{a}{\sqrt{x^2+a^2}}\cdot\frac{b}{\sqrt{x^2+b^2}} = \frac{1}{\sqrt{(x^2+a^2)(x^2+b^2)}}(x^2+ab)$$

θ は 90° 以上になることはない$(0 < \theta < 90°)$

よって $\cos\theta$ が最小になる点が θ が最大となる点である

$(\cos\theta)' = 0$となる点は

$$(\cos\theta)' = \{(x^2+a^2)(x^2+b^2)\}^{-\frac{3}{2}}\cdot 2x\{(x^2+a^2)+(x^2+b^2)\}\cdot\left(-\frac{1}{2}\right)\cdot(x^2+ab)$$

$$+ \{(x^2+a^2)(x^2+b^2)\}^{-\frac{1}{2}}\cdot 2x = 0$$

$$\{(x^2+a^2)(x^2+b^2)\}^{-\frac{3}{2}}\{-x(2x^2+a^2+b^2)(x^2+ab) + 2x(x^2+a^2)(x^2+b^2)\} = 0$$

$$\{(x^2+a^2)(x^2+b^2)\}^{-\frac{3}{2}}\cdot x(2x^4+a^2x^2+b^2x^2+2abx^2+a^3b+ab^3-2x^4-2a^2x^2-2b^2x^2-2a^2b^2) = 0$$

$$\{(x^2+a^2)(x^2+b^2)\}^{-\frac{3}{2}}\cdot x(2abx^2-a^2x^2-b^2x^2-2a^2b^2+a^3b+ab^3) = 0$$

$$\{(x^2+a^2)(x^2+b^2)\}^{-\frac{3}{2}}\cdot x\{x^2(2ab-a^2-b^2) - ab(2ab-a^2-b^2)\} = 0$$

$$\{(x^2+a^2)(x^2+b^2)\}^{-\frac{3}{2}}\cdot x(2ab-a^2-b^2)(x^2-ab) = 0$$

$\therefore x = 0$、$ai$、$bi$、$\sqrt{ab}$

$0 < x < 90°$の条件に適合するのは$x = \sqrt{ab}$

$x < \sqrt{ab}$で$\cos\theta'$は負の値→$\cos\theta$は減少  $x > \sqrt{ab}$で$\cos\theta'$は正の値→$\cos\theta$は増加

よって$x = \sqrt{ab}$で$\cos\theta$は最小値となるので$\theta(\angle APB)$は最大となる
