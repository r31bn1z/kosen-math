$y_1 = a(x-1) - x^a - 1$ とおくと

$y_1' = a - ax^{a-1} = a(1-x^{a-1})$

$y_1' = 0$ のとき  $a(1-x^{a-1}) = 0$  $\therefore x = 1$

この関数の定義域は$x > 1$の実数全体であり$x = 1$の極限値は

$$\lim_{x \to 1} y_1 = a(1-1) - 1^a - 1 = -2$$

| $x$ | 1 | ・・・ |
|---|---|---|
| $y_1{}'$ | 0 | - |
| $y$ | ／ | |

$x = 1$の極限がマイナスであり、さらに減少する曲線であるので

$y_1 < 0$  $\therefore a(x-1) < x^a - 1$

$y_2 = x^a - 1 - ax^{a-1}(x-1)$ とおくと

$y_2' = ax^{a-1} - a(a-1)x^{a-2}(x-1) - ax^{a-1} = -a(a-1)x^{a-2}(x-1)$

$y_2' = 0$ のとき  $-a(a-1)x^{a-2}(x-1) = 0$  $x^{a-2} = 0$  $x - 1 = 0$  $\therefore x = 0, 1$

$x = 1$の極限値は

$$\lim_{x \to 1} y_2 = 1^a - 1 - a \cdot 1^{a-1}(1-1) = 0$$

| $x$ | 1 | ・・・ |
|---|---|---|
| $y_1{}'$ | 0 | - |
| $y$ | ／ | |

$x = 1$の極限がマイナスであり、さらに減少する曲線であるので

$y_1 < 0$  $\therefore x^a - 1 < ax^{a-1}(x-1)$

これらから$a(x-1) < x^a - 1 < ax^{a-1}(x-1)$
