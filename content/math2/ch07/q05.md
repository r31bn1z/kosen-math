### (1)
実数解の個数＝x 軸との交点の数 となるので

$f = x^3 - 3x + 1 - a$ とおくと

$f' = 3x^2 - 3$ $f' = 0$ のとき $3x^2 - 3 = 0$ $x = \pm 1$

$x = 1$ のとき $x$ 軸と接すると考えると

$f = 1 - 3 + 1 - a = 0$ $a = -1$

$x = -1$ のとき $x$ 軸と接すると考えると

$f = -1 + 3 + 1 - a = 0$ $a = 3$

これから $a < -1, 3 < a$ のとき1個 $a = -1, a = 3$ のとき2個 $-1 < a < 3$ のとき3個

### (2)
$f = 4x^2 - \dfrac{1}{x} - a$ （定義域 $x \neq 0$）とおくと

$f' = 8x + \dfrac{1}{x^2}$ $f' = 0$ のとき $8x + \dfrac{1}{x^2} = 0$ $8x^3 + 1 = 0$ $x^3 = -\dfrac{1}{8}$ $x = -\dfrac{1}{2}$

$x = -\dfrac{1}{2}$ のとき $x$ 軸と接すると考えると $4 \cdot \dfrac{1}{4} + 2 - a = 0$ $a = 3$

これから

$a < 3$ のとき1個 $a = 3$ のとき2個 $3 < a$ のとき3個
