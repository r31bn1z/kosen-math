$y = e^x + 1$

$y' = e^x$

これから接線の方程式は

$$y - f(a) = e^a(x - a)$$

点Pの座標が$(a, f(a)) = (a, e^a + 1)$だとすると

$$y - (e^a + 1) = e^a(x - a)$$

$$\therefore y = e^a(x - a) + e^a + 1$$

この式に$y = 0$を代入すると

$$0 = e^a(x - a) + e^a + 1 = x - a + 1 + e^{-a}$$

$$x = a - 1 - e^{-a} \quad \to \text{点Q\text{の}x\text{座標}}$$

これからQRの長さは  $QR = a - (a - 1 - e^{-a}) = 1 + e^{-a}$

PRの長さは$y = e^a + 1$であえり、△PQRは直角三角形であるのでこの面積$S$は

$$S = \frac{1}{2} \cdot QR \cdot PR = \frac{1}{2}(e^a + 1)(1 + e^{-a}) = \frac{1}{2}(1 + e^a + e^{-a} + 1) = \frac{1}{2}(e^a + e^{-a} + 2)$$

$$S' = \frac{1}{2}(e^a - e^{-a})$$

$S' = 0$となるのは  $e^a - e^{-a} = 0$  $e^a = e^{-a}$  $a = -a$  $a = 0$

$x = a = 0$のとき△PQRは最小になる。この時の面積は

$$S = \frac{1}{2}(e^0 + e^{-0} + 2) = \frac{1}{2}(1 + 1 + 2) = \frac{1}{2} \cdot 4 = 2$$

△PQRの面積は$x = 0$のとき最小値$S = 2$となる
