$y_1 = x - \sin x$とおくと

$$y_1{}' = 1 - \cos x$$

$y' = 0$となるのは $1 - \cos x = 0$  $\cos x = 1$  $x = 0$

$x=0$ の極限値は

$$\lim_{x \to 0} y_1 = \lim_{x \to 0}(x - \sin x) = 0 - \sin 0 = 0$$

| x | 0 | ・・・ | $\dfrac{\pi}{2}$ |
|---|---|---|---|
| $y_1{}'$ | 0 | + | + |
| $y_1$ | ／ |  | ／ |

$x = 0$ の極限値は $0$ であり、増減表より$\left(0 < x < \dfrac{\pi}{2}\right)$では$y_1$は増加なので

$$y_1 > 0 \qquad x - \sin x > 0 \qquad \sin x < x$$

$$y_2 = \sin x - \frac{2x}{\pi}$$

$$y_2{}' = \cos x - \frac{2}{\pi}$$

$y_2{}' = 0$となるのは $\cos x - \dfrac{2}{\pi} = 0$

$\cos x = \dfrac{2}{\pi}$のとき

$x = 0$ のとき、極限値 $\displaystyle\lim_{x \to 0} y_2 = \lim_{x \to 0}\left(\sin x - \frac{2x}{\pi}\right) = \sin 0 - \frac{2 \cdot 0}{\pi} = 0$

$x = \dfrac{2}{\pi}$ のとき、極限値 $\displaystyle\lim_{x \to \frac{2}{\pi}} y_2 = \lim_{x \to \frac{2}{\pi}}\left(\sin x - \frac{2x}{\pi}\right) = \sin\left(\frac{2}{\pi}\right) - \frac{2}{\pi}\cdot\frac{2}{\pi} = 1 - \frac{4}{\pi^2} > 0$

| x | 0 | ・・・ | $\cos x = \dfrac{2}{\pi}$ | ・・・ | $\dfrac{2}{\pi}$ |
|---|---|---|---|---|---|
| $y_2{}'$ | + | + | 0 | - | - |
| $y_2$ | ／ |  |  |  | ／ |

増減表より$y_2$は$\left(0 < x < \dfrac{\pi}{2}\right)$の範囲で$y_2 > 0$であると分かるので

$$y_2 > 0 \qquad \sin x - \frac{2x}{\pi} > 0 \qquad \frac{2x}{\pi} < \sin x$$

これらの結果より $\dfrac{2x}{\pi} < \sin x < x$
