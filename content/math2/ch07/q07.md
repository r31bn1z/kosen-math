$$x - \cos x + a = 0$$

$f = x - \cos x + a$ とおくと

$$f' = 1 + \sin x$$

$f' = 0$ のとき $\sin x = -1$  $x = \dfrac{3}{2}\pi$

| x  | ・・・ | $\dfrac{3}{2}\pi$ | ・・・ |
|----|--------|--------------------|--------|
| y' | ＋     | 0                  | ＋     |
| y  |        | $\dfrac{3}{2}\pi + a$ |      |

これから実数 a のどんな値に対しても増加関数であるのでただ１つの実数解となる

この問のグラフは変換原稿に含まれていません。

$f = x - \cos x + a$ （a=1 のとき）
