### (1)

$y = e^x - \dfrac{x^2}{2}$ とおくと

$y'= e^x - x$

$y'=0$ のとき  $e^x - x = 0$  （$e^x \approx 1+x+\dfrac{x^2}{2}$ とする）

$$1+x+\dfrac{x^2}{2}=x \qquad \therefore x = \sqrt{2}\,i$$

これから $y'=0$ となる $x$ の値は存在しない。

$x=0$ のとき極限値は  $\displaystyle\lim_{x\to 0} y = e^0 - \dfrac{0}{2} = 1$

| $x$ | 0 | ・・・ |
|---|---|---|
| $y'$ | + | + |
| $y$ | ／ |  |

$x=0$ のとき極限値が $1$ であるので $y$ が負となることはない

よって $y>0$  $\therefore e^x > \dfrac{x^2}{2}$

### (2)

$y = \sin x + \dfrac{x^2}{2} - x$ とおくと

$y' = \cos x + x - 1$

$y'=0$ のとき  $\cos x + x - 1 = 0$  $\therefore x = 0$

$x=0$ のとき極限値は  $\displaystyle\lim_{x\to 0} y = 0$

| $x$ | 0 | ・・・ |
|---|---|---|
| $y'$ | 0 | + |
| $y$ | ／ |  |

これから $y$ が負となることはない

よって $y>0$  $\therefore x < \sin x + \dfrac{x^2}{2}$

### (3)

$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots + (-1)^n \frac{x^{2n}}{(2n)!} + \cdots$$

$\cos x \cong 1 - \dfrac{x^2}{2!}$ としたとき、誤差は $\dfrac{x^4}{4!}$ であり常に正であるため

$$1 - \frac{x^2}{2!} < \cos x \text{ である}$$

$\cos x \cong 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!}$ としたとき、誤差は $-\dfrac{x^6}{6!}$ であり常に負であるため

$$\cos x < 1 - \frac{x^2}{2!} + \frac{x^4}{4!} \text{ である}$$

よって

$$1 - \frac{x^2}{2!} < \cos x < 1 - \frac{x^2}{2!} + \frac{x^4}{4!} \text{ となる}$$
