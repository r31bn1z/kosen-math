### (1)
$$y = e^{2x}$$

$$y' = (2x)'e^{2x} = 2e^{2x}$$

### (2)
$$y = e^{2-3x}$$

$$y' = (2-3x)'e^{2-3x} = -3e^{2-3x}$$

### (3)
$$y = xe^{-2x}$$

$$y' = e^{-2x} + x(-2x)'e^{-2x} = e^{-2x} - 2xe^{-2x} = (1-2x)e^{-2x}$$

### (4)
$$y = xe^{-x^2} = e^{-x^2} + x(-x^2)'e^{-x^2} = e^{-x^2} - 2x^2e^{-x^2} = (1-2x^2)e^{-x^2}$$

### (5)
$$y = (x+1)a^{2x}$$ 両辺の $\log$ をとって

$$\log y = \log(x+1)a^{2x} \qquad \log y = \log(x+1) + 2x \cdot \log a$$

$$\frac{y'}{y} = \frac{1}{x+1} + 2\log a \qquad y' = y\left(\frac{1}{x+1} + 2\log a\right) \qquad y' = (x+1)a^{2x}\left(\frac{1}{x+1} + 2\log a\right)$$

$$y' = \{1 + 2(x+1)\log a\}a^{2x}$$

### (6)
$$y = \frac{1}{1-e^{2x}}$$

$$y' = (1-e^{2x})^{-1\prime} = -(1-e^{2x})'(1-e^{2x})^{-2} = -(-2e^{2x})(1-e^{2x})^{-2} = \frac{2e^{2x}}{(1-e^{2x})^2}$$
