### (1)
$f = \log_{10} x - \dfrac{x}{20}$ とすると $f$ は $x \geq 0$ で連続である

$$f_0 = -\infty < 0 \qquad f_{(10)} = 1 - \dfrac{1}{2} = \dfrac{1}{2} > 0$$

これから中間値の定理より

$$f_{(c)} = \log_{10} c - \dfrac{c}{20} = 0 \quad \text{であるような} c \text{が区間} (0,10) \text{の中に少なくとも1\text{つは存在する}}$$

### (2)
$f = (x^2 - 1)\cos x + \sqrt{2}\sin x - 1$ とすると $f$ は全区間で連続である

$$f_{(0)} = -1 - 1 = -2 < 0 \qquad f_{\left(\frac{\pi}{2}\right)} = \sqrt{2} - 1 > 0$$

これから中間値の定理より

$$f_{(c)} = (c^2 - 1)\cos c + \sqrt{2}\sin c - 1 \quad \text{であるような} c \text{が区間} \left(0, \dfrac{\pi}{2}\right) \text{の中に少なくとも1\text{つは存在する}}$$
