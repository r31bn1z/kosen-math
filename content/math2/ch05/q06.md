### (1)
$$y = (x^2 + 2x)(3x + 1) = 3x^3 + 7x^2 + 2x$$

$$y' = 9x^2 + 14x + 2$$

### (2)
$$y = (2x^3 + 6x)(7x - 5) = 14x^4 - 10x^3 + 42x^2 - 30x$$

$$y' = 56x^3 - 30x^2 + 84x - 30$$

### (3)
$$s = (t + 1)(t^2 - 4t - 5) = t^3 - 3t^2 - 9t - 5$$

$$s' = 3t^2 - 6t - 9$$

### (4)
$$y = (x - 1)(x - 2)(x - 3) = x^3 - 6x^2 + 11x - 6$$

$$y' = 3x^2 - 12x + 11$$
