与式においてh = x − aとおくと

$$\text{左辺} = \lim_{h\to0}\frac{1}{h}\left\{f\left(a+h+\frac{1}{2}h\right) + f\left(a+h+\frac{3}{2}h\right) - 2f(a+h)\right\}$$

$$= \lim_{h\to0}\frac{1}{h}\left\{f\left(a+\frac{3}{2}h\right) + f\left(a+\frac{5}{2}h\right) - 2f(a+h)\right\}$$

$$= \lim_{h\to0}\frac{1}{h}f\left(a+\frac{3}{2}h\right) + \lim_{h\to0}\frac{1}{h}f\left(a+\frac{5}{2}h\right) - 2\lim_{h\to0}\frac{1}{h}f(a+h)$$

$$h' = \frac{3}{2}h、\ h'' = \frac{5}{2}h \text{ とおくと}$$

$$= \lim_{h\to0}\frac{1}{\frac{2}{3}h'}\{f(a+h')-f(a)\} + \lim_{h\to0}\frac{1}{\frac{2}{5}h''}\{f(a+h'')-f(a)\} - 2\lim_{h\to0}\frac{1}{h}f(a+h) + \lim_{h\to0}\frac{1}{\frac{2}{3}h'}f(a) + \lim_{h\to0}\frac{1}{\frac{2}{5}h''}f(a)$$

$$= \frac{3}{2}f'(a) + \frac{5}{2}f'(a) - 2\lim_{h\to0}\frac{1}{h}f(a+h) + \lim_{h\to0}\frac{1}{h}f(a) + \lim_{h\to0}\frac{1}{h}f(a)$$

$$= \frac{8}{2}f'(a) - 2\lim_{h\to0}\frac{1}{h}\{f(a+h)-f(a)\}$$

$$= 4f'(a) - 2f'(a) = 2f'(a)$$
