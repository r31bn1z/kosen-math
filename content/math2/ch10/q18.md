### (1)
$0 \leq h \leq 1$ のとき

$$S_{(h)} = \pi x_1^2 - \pi x_2^2$$

$y = (x^2-1)^2$から  $x^2 = \pm\sqrt{y} + 1$

y は高さであるので h とすると

$$S_{(h)} = \pi(\sqrt{h}+1) - \pi(-\sqrt{h}+1) = 2\pi\sqrt{h}$$

$1 < h \leq 9$ のとき  $S_{(h)} = \pi x^2 = \pi(\sqrt{h}+1)$

### (2)
$0 \leq h \leq 1$ のときで

$$V_{(h)} = \int_0^1 S_{(h)}\,dh = \int_0^1 2\pi\sqrt{h}\,dh = 2\pi\left[\frac{2}{3}h^{\frac{3}{2}}\right]_0^1 = \frac{4}{3}\pi$$

### (3)
$0 \leq h \leq 9$のとき

$$V_{(h)} = \int_0^h S_{(h)}\,dh = \int_0^1 2\pi\sqrt{h}\,dh + \int_1^h \pi(\sqrt{h}+1)\,dh = \frac{4}{3}\pi + \pi\left[\frac{2}{3}h^{\frac{3}{2}} + h\right]_1^h = \pi\left(\frac{2}{3}h^{\frac{3}{2}} + h - \frac{1}{3}\right)$$

$\dfrac{dV}{dt} = c$ とおくと

$h = 4$ では

$$\frac{dV}{dt} = \frac{dV}{dh}\cdot\frac{dh}{dt} = S_{(h)}\cdot\frac{dh}{dt} = \pi(\sqrt{h}+1)\frac{dh}{dt} = c$$

$$\frac{dh}{dt} = \frac{c}{\pi(\sqrt{h}+1)}\qquad h=4 \text{を代入して}$$

$$= \frac{c}{\pi(2+1)} = \frac{c}{3\pi}$$
