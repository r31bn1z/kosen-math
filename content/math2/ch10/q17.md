### (1)
$y \leq 1$ の容器の容量は

$$V = \pi\int_0^1 y^2\,dy = \pi\left[\frac{1}{3}y^3\right]_0^1 = \frac{\pi}{3}$$

これから $\dfrac{\pi}{3}$ 秒後に水面は $y=1$ の所にある

・$0 \leq t \leq \dfrac{\pi}{3}$ のとき

$$\pi\int_0^H y^2\,dy = \frac{\pi}{3}[y^3]_0^H = \frac{\pi}{3}H^3$$

これは時間 $t$ と等しいので

$$\frac{\pi}{3}H^3 = t \qquad H = \sqrt[3]{\frac{3}{\pi}t}$$

・$\dfrac{\pi}{3} < t$ のとき

$$\pi\int_0^1 y^2\,dy + \pi\int_1^H \left(\frac{1}{y}\right)^2 dy = \frac{\pi}{3} + \pi\left[-\frac{1}{y}\right]_1^H = \frac{4\pi}{3} - \frac{\pi}{H}$$

これは時間 $t$ と等しいので

$$\frac{4\pi}{3} - \frac{\pi}{H} = t \qquad H = \frac{3\pi}{4\pi - 3t}$$

ここで $t > \dfrac{4\pi}{3}$ となると $H < 0$ となるので

$$\frac{\pi}{3} < t < \frac{4\pi}{3} \text{ のとき} \qquad H = \frac{3\pi}{4\pi - 3t}$$

### (2)
$0 \leq t \leq \dfrac{\pi}{3}$ のとき

$$H' = \sqrt[3]{\frac{3}{\pi}} \cdot \frac{1}{3}t^{-\frac{2}{3}} = \frac{1}{\sqrt[3]{9\pi t^2}}$$

$\dfrac{\pi}{3} < t < \dfrac{4\pi}{3}$ のとき

$$H' = \frac{-3\pi(-3)}{(4\pi-3t)^2} = \frac{9\pi}{(4\pi-3t)^2}$$
