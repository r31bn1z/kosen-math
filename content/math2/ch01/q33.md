$a_1 = 1$、$b_1 = 0$ $\quad$ $a_{n+1} = \dfrac{2}{3}a_n + \dfrac{1}{3}b_n$ $\quad$ ① $\quad\quad$ $b_{n+1} = \dfrac{1}{3}a_n + \dfrac{2}{3}b_n$ $\quad$ ②

①＋②は $\quad$ $a_{n+1} + b_{n+1} = a_n + b_n$ $\quad$ これより $a_n + b_n$ は一定

$a_1 = 1$、$b_1 = 0$ より $\quad$ 常に $a_n + b_n = 1$ $\quad$ ④

①－②は $\quad$ $a_{n+1} - b_{n+1} = \dfrac{1}{3}a_n - \dfrac{1}{3}b_n = \dfrac{1}{3}(a_n - b_n)$ $\quad$ ⑤

$a_n - b_n = C_n$ とおくと $C_n$ は $\dfrac{1}{3}$ の等比数列なので $C_1 = 1 - 0 = 1$ より

$$C_n = \frac{1}{3^{n-1}} \quad ⑥$$

④＋⑥より $\quad$ $2a_n = 1 + \dfrac{1}{3^{n-1}}$ $\quad\quad$ $a_n = \dfrac{1}{2}\left(1 + \dfrac{1}{3^{n-1}}\right)$ $\quad$ ⑦

④に⑦を代入して

$$\frac{1}{2}\left(1 + \frac{1}{3^{n-1}}\right) + b_n = 1 \quad\quad b_n = 1 - \frac{1}{2}\left(1 + \frac{1}{3^{n-1}}\right) = \frac{1}{2}\left(1 - \frac{1}{3^{n-1}}\right)$$
