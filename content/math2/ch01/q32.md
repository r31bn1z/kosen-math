### (1)
$$\sum_{n=1}^{10} f_{(n)} = \sum_{n=1}^{9} n + f_{(10)} = \frac{9(9+1)}{2} + (1+0) = \frac{9\cdot 10}{2} + 1 = 46$$

### (2)
$$\sum_{n=1}^{100} f_{(n)} = \sum_{n=1}^{9} n + \sum_{n=10}^{99} f_{(n)} + f_{(100)}$$

ここで $\displaystyle\sum_{n=10}^{99} f_{(n)} = f_{(10)} + f_{(11)} + f_{(12)} + \cdots + f_{(98)} + f_{(99)} = (1+0) + (1+1) + (1+2) + \cdots + (9+8) + (9+9)$

$$= \sum_{n=1}^{9} n \times (10+9) \quad \text{から}$$

$$\sum_{n=1}^{100} f_{(n)} = \sum_{n=1}^{9} n + 19\sum_{n=1}^{9} n + (1+0+0) = 20\sum_{n=1}^{9} n + 1 = 20 \times \frac{9(9+1)}{2} + 1 = 901$$

### (3)
$$\sum_{n=1}^{10^k} f_{(n)} = \sum_{n=1}^{9} f_{(n)} + \sum_{n=10}^{99} f_{(n)} + \sum_{n=100}^{999} f_{(n)} + \cdots + \sum_{n=10^{k-1}}^{10^{k}} f_{(n)}$$

$$= \sum_{n=1}^{9} n + 19\sum_{n=1}^{9} n + (1+0+0)+(1+0+1)+\cdots+(9+9+8)+(9+9+9)+\cdots+\sum_{n=10^{k-1}}^{10^{k}} f_{(n)}$$

$$= \sum_{n=1}^{9} n + 19\sum_{n=1}^{9} n + (100+9\times 20)\sum_{n=1}^{9} n + \cdots + (1+0+0+\cdots+0)$$

$$= 300\sum_{n=1}^{9} n + \cdots + 1 = k \times 10^{k-1} \times \sum_{n=1}^{9} n + 1 = k \cdot 10^{k-1} \cdot \frac{9(9+1)}{2} + 1 = 45k \cdot 10^{k-1} + 1$$
