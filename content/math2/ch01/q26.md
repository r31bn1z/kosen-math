### (1)
階差数列 $b_n$ の一般式は

$$b_n = 2n$$

よってこの数列の一般項 $a_n$ は $a_1 = 2$ より

$$a_n = a_1 + \sum_{k=1}^{n-1} b_k = 2 + \sum_{k=1}^{n-1} 2k = 2 + 2 \cdot \frac{(n-1) \cdot n}{2} = n^2 - n + 2$$

また、第n項までの総和は

$$S = \sum_{k=1}^{n} (k^2 - k + 2) = \frac{n(n+1)(2n+1)}{6} - \frac{n(n+1)}{2} + 2n$$

$$= \frac{n}{6}\{(n+1)(2n+1-3)+12\} = \frac{n(2n^2-2n+2n-2+12)}{6} = \frac{n(2n^2+10)}{6}$$

$$= \frac{n(n^2+5)}{3}$$

### (2)
階差数列 $b_n$ の一般項は、初項 $b_1 = 12$、公差 $d = 6$ より

$$b_n = 6 + 6n$$

よってこの数列の一般項 $a_n$ は $a_1 = 5$ より

$$a_n = a_1 + \sum_{k=1}^{n-1} (6+6k) = 5 + 6(n-1) + 6 \cdot \frac{(n-1) \cdot n}{2} = 5 + 6n - 6 + 3n^2 - 3n = 3n^2 + 3n - 1$$

また、第n項までの和Sは

$$S = \sum_{k=1}^{n} (3k^2+3k-1) = 3 \cdot \frac{n(n+1)(2n+1)}{6} + 3 \cdot \frac{n(n+1)}{2} - n$$

$$= \frac{1}{2}n\{(n+1)(2n+1+3)-2\} = \frac{1}{2}n\{(n+1)(2n+4)-2\} = \frac{1}{2}n(2n^2+4n+2n+4-2)$$

$$= \frac{1}{2}n(2n^2+6n+2) = n(n^2+3n+1)$$

### (3)
階差数列の階差数列$C_n$は

$$C_n = n$$

これより階差数列$b_n$は$b_1 = 1$より

$$b_n = b_1 + \sum_{k=1}^{n-1} C_k = 1 + \sum_{k=1}^{n-1} k = 1 + \frac{(n-1)\cdot n}{2} = \frac{1}{2}(n^2 - n + 2)$$

よってこの数列の一般項$a_n$は

$$a_n = a_1 + \sum_{k=1}^{n-1} b_k = 1 + \sum_{k=1}^{n-1} \frac{1}{2}(k^2 - k + 2) = 1 + \frac{1}{2}\cdot\frac{(n-1)\cdot n\cdot(2n-1)}{6} - \frac{1}{2}\cdot\frac{(n-1)\cdot n}{2} + (n-1)$$

$$= \frac{1}{12}n\{(n-1)(2n-1-3)+12\} = \frac{1}{12}n\{(n-1)(n-2)\cdot 2+12\} = \frac{1}{6}n(n^2-3n+2+6)$$

$$= \frac{n(n^2-3n+8)}{6}$$

また、第n項までの和Sは

$$S = \sum_{k=1}^{n} \frac{k(k^2-3k+8)}{6} = \frac{1}{6}\sum_{k=1}^{n} (k^3 - 3k^2 + 8k)$$

$$= \frac{1}{6}\left\{\frac{n^2(n+1)^2}{4} - 3\cdot\frac{n(n+1)(2n+1)}{6} + 8\cdot\frac{n(n+1)}{2}\right\}$$

$$= \frac{1}{24}n(n+1)(n^2+n-4n-2+16) = \frac{n(n+1)(n^2-3n+14)}{24}$$
