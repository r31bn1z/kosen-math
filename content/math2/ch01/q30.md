$$\sum_{k=1}^{n} kx^k = S_n$$ とおくと

$$S_n = x + 2x^2 + 3x^3 + \cdots + (n-1)x^{n-1} + nx^n$$ この両辺に $x$ をかけて

$$xS_n = x^2 + 2x^3 + 3x^4 + \cdots + (n-1)x^n + nx^{n+1}$$

$$S_n - xS_n = (1-x)S_n = x + x^2 + x^3 + \cdots + x^n - nx^{n+1} = \frac{x(1-x^n)}{1-x} - nx^{n+1}$$

$$S_n = \frac{x(1-x^n) - nx^{n+1}(1-x)}{(1-x)^2} = \frac{x\{1-(n+1)x^n + nx^{n+1}\}}{(1-x)^2}$$
