### (1)
$$(\text{左辺}) = Ca^{n+2}+Db^{n+2}-(a+b)(Ca^{n+1}+Db^{n+1})+ab(Ca^n+Db^n)$$

$$= Ca^{n+2}+Db^{n+2}-(Ca^{n+2}+Dab^{n+1}+Ca^{n+1}b+Db^{n+2})+Ca^{n+1}b+Dab^{n+1}=0$$

### (2)
(1)より $x_n = Ca^n+Db^n$ とおく。

$x_0 = p$ を代入すると $x_0 = p = Ca^0+Db^0 = C+D$ ①

$x_1 = q$ を代入すると $x_1 = q = Ca^1+Db^1$ ②

①より $D = p-C$ ①' これを②に代入して

$$q = Ca+(p-C)b \qquad q-pb = C(a-b) \qquad C = \dfrac{q-pb}{a-b}$$ これを①'に代入して

$$D = p-\dfrac{q-pb}{a-b} = \dfrac{ap-q}{a-b}$$

$C,D$ を $x_n = Ca^n+Db^n$ の式に代入すると

$$x_n = \dfrac{q-bp}{a-b}a^n + \dfrac{ap-q}{a-b}b^n$$

但し、$a=b$ の時 $x_n = (C+D)a^n$

$$C+D = \dfrac{q-bp}{a-b}+\dfrac{ap-q}{a-b} = \dfrac{p(a-b)}{a-b} = p$$ より $x_n = pa^n$

### (3)
$a=-6$、$b=-5$、$p=q=1$として(2)で出した式へ代入すると

$$x_n = \dfrac{q-bp}{a-b}a^n + \dfrac{ap-q}{a-b}b^n = \dfrac{1-(-5)\cdot1}{-6-(-5)}(-6)^n + \dfrac{-6\cdot1-1}{-6-(-5)}(-5)^n = -6\cdot(-6)^n+7\cdot(-5)^n$$

$$= (-6)^{n+1}+7\cdot(-5)^n$$
