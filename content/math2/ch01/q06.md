### (1)
初項 $a = 12$、$d = 3$ とし、第 n 項 $l$ は $l = 99$ とする

$$a_n = a + (n-1)d = 12 + (n-1) \cdot 3 = 3n + 9$$

この式に $a_n = l = 99$ を代入すると

$$99 = 3n + 9 \qquad n = 30$$

よって 30 項までの和を求めればよいので

$$S_{30} = \frac{n(a+l)}{2} = \frac{30(12+99)}{2} = 1665$$

### (2)
初項 $a = 10$、$d = 5$ とし、第 n 項 $l$ は $l = 95$ とする

$$a_n = a + (n-1)d = 10 + (n-1) \cdot 5 = 5n + 5$$

この式に $a_n = l = 95$ を代入すると

$$95 = 5n + 5 \qquad n = 18$$

よって 18 項までの和を求めればよいので

$$S_{18} = \frac{n(a+l)}{2} = \frac{18(10+95)}{2} = 945$$

### (3)
3 と 5 両方の倍数である数は 15 の倍数であるので

初項 $a = 15$、$d = 15$ とし、第 n 項 $l$ は $l = 90$ とする

$$a_n = a + (n-1)d = 15 + (n-1) \cdot 15 = 15n$$

この式に $a_n = l = 90$ を代入すると

$$90 = 15n \qquad n = 6$$

よって 6 項までの和を求めればよいので

$$S_6 = \frac{n(a+l)}{2} = \frac{6(15+90)}{2} = 315$$

### (4)
3 と 5 の倍数のそれぞれの和から重複する 15 の倍数を引けばよいので

$$1665 + 945 - 315 = 2295$$

### (5)
２けたの自然数の合計は

$$\sum_{n=10}^{99} n = \sum_{n=1}^{99} n - \sum_{n=1}^{9} n = \frac{99(99+1)}{2} - \frac{9(9+1)}{2} = 4905$$

この値から３または５の倍数の和を引けばよいので

$$4905 - 2295 = 2610$$
