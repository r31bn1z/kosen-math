### (1)
$$2axy + 3a^2y = ay(2x + 3a)$$

### (2)
$$4a^3 - 2a^2b = 2a^2(2a - b)$$

### (3)
$$3x^3 - 2x^2y + xy^2 = x(3x^2 - 2xy + y^2)$$

### (4)
$$a^2b + abc - a^2c = a(ab + bc - ac)$$

### (5)
$$xyz - yz^2 + 2xy^2 = y(xz - z^2 + 2xy)$$

### (6)
$$a^2b + a^2c - ab^2 - b^2c = ab(a - b) + c(a^2 - b^2) = ab(a - b) + c(a - b)(a + b) = (a - b)(ab + bc + ca)$$
