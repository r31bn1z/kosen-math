### (1)
$$-2x^2y^3$$

x と y の整式と考えた場合 次数 5 係数−2

x の整式と考えた場合 次数 2 係数$-2y^3$

### (2)
$$x^2 - 3xy + 5y^2$$

x と y の整式と考えた場合 次数 2 係数1、−3、5

x の整式と考えた場合 次数 2 係数1、−3y、$5y^2$

### (3)
$$x^3y + 2x^2y^2 - 3y^4$$

x と y の整式と考えた場合 次数 4 係数1、2、−3

x の整式と考えた場合 次数 3 係数 y、$2y^2$、$-3y^4$
