$$\dfrac{A}{x^2+x+1} = \alpha \text{ 余り } (2x+1)$$ とすると

$$A = \alpha(x^2+x+1) + (2x+1)$$ と書けるので

$$\dfrac{A}{x^2+x+1} = \alpha + \dfrac{2x+1}{x^2+x+1}$$    $(2x+1)$は$(x^2+x+1)$でさらに割ることは出来ない

同様に

$$B = \beta(x^2+x+1) + (5x-3)$$

### (1)

$$3A = 3\{\alpha(x^2+x+1)+(2x+1)\} = 3\alpha(x^2+x+1)+3(2x+1)$$

これから余りは$6x+3$

### (2)

$$A+B = \alpha(x^2+x+1)+(2x+1)+\beta(x^2+x+1)+(5x-3) = (\alpha+\beta)(x^2+x+1)+(2x+1+5x-3)$$

これから余りは$7x-2$

### (3)

$$A-B = \alpha(x^2+x+1)+(2x+1)-\{\beta(x^2+x+1)+(5x-3)\} = (\alpha-\beta)(x^2+x+1)+(2x+1-5x+3)$$

これから余りは$-3x+4$

### (4)

$$AB = \{\alpha(x^2+x+1)+(2x+1)\}\{\beta(x^2+x+1)+(5x-3)\}$$

$$= \alpha\beta(x^2+x+1)^2 + \{(5x-3)\alpha+(2x+1)\beta\}(x^2+x+1) + (2x+1)(5x-3)$$

これから余りは$(2x+1)(5x-3) = 10x^2-x-3$となるがこれは$(x^2+x+1)$でまだ割ることが出来る

（イメージとしては $7 \div 2 = 2$ 余り $3$ としているようなもの）

$$\dfrac{10x^2-x-3}{x^2+x+1} = 10 + \dfrac{-11x-13}{x^2+x+1}$$ となり

$$AB = \alpha\beta(x^2+x+1)^2 + \{(5x-3)\alpha+(2x+1)\beta\}(x^2+x+1) + 10(x^2+x+1) + (-11x-13)$$

これから余りは$-11x-13$
