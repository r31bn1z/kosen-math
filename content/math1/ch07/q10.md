### (1)
$$x^3 = -1 \qquad x^3 + 1 = 0 \qquad (x+1)(x^2-x+1) = 0 \qquad x = -1, \frac{1 \pm \sqrt{1-4}}{2} \qquad x = -1, \frac{1 \pm \sqrt{3}i}{2}$$

### (2)
$$x^3 = 8 \qquad x^3 - 8 = 0 \qquad (x-2)(x^2+2x+4) = 0 \qquad x = 2, -1 \pm \sqrt{1-4} \qquad x = 2, -1 \pm \sqrt{3}i$$

### (3)
$$x^4 - 1 = 0 \qquad (x^2-1)(x^2+1) = 0 \qquad (x-1)(x+1)(x^2+1) = 0 \qquad x = \pm1, \pm i$$
