$$f(x) = G_1(x)(x - \alpha) + m$$

$$f(x) = G_2(x)(x^2 - \beta) + px + q$$

$x = \alpha, \pm\sqrt{\beta}$ のとき$f(x)$はそれぞれ

$$f(\alpha) = m$$

$$f(\sqrt{\beta}) = \sqrt{\beta} \cdot p + q$$

$$f(-\sqrt{\beta}) = -\sqrt{\beta} \cdot p + q$$

$f(x)$を$(x-\alpha)(x^2-\beta)$で割ったときの余りは２次関数となるので、これを $ax^2 + bx + c$ と置くと

$$f(x) = G_3(x)(x - \alpha)(x^2 - \beta) + ax^2 + bx + c$$

$x = \alpha, \pm\sqrt{\beta}$ のとき$f(x)$はそれぞれ

$$f(\alpha) = a\alpha^2 + b\alpha + c = m \qquad ①$$

$$f(\sqrt{\beta}) = a\beta + b\sqrt{\beta} + c = \sqrt{\beta} \cdot p + q \qquad ②$$

$$f(-\sqrt{\beta}) = a\beta - b\sqrt{\beta} + c = -\sqrt{\beta} \cdot p + q \qquad ③$$

①、②、③から$a, b, c$を求めると

$$a = \frac{m - q - p\alpha}{\alpha^2 - \beta} \qquad b = p \qquad c = \frac{p\alpha\beta + q\alpha^2 - m\beta}{\alpha^2 - \beta}$$

となる。これから

$\alpha^2 \neq \beta$ のとき

$$\frac{m - q - p\alpha}{\alpha^2 - \beta}x^2 + px + \frac{p\alpha\beta + q\alpha^2 - m\beta}{\alpha^2 - \beta}$$

$\alpha^2 = \beta$ かつ $m = p\alpha + q$ のとき $kx^2 + px + q - k\beta$ ($k$は任意)

$\alpha^2 = \beta$ かつ $m \neq p\alpha + q$ のとき 解なし
