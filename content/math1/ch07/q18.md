$$ax^2 + bx + c = 0$$

$$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

### (1)

$$a + c = 0 \qquad a = -c \qquad \text{これから}$$

$$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \dfrac{-b \pm \sqrt{b^2 + 4c^2}}{2a} \qquad b^2 + 4c^2 \geq 0 \quad \text{なので} x \text{は実数解を持つ}$$

### (2)

$$b = a + c$$

$$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \dfrac{-b \pm \sqrt{(a+c)^2 - 4ac}}{2a} = \dfrac{-b \pm \sqrt{a^2 + 2ac + c^2 - 4ac}}{2a} = \dfrac{-b \pm \sqrt{a^2 - 2ac + c^2}}{2a}$$

$$= \dfrac{-b \pm \sqrt{(a-c)^2}}{2a} = \dfrac{-b \pm (a-c)}{2a} \qquad \text{これから} x \text{は実数解を持つ}$$
