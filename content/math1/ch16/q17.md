（問題集解答の変数を使用）

点A(a,a') 点B(b,b')とする

円の接線の方程式は$x_0 x + y_0 y = r^2$なので

点Pを通り点Aで円と接する接線の方程式は $ax_1 + a'y_1 = r^2$ ①

点Pを通り点Bで円と接する接線の方程式は $bx_1 + b'y_1 = r^2$ ②

①－②から  $(a-b)x_1 + (a'-b')y_1 = 0$  $\dfrac{a'-b'}{a-b} = -\dfrac{x_1}{y_1}$

点A,点Bを通る直線の方程式は $y = \dfrac{a'-b'}{a-b}x + C = -\dfrac{x_1}{y_1}x + C$

Cは点この直線が点Aを通ることから  $a' = -\dfrac{x_1}{y_1}a + C$  $C = \dfrac{a'y_1+ax_1}{y_1} = \dfrac{r^2}{y_1}$

これから

$$y = -\dfrac{x_1}{y_1}x + \dfrac{r^2}{y_1}\qquad x_1x + y_1y = r^2$$
