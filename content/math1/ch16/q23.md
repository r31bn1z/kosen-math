直線の方程式は$y = ax + b$ 点$(3,4)$を通るので $y = a(x-3) + 4$

$y^2 = 4x$ $x = \dfrac{y^2}{4}$ これを直線の式に代入すると

$$y = a\left(\dfrac{y^2}{4} - 3\right) + 4$$

$$y^2 - \dfrac{4}{a}y + 16 - 12a = 0$$

この方程式の解を$\alpha, \beta$とおくと

$(y - \alpha)(y - \beta) = 0$

$$y^2 - (\alpha + \beta)y + \alpha\beta = 0$$

これから $\alpha + \beta = \dfrac{4}{a}$ よって AB の中点の$y = \dfrac{\alpha + \beta}{2} = \dfrac{2}{a}$ $a = \dfrac{2}{y}$

$y = a(x-3) + 4 = \dfrac{2}{y}(x - 3) + 4$  $y^2 = 2x - 6 + 4y$  $y^2 - 4y = 2x - 6$
