楕円の $x$ 軸との交点は $(\pm\sqrt{2}, 0)$

楕円上のある点を $\left(n, \sqrt{1-\dfrac{n^2}{2}}\right)$ と考えると、定点 $A(a, 0)$ との距離 $h$ は

$$h = \sqrt{(n-a)^2 + \left(\sqrt{1-\dfrac{n^2}{2}} - 0\right)^2} = \sqrt{(n-a)^2+1-\dfrac{n^2}{2}} = \sqrt{n^2-2an+a^2+1-\dfrac{n^2}{2}} = \sqrt{\dfrac{n^2}{2}-2an+a^2+1}$$

$$= \sqrt{\dfrac{1}{2}(n^2-4an+2a^2)+1} = \sqrt{\dfrac{1}{2}(n-2a)^2-a^2+1}$$

$g = h^2 = \dfrac{1}{2}(n-2a)^2-a^2+1$ とすると

$g' = n-2a$ $g'=0$ のとき $n-2a=0$ $n=2a$ よって $n=2a$ のとき $g$ は最小値をとり、

$h$ も最小となる

$-\sqrt{2} \le n \le \sqrt{2}$ から $-\sqrt{2} \le 2a \le \sqrt{2}$ $-\dfrac{\sqrt{2}}{2} \le a \le \dfrac{\sqrt{2}}{2}$

この範囲では $n=2a$ を成り立たせることが出来るので

$$h = \sqrt{\dfrac{1}{2}(2a-2a)^2-a^2+1} = \sqrt{-a^2+1}$$ $-\dfrac{\sqrt{2}}{2}\le a \le \dfrac{\sqrt{2}}{2}$ から $a^2 \le \dfrac{1}{2}$ となり1より小さいので

$$=\sqrt{1-a^2}$$ が最小値となる

$-\sqrt{2}\le 2a \le \sqrt{2}$ 以外の範囲、つまり $2a<-\sqrt{2}$ $\sqrt{2}<2a$ では $n=2a$ を満足できないので

$2a<-\sqrt{2}$ $a<-\dfrac{\sqrt{2}}{2}$ のとき $n=-\sqrt{2}$ とすれば $(n-2a)^2$ の部分を最も小さくすることが出来る

このとき $h = \sqrt{\dfrac{1}{2}(-\sqrt{2}-2a)^2-a^2+1} = \sqrt{\dfrac{1}{2}(2+4\sqrt{2}a+4a^2)-a^2+1} = \sqrt{a^2+2\sqrt{2}a+2}$

$$=\sqrt{(\sqrt{2}+a)^2}=|\sqrt{2}+a|$$ が最小となる

同様に $2a>\sqrt{2}$ $a>\dfrac{\sqrt{2}}{2}$ のとき $n=\sqrt{2}$ とすれば $(n-2a)^2$ の部分を最も小さくすることが出来る

このとき $h = \sqrt{\dfrac{1}{2}(\sqrt{2}-2a)^2 - a^2 + 1} = \sqrt{\dfrac{1}{2}(2-4\sqrt{2}a+4a^2) - a^2 + 1} = \sqrt{a^2 - 2\sqrt{2}a + 2}$

$$= \sqrt{(-a+\sqrt{2})^2} = |\sqrt{2}-a|$$ が最小となる
