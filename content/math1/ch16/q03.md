### (1)
直線の方程式を円の方程式に代入して

$$x^2 + (-2x+5)^2 = 25 \qquad x^2 + 4x^2 - 20x + 25 = 25 \qquad 5x^2 - 20x = 0 \qquad 5x(x-4) = 0$$

$$x = 0, 4$$

$x = 0$のとき$y = 5$  $(0,5)$

$x = 4$のとき$y = -3$  $(4,-3)$

### (2)
直線の方程式を円の方程式に代入して

$$x^2 + (x+3)^2 - 6x + 4(x+3) - 37 = 0$$

$$x^2 + x^2 + 6x + 9 - 6x + 4x + 12 - 37 = 0$$

$$2x^2 + 4x - 16 = 0 \qquad x^2 + 2x - 8 = 0 \qquad (x+4)(x-2) = 0 \qquad x = -4, 2$$

$x = -4$のとき$y = -1$  $(-4,-1)$

$x = 2$のとき$y = 5$  $(2,5)$
