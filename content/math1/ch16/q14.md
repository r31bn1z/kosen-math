$$x^2 + y^2 + 6x - 4y - 21 = 0 \qquad (x+3)^2 + (y-2)^2 - 13 - 21 = 0 \qquad (x+3)^2 + (y-2)^2 = 34$$

接線の方程式は

円の中心が原点の場合$x^2 + y^2 = r^2$ → $x_0 x + y_0 y = r^2$ （問題集 p.88）

円の中心が原点ではない場合$(x+a)^2 + (y+b)^2 = r^2$ →
$$(x+a)(x_0+a) + (y+b)(y_0+b) = r^2$$

これから与式の接線の方程式は

点$(2,5)$  $(x+3)(2+3) + (y-2)(5-2) = 34$  $5x + 3y - 25 = 0$

点$(-8,-1)$  $(x+3)(-8+3) + (y-2)(-1-2) = 34$  $5x + 3y + 43 = 0$

円 $x^2 + y^2 + 6x - 4y - 21 = 0$ の接線の接線を $y = \dfrac{dy}{dx}x + b$ とすると

円の式を微分して $2x + 2y\dfrac{dy}{dx} + 6 - 4\dfrac{dy}{dx} = 0$ $\dfrac{dy}{dx}(y-2) + (x+3) = 0$

$$\frac{dy}{dx} = -\frac{x+3}{y-2}$$

$(2,5)$ を通るとき $\dfrac{dy}{dx} = -\dfrac{2+3}{5-2} = -\dfrac{5}{3}$ よって接線の方程式は

$$y = -\frac{5}{3}x + b \qquad (2,5) \text{を通るので} \qquad 5 = -\frac{5}{3}\cdot 2 + b \qquad b = \frac{25}{3}$$

よって $y = -\dfrac{5}{3}x + \dfrac{25}{3}$ $\therefore 5x + 3y - 25 = 0$

$(-8,-1)$ を通るとき $\dfrac{dy}{dx} = -\dfrac{-8+3}{-1-2} = -\dfrac{5}{3}$ よって接線の方程式は

$$y = -\frac{5}{3}x + b \qquad (-8,-1) \text{を通るので} \qquad -1 = -\frac{5}{3}\cdot(-8) + b \qquad b = -\frac{43}{3}$$

よって $y = -\dfrac{5}{3}x - \dfrac{43}{3}$ $\therefore 5x + 3y + 43 = 0$
