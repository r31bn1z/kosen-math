### (1)
問題集 p.89 双曲線より

$(6,0), (-6,0)$殻の距離の差が$8$なので

$$b = \sqrt{6^2 - 4^2} = \sqrt{20}$$

$$\frac{x^2}{16} - \frac{y^2}{20} = 1$$

### (2)
$$\sqrt{(3-5)^2 + (-4)^2} = \sqrt{20} = 2\sqrt{5}$$

$$\sqrt{(-3-5)^2 + (-4)^2} = \sqrt{80} = 4\sqrt{5}$$

距離の差は$2\sqrt{5}$

$$a = \sqrt{5} \qquad c = 3 \qquad b = \sqrt{9-5} = 2$$

$$\frac{x^2}{5} - \frac{y^2}{4} = 1$$

### (3)
漸近線が$y = \pm 2x$なので $b = 2a$ である

$$\frac{x^2}{a^2} - \frac{y^2}{4a^2} = 1 \qquad (1,0)\text{を通るので} \qquad \frac{1}{a^2} = 1 \qquad a = \pm 1 \qquad b = \pm 2$$

これから $$\frac{x^2}{1} - \frac{y^2}{4} = 1$$

### (4)
点$(0,4)$を通ると仮定する

焦点が$y$軸上にあるので一般形は

$$-\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$
となる

$$\sqrt{(5-4)^2} = 1$$

$$\sqrt{(-5-4)^2} = 9$$

距離の差は$8$

$a = 4$ $c = 5$ $b = 3$ となるので

$$-\frac{x^2}{16} + \frac{y^2}{9} = 1$$
