円上の点$(x_0, y_0)$における接線の方程式は $x_0 x + y_0 y = 3$

$$y = -\frac{x_0}{y_0}x + \frac{3}{y_0} = mx + \frac{3}{y_0}$$  これから $m = -\dfrac{x_0}{y_0}$

点$(3,4)$を通るので $3x_0 + 4y_0 = 3$ $3\dfrac{x_0}{y_0} + 4 = \dfrac{3}{y_0}$ $-3m + 4 = \dfrac{3}{y_0}$ $y_0 = \dfrac{3}{-3m+4}$

円上の点$(x_0, y_0)$において $x_0^2 + y_0^2 = 3$ $\dfrac{x_0^2}{y_0^2} + 1 = \dfrac{3}{y_0^2}$ $m^2 + 1 = \dfrac{3}{y_0^2}$

この２式から

$$m^2 + 1 = \frac{3}{\left(\dfrac{3}{-3m+4}\right)^2}$$  $3m^2 + 3 = (-3m+4)^2$  $3m^2 + 3 = 9m^2 - 24m + 16$

$$6m^2 - 24m + 13 = 0$$

$$m = \frac{12 \pm \sqrt{144-78}}{6} = \frac{12 \pm \sqrt{66}}{6}$$

傾きの積は$\dfrac{12+\sqrt{66}}{6} \times \dfrac{12-\sqrt{66}}{6} = \dfrac{144-66}{36} = \dfrac{78}{36} = \dfrac{13}{6}$
