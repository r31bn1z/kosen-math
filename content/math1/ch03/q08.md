### (1)
$3x + 4y = 12 \qquad y = 3 - \dfrac{3}{4}x$ となる

ここで$Z = xy$ として 上式を代入すると

$$Z = x\left(3 - \dfrac{3}{4}x\right) = -\dfrac{3}{4}x^2 + 3x = -\dfrac{3}{4}(x^2 - 4x) = -\dfrac{3}{4}\{(x-2)^2 - 4\} = -\dfrac{3}{4}(x-2)^2 + 3$$

この関数は上に凸なので

これから$x = 2$ の時 最大値$3$

### (2)
$x - y = 2 \qquad y = x - 2$ となる

ここで$Z = x^2 + y^2$ として 上式を代入すると

$$Z = x^2 + (x-2)^2 = x^2 + x^2 - 4x + 4 = 2x^2 - 4x + 4 = 2(x^2 - 2x + 2) = 2\{(x-1)^2 + 1\} = 2(x-1)^2 + 2$$

この関数は下に凸なので

これから$x = 1$ のとき 最小値$2$

### (3)
$2x + 3y = 5 \qquad y = \dfrac{1}{3}(5 - 2x)$ となる

ここで$Z = 4x^2 + y^2$として 上式を代入すると

$$Z = 4x^2 + \left\{\dfrac{1}{3}(5-2x)\right\}^2 = 4x^2 + \dfrac{1}{9}(25 - 20x + 4x^2) = \dfrac{1}{9}(36x^2 + 25 - 20x + 4x^2) = \dfrac{1}{9}(40x^2 - 20x + 25)$$

$$= \dfrac{5}{9}(8x^2 - 4x + 5) = \dfrac{40}{9}\left(x^2 - \dfrac{1}{2}x + \dfrac{5}{8}\right) = \dfrac{40}{9}\left\{\left(x - \dfrac{1}{4}\right)^2 + \dfrac{9}{16}\right\} = \dfrac{40}{9}\left(x - \dfrac{1}{4}\right)^2 + \dfrac{5}{2}$$

この関数は下に凸なので

これから $x = \dfrac{1}{4}$のとき 最小値$\dfrac{5}{2}$
