### (1)

$$y = 3x^2 + px + q = 3\left(x^2 + \frac{p}{3}x\right) + q = 3\left(x + \frac{p}{6}\right)^2 - \frac{p^2}{12} + q$$

x=1 で最小値５となるので

$$\frac{p}{6} = -1 \qquad p = -6$$

$$-\frac{p^2}{12} + q = -3 + q = 5 \qquad q = 8$$

これから$p = -6$、$q = 8$

### (2)

$$y = px^2 + x + q = p\left(x^2 + \frac{1}{p}x\right) + q = p\left(x + \frac{1}{2p}\right)^2 - \frac{1}{4p} + q$$

$x = 2$ で最大値１となるので

$$\frac{1}{2p} = -2 \qquad p = -\frac{1}{4}$$

$$-\frac{1}{4p} + q = 1 + q = 1 \qquad q = 0$$

これから $p = -\dfrac{1}{4}$、$q = 0$
