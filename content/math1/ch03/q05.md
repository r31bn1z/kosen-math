（グラフについては p.110 の解答の通り）

### (1)

$$y = x^2 - 4x + 5 = (x-2)^2 + 1$$

これから頂点は$(2, 1)$

### (2)

$$y = x(x-2) = x^2 - 2x = (x-1)^2 - 1$$

これから頂点は$(1, -1)$

### (3)

$$y = -x^2 + 2x + 1 = -(x-1)^2 + 2$$

これから頂点は$(1, 2)$

### (4)

$$y = -3x^2 + 12x = -3(x^2 - 4x) = -3(x-2)^2 + 12$$

これから頂点は$(2, 12)$

### (5)

$$y = -x^2 + x + 1 = -\left(x - \frac{1}{2}\right)^2 + \frac{5}{4}$$

これから頂点は$\left(\dfrac{1}{2}, \dfrac{5}{4}\right)$

### (6)

$$y = 5 - 2x^2 = -2x^2 + 5$$

これから頂点は$(0, 5)$

### (7)

$$y = 2(x-1)(x+3) = 2(x^2 + 2x - 3) = 2\{(x+1)^2 - 4\} = 2(x+1)^2 - 8$$

これから頂点は$(-1, -8)$

### (8)

$$y = -x^2 - 4x - 4 = -(x+2)^2$$

これから頂点は$(-2, 0)$
