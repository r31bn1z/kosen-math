### (1)
$$y = x^2 - 4x = (x-2)^2 - 4$$

これから頂点は$(2, -4)$

また、このグラフは下に凸なので $x=2$のとき最小値$-4$

### (2)
$$y = x^2 + 3x + 2 = \left(x + \frac{3}{2}\right)^2 - \frac{1}{4}$$

これから頂点は$\left(-\frac{3}{2}, -\frac{1}{4}\right)$

また、このグラフは下に凸なので $x = -\frac{3}{2}$のとき最小値$-\frac{1}{4}$

### (3)
$$y = -2x^2 + 4x + 1 = -2(x-1)^2 + 3$$

これから頂点は$(1,3)$

また、このグラフは上に凸なので $x = 1$のとき最大値$3$

### (4)
$$y = 3 + 4x - 6x^2 = -6\left(x^2 - \frac{2}{3}x\right) + 3 = -6\left(x - \frac{1}{3}\right)^2 + \frac{11}{3}$$

これから頂点は$\left(\frac{1}{3}, \frac{11}{3}\right)$

また、このグラフは上に凸なので $x = \frac{1}{3}$のとき最大値$\frac{11}{3}$

### (5)
$$y = (x-1)(x+3) = x^2 + 2x - 3 = (x+1)^2 - 4$$

これから頂点は$(-1, -4)$

また、このグラフは下に凸なので $x = -1$のとき最小値$-4$

### (6)

$$y = 3x^2 + x - 2 = 3\left(x^2 + \frac{1}{3}x\right) - 2 = 3\left(x + \frac{1}{6}\right)^2 - \frac{25}{12}$$

これから頂点は $\left(-\dfrac{1}{6}, -\dfrac{25}{12}\right)$

また、このグラフは下に凸なので $x = -\dfrac{1}{6}$ のとき最小値 $-\dfrac{25}{12}$
