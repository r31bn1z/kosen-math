### (1)
頂点が$(1,2)$なので

$$y = a(x-1)^2 + 2$$

また$(0,6)$を通るので代入すると

$$6 = a + 2 \qquad a = 4$$

これから $y = 4(x-1)^2 + 2$

### (2)
点$(-1,2)$を通り軸が$x=-1$なのでこれは頂点である

$$y = a(x+1)^2 + 2$$

点$(1,-2)$を通るので

$$-2 = 4a + 2 \qquad a = -1$$

これから $y = -(x+1)^2 + 2$

### (3)
$x=-1$が軸で$x$軸上に頂点があるので頂点は$(-1,0)$である

$$y = a(x+1)^2$$

$(0,4)$を通るので

$$4 = a$$

これから $y = 4(x+1)^2$

### (4)
$y = ax^2 + bx + c$とおくと

$$6 = a - b + c \qquad ①$$
$$0 = a + b + c \qquad ②$$
$$2 = 9a + 3b + c \qquad ③$$

①－②から $6 = -2b \qquad b = -3$

$$3 = a + c \qquad ④$$
$$11 = 9a + c \qquad ⑤$$

④－⑤から$-8 = -8a \qquad a = 1$

これらを②に代入して

$$0 = 1 - 3 + c \qquad c = 2$$

よって $y = x^2 - 3x + 2$
