### (1)

$$\cos^2 x + 4\sin x = 1 - \sin^2 x + 4\sin x = -(\sin x - 2)^2 + 5$$

$-(\sin x - 2)^2 < 0$ なので

与式の最大値は$(\sin x - 2)^2$が最小の時であり $\sin x = 1$ となる このとき最大値$4$

与式の最小値は$(\sin x - 2)^2$が最大の時であり $\sin x = -1$ となる このとき最小値$-4$

### (2)

$$\sin^2 x - 3\sin x = \left(\sin x - \frac{3}{2}\right)^2 - \frac{9}{4}$$

$\left(\sin x - \dfrac{3}{2}\right)^2 > 0$ なので

与式の最大値は$\left(\sin x - \dfrac{3}{2}\right)^2$が最大の時であり $\sin x = -1$ となる このとき最大値$4$

与式の最小値は$\left(\sin x - \dfrac{3}{2}\right)^2$が最小の時であり $\sin x = 1$ となる このとき最小値$-2$

### (3)

$$2\sin x + \cos 2x = 2\sin x + 1 - 2\sin^2 x = -2(\sin^2 x - \sin x) + 1 = -2\left(\sin x - \frac{1}{2}\right)^2 + \frac{3}{2}$$

$-2\left(\sin x - \dfrac{1}{2}\right)^2 \leq 0$ なので

与式の最大値は$\left(\sin x - \dfrac{1}{2}\right)^2$が最小の時であり $\sin x = \dfrac{1}{2}$ となる このとき最大値$\dfrac{3}{2}$

与式の最小値は$\left(\sin x - \dfrac{1}{2}\right)^2$が最大の時であり $\sin x = -1$ となる このとき最小値$-3$

### (4)

$$\sin^2 x + \sin 2x = \frac{1}{2} - \frac{1}{2}\cos 2x + \sin 2x = \frac{1}{2} - \frac{\sqrt{5}}{2}\cos(2x + \varphi)$$

与式の最大値は$\cos(2x + \varphi) = -1$ の時であり最大値$\dfrac{1+\sqrt{5}}{2}$

与式の最小値は$\cos(2x + \varphi) = 1$ の時であり最小値$\dfrac{1-\sqrt{5}}{2}$

### (5)

$$3\sin x + 4\cos x = 5\cos(x+\varphi) \qquad \varphi = -\tan^{-1}\frac{3}{4}$$

与式の最大値は $\cos(x+\varphi) = 1$ の時であり最大値 $5$

与式の最小値は $\cos(x+\varphi) = -1$ の時であり最小値 $-5$

### (6)

$$6\cos^2 x + 8\sin x \cdot \cos x = 3 + 3\cos 2x + 4\sin 2x = 3 + 5\cos(2x+\varphi)$$

与式の最大値は $\cos(2x+\varphi) = 1$ の時であり最大値 $8$

与式の最小値は $\cos(2x+\varphi) = -1$ の時であり最小値 $-2$
