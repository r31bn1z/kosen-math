### (1)

$$\sin\left(x - \frac{\pi}{3}\right)$$

周期は $2\pi$ なのでこれが $\sin$ の関数であることから最大値は $1$，最小値は $-1$ と分かる

また、この関数は x 軸方向に $\frac{\pi}{3}$ 平行移動していることから

最大値は $x = \frac{5}{6}\pi$ のとき $1$  最小値は $x = \frac{11}{6}\pi$ のとき $-1$

### (2)

$$a \cdot \sin x + b \cdot \cos x = \sqrt{a^2 + b^2}\left(\sin x \cdot \frac{a}{\sqrt{a^2+b^2}} + \frac{b}{\sqrt{a^2+b^2}} \cdot \cos x\right) = \sqrt{a^2+b^2}\cos(x-\theta) \qquad \theta = \tan^{-1}\frac{a}{b} \text{ より}$$

$$2\sin x + \sqrt{3}\cos x = \sqrt{2^2 + (\sqrt{3})^2}\cos(x-\theta) = \sqrt{7}\cos(x-\theta) \qquad \theta = \tan^{-1}\frac{2}{\sqrt{3}} = 49.1° \text{ であるので}$$

最大値は $x = 49.1°$ のときで $\sqrt{7}\cos 0° = \sqrt{7}$

最小値は $x = 180° + 49.1 = 229.1°$ のときで $\sqrt{7}\cos 180° = -\sqrt{7}$

### (3)

$$\sin x - \cos\left(x - \frac{\pi}{6}\right) = \sin x - \sin\left(x + \frac{1}{3}\pi\right) = 2\cos\left(x + \frac{\pi}{6}\right)\sin\left(-\frac{1}{6}\pi\right) = -\cos\left(x + \frac{\pi}{6}\right) = \sin\left(x - \frac{\pi}{3}\right)$$

これから

最大値は $x = \frac{5}{6}\pi$ のとき $1$  最小値は $x = \frac{11}{6}\pi$ のとき $-1$

### (4)

$$\sin x + \sin\left(x + \frac{\pi}{3}\right) = 2\sin\left(x + \frac{\pi}{6}\right)\cos\left(-\frac{\pi}{6}\right) = \sqrt{3}\sin\left(x + \frac{\pi}{6}\right)$$

これから

最大値は $x = \frac{\pi}{3}$ のときで $\sqrt{3}$  最小値は $x = \frac{4}{3}\pi$ のときで $-\sqrt{3}$

### (5)
$$\sin\left(x-\frac{\pi}{3}\right)\sin\left(x+\frac{\pi}{3}\right)=-\frac{1}{2}\left(\cos 2x-\cos\left(-\frac{2}{3}\pi\right)\right)=-\frac{1}{2}\left(\frac{1}{2}+\cos 2x\right)=-\frac{1}{4}-\frac{1}{2}\cos 2x$$

これから

最大値は $x=\dfrac{\pi}{2},\dfrac{3}{2}\pi$ のときで $\dfrac{1}{4}$  最小値は $x=0,\pi$ のときで $-\dfrac{3}{4}$
