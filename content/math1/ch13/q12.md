### (1)
$$2\sin^2 x > 1 \qquad \sin^2 x > \frac{1}{2} \qquad \sin x < -\frac{1}{\sqrt{2}} \qquad \frac{1}{\sqrt{2}} < \sin x$$

これから $\dfrac{1}{4}\pi < x < \dfrac{3}{4}\pi$  $\dfrac{5}{4}\pi < x < \dfrac{7}{4}\pi$

### (2)
$$4\cos^2 x < 1 \qquad \cos^2 x < \frac{1}{4} \qquad \cos x < -\frac{1}{2} \qquad \frac{1}{2} < \cos x$$

これから $\dfrac{1}{3}\pi < x < \dfrac{2}{3}\pi$  $\dfrac{4}{3}\pi < x < \dfrac{5}{3}\pi$

### (3)
$$\sin^2 x \geq \sin x \qquad \sin x(\sin x - 1) \geq 0 \qquad \sin x \leq 0 \qquad 1 \leq \sin x$$

これから $x = 0$  $\pi \leq x \leq 2\pi$  $x = \dfrac{\pi}{2}$

### (4)
$$\cos^2 x < \cos x \qquad \cos x(\cos x - 1) < 0 \qquad 0 < \cos x < 1$$

これから $0 < x < \dfrac{\pi}{2}$  $\dfrac{3}{2}\pi < x < 2\pi$
