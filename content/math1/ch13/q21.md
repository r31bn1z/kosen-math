### (1)

$$\sin x + \sin y = 2\sin\frac{x+y}{2}\cos\frac{x-y}{2} = 2\sin\frac{\pi}{6}\cos\left(\frac{\pi}{6}-y\right) = \cos\left(\frac{\pi}{6}-y\right)$$

これは$\cos(-y)$が$-\dfrac{\pi}{6}$平行移動しただけの$\cos$関数なので

最大値は$\cos\left(\dfrac{\pi}{6}-y\right)=1$のときで$1$

最小値は$\cos\left(\dfrac{\pi}{6}-y\right)=-1$のときで$-1$

### (2)

$$\sin x + \cos y = \sin\left(\frac{\pi}{3}-y\right) + \cos y = \sin\frac{\pi}{3}\cos y - \cos\frac{\pi}{3}\sin y + \cos y = \frac{\sqrt3}{2}\cos y - \frac12\sin y + \cos y$$

$$= -\frac12\sin y + \frac{\sqrt3+2}{2}\cos y = \sqrt{\left(-\frac12\right)^2+\left(\frac{\sqrt3+2}{2}\right)^2}\sin(y+\alpha) = \frac{\sqrt{6+4\sqrt3+2}}{2}\sin(y+\alpha)$$

$$= \frac{\sqrt{\left(\sqrt6+\sqrt2\right)^2}}{2}\sin(y+\alpha) = \frac{\sqrt6+\sqrt2}{2}\sin(y+\alpha)$$

最大値は$\sin(y+\alpha)=1$のときで $\dfrac{\sqrt6+\sqrt2}{2}$

最小値は$\sin(y+\alpha)=-1$のときで $-\dfrac{\sqrt6+\sqrt2}{2}$

### (3)

$$\sin x\cos y = \frac12\{\sin(x+y)+\sin(x-y)\} = \frac12\left\{\sin\frac{\pi}{3}+\sin\left(\frac{\pi}{3}-2y\right)\right\} = \frac{\sqrt3}{4}+\frac12\sin\left(\frac{\pi}{3}-2y\right)$$

最大値は$\sin\left(\dfrac{\pi}{3}-2y\right)=1$のときで $\dfrac{\sqrt3+2}{4}$

最小値は$\sin\left(\dfrac{\pi}{3}-2y\right)=-1$のときで $\dfrac{\sqrt3-2}{4}$

### (4)

$$\cos x \cos y = \frac{1}{2}\{\cos(x+y) + \cos(x-y)\} = \frac{1}{2}\left\{\cos\frac{\pi}{3} + \cos\left(\frac{\pi}{3}-2y\right)\right\} = \frac{1}{4} + \frac{1}{2}\cos\left(\frac{\pi}{3}-2y\right)$$

最大値は$\cos\left(\dfrac{\pi}{3}-2y\right) = 1$のときで $\dfrac{3}{4}$

最小値は$\cos\left(\dfrac{\pi}{3}-2y\right) = -1$のときで $-\dfrac{1}{4}$

### (5)

$$\sin^2 x + \sin^2 y = \frac{1}{2}\{1-\cos 2x + 1 - \cos 2y\} = 1 - \frac{1}{2}\{\cos 2x + \cos 2y\} = 1 - \cos(x+y)\cos(x-y)$$

$$= 1 - \cos\frac{\pi}{3}\cos\left(\frac{\pi}{3}-2y\right) = 1 - \frac{1}{2}\cos\left(\frac{\pi}{3}-2y\right)$$

最大値は$\cos\left(\dfrac{\pi}{3}-2y\right) = 1$のときで $\dfrac{3}{2}$

最小値は$\cos\left(\dfrac{\pi}{3}-2y\right) = -1$のときで$\dfrac{1}{2}$

### (6)

$$\sin^2 x + \cos^2 y = \frac{1}{2}\{\{1-\cos 2x + 1 + \cos 2y\} = 1 - \frac{1}{2}\{\cos 2x - \cos 2y\} = 1 + \sin(x+y)\sin(x-y)$$

$$= 1 + \frac{\sqrt{3}}{2}\sin\left(\frac{\pi}{3}-2y\right)$$

最大値は$\sin\left(\dfrac{\pi}{3}-2y\right) = 1$のときで$\dfrac{2+\sqrt{3}}{2}$

最小値は$\sin\left(\dfrac{\pi}{3}-2y\right) = -1$のときで$\dfrac{2-\sqrt{3}}{2}$
