右図のように

A、B、P を取り

$\angle PAB = x$ とおくと

$$\sin x = \frac{BP}{l}$$

$$\cos x = \frac{AP}{l}$$

$4l\sin x = 4BP$  $3l\cos x = 3AP$ なので

$$4l\sin x + 3l\cos x = 3AP + 4BP$$ となる

$$4l\sin x + 3l\cos x = 5l\sin(x+\alpha)$$となるので

最大値は$\sin(x+\alpha) = 1$のときで  $5l$となる
