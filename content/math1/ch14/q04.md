### (1)
右図のように考えると

$$b\sin B = c\sin C$$

$$b\cdot\frac{x}{c} = c\cdot\frac{x}{b} \qquad \frac{b}{c} = \frac{c}{b}$$

[図：三角形ABC。頂点Aから辺aへの垂線の長さをxとする。辺AB = c、辺AC = b、辺BC = a]

これから$b = c$であり 二等辺三角形となる

### (2)

$$\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2} = 2\cos\frac{\pi-C}{2}\cos\frac{A-B}{2} = 2\sin\frac{C}{2}\cos\frac{A-B}{2}$$

$$\sin C = 2\sin\frac{C}{2}\cos\frac{C}{2}$$

これから

$$\sin\frac{C}{2}\left\{\cos\frac{A-B}{2}-\cos\frac{C}{2}\right\}=0 \qquad \sin\frac{C}{2}=0,\ \cos\frac{A-B}{2}-\cos\frac{C}{2}=0$$

$$\cos\frac{A-B}{2}-\cos\frac{C}{2} = -2\sin\dfrac{\dfrac{A-B}{2}+\dfrac{C}{2}}{2}\sin\dfrac{\dfrac{A-B}{2}-\dfrac{C}{2}}{2} = -2\sin\frac{A-B+C}{4}\sin\frac{A-B-C}{4}=0$$

$C=\pi-(A+B)$より

$$\frac{A-B+\pi-(A+B)}{4} = \frac{\pi-2B}{4} = \frac{\pi}{4}-\frac{B}{2}=0 \qquad B=\frac{\pi}{2}$$

$$\frac{A-B-\pi+(A+B)}{4} = \frac{2A-\pi}{4} = \frac{A}{2}-\frac{\pi}{4}=0 \qquad A=\frac{\pi}{2}$$

これから A 又は B が直角の直角三角形となる

### (3)
正弦定理より $\dfrac{a}{\sin A} = \dfrac{c}{\sin C} = 2R$  余弦定理より $\cos B = \dfrac{c^2+a^2-b^2}{2ac}$ なので

$$\frac{a}{2R} = 2\left\{\frac{c^2+a^2-b^2}{2ac}\right\}\frac{c}{2R}$$

$$a^2 = a^2+c^2-b^2 \qquad b^2=c^2$$

これから b=c であり 二等辺三角形となる

### (4)

$$\cos A:\cos B = b:a \qquad a\cos A = b\cos B$$

$$\frac{a(b^2+c^2-a^2)}{2bc} = \frac{b(c^2+a^2-b^2)}{2ca}$$

$$a^2(b^2+c^2-a^2) = b^2(c^2+a^2-b^2)$$

$$c^2a^2 - a^4 = b^2c^2 - b^4 \qquad (a^2+b^2)(a^2-b^2) - c^2(a^2-b^2) = (a^2-b^2)(a^2+b^2-c^2) = 0$$

$$a^2+b^2=c^2$$

これから $a=b$ の二等辺三角形 または $C=90^\circ$ の直角三角形となる

### (5)

$$\tan^2 A : \tan^2 B = a^2:b^2 \qquad (b\tan A)^2=(a\tan B)^2 \qquad \frac{(b\sin A)^2}{\cos^2 A}=\frac{(a\sin B)^2}{\cos^2 B}$$

正弦定理より $\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=2R$  $a\sin B=b\sin A$  $(a\sin B)^2=(b\sin A)^2$となるので

$$\frac{(b\sin A)^2}{\cos^2 A}=\frac{(a\sin B)^2}{\cos^2 B} \qquad \frac{1}{\cos^2 A}=\frac{1}{\cos^2 B} \qquad \cos^2 A=\cos^2 B \qquad \sin^2 A=\sin^2 B$$

これから $a=b$ の二等辺三角形となる

### (6)

$$b^2\sin^2 C + c^2\sin^2 B = 2bc\cdot\cos B\cos C$$

正弦定理より $\dfrac{c}{\sin C}=\dfrac{b}{\sin B}=2R$  $c^2\sin^2 B = b^2\sin^2 C$  となるので

$$2b^2\sin^2 C = 2bc\cdot\cos B\cos C \qquad b\sin^2 C = c\cdot\cos B\cos C \qquad b(1+\cos C)(1-\cos C)=c\cdot\cos B\cos C$$

余弦定理より

$$b\left\{1+\frac{a^2+b^2-c^2}{2ab}\right\}\left\{1-\frac{a^2+b^2-c^2}{2ab}\right\}=c\left\{\frac{c^2+a^2-b^2}{2ca}\right\}\left\{\frac{a^2+b^2-c^2}{2ab}\right\}$$

$$\{2ab+a^2+b^2-c^2\}\{2ab-a^2-b^2+c^2\}=\{a^2-b^2+c^2\}\{a^2+b^2-c^2\}$$

$$\{(a+b)^2-c^2\}\{c^2-(a-b)^2\}=\{a^2-b^2+c^2\}\{a^2+b^2-c^2\}$$

$$-(a+b)^2(a-b)^2-c^4+c^2(a+b)^2+c^2(a-b)^2=a^4-(b^2-c^2)^2$$

$$2a^2(b^2+c^2)=2a^4 \qquad b^2+c^2=a^2$$

これから $A=90^\circ$ の直角三角形となる
