### (1)
$$\sqrt{a^2 - 4a + 4} = \sqrt{(a-2)^2} = |a-2|$$

### (2)
$$\sqrt{9x^2 - 6x + 1} = \sqrt{(3x-1)^2} = |3x-1|$$

### (3)
$$\sqrt{(a-3)^2} + \sqrt{(a+3)^2} = |a-3| + |a+3|$$

$a \geq 3$ のとき $a - 3 + a + 3 = 2a$

$-3 \leq a < 3$ のとき $3 - a + a + 3 = 6$

$a < -3$ のとき $3 - a - 3 - a = -2a$
