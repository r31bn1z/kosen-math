### (1)
$$\frac{5}{\sqrt{2}} - \sqrt{2} = \frac{5\sqrt{2}}{2} - \sqrt{2} = \frac{5\sqrt{2} - 2\sqrt{2}}{2} = \frac{3\sqrt{2}}{2}$$

### (2)
$$\frac{3\sqrt{2}}{\sqrt{7}} + \frac{5\sqrt{7}}{\sqrt{2}} = \frac{6+35}{\sqrt{14}} = \frac{41}{\sqrt{14}} = \frac{41\sqrt{14}}{14}$$

### (3)
$$\frac{1}{2+\sqrt{3}} - \frac{1}{2-\sqrt{3}} = \frac{2-\sqrt{3}-2-\sqrt{3}}{(2+\sqrt{3})(2-\sqrt{3})} = \frac{-2\sqrt{3}}{4-3} = -2\sqrt{3}$$

### (4)
$$\frac{1}{\sqrt{3}+\sqrt{5}} + \frac{1}{\sqrt{5}+\sqrt{7}} = \frac{\sqrt{3}-\sqrt{5}}{3-5} + \frac{\sqrt{5}-\sqrt{7}}{5-7} = -\frac{\sqrt{3}-\sqrt{7}}{2} = \frac{\sqrt{7}-\sqrt{3}}{2}$$

### (5)
$$\frac{\sqrt{5}-\sqrt{3}}{\sqrt{5}+\sqrt{3}} + \frac{\sqrt{5}+\sqrt{3}}{\sqrt{5}-\sqrt{3}} = \frac{(\sqrt{5}-\sqrt{3})^2 + (\sqrt{5}+\sqrt{3})^2}{(\sqrt{5}+\sqrt{3})(\sqrt{5}-\sqrt{3})} = \frac{5-2\sqrt{15}+3+5+2\sqrt{15}+3}{2} = \frac{16}{2} = 8$$
