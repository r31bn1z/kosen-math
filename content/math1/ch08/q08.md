それぞれ与えられた式を$f(x)$とすると  偶関数なら$f(x) = f(-x)$  奇関数なら$f(-x) = -f(x)$ となる

### (1)
$$x^3 + 2x$$

$$f(-x) = -x^3 - 2x = -f(x)$$ よって奇関数である

### (2)
$$x^4 + 3$$

$$f(-x) = x^4 + 3 = f(x)$$ よって偶関数である

### (3)
$$(x+1)^3 = x^3 + 3x^2 + 3x + 1$$

$$f(-x) = -x^3 + 3x^2 - 3x + 1$$ よっていずれでもない

### (4)
$$x^4 + 2x^2$$

$$f(-x) = x^4 + 2x^2$$ よって偶関数である

### (5)
$$x^2 + x + 1$$

$$f(-x) = x^2 - x + 1$$ よっていずれでもない

### (6)
$$-x(2 - x^2)$$

$$f(-x) = x(2 - x^2) = -f(x)$$ よって奇関数である

### (7)
$$(x^2 + 1)(x^4 - 2)$$

$$f(-x) = (x^2 + 1)(x^4 - 2) = f(x)$$ よって偶関数である

### (8)
$$x^3(x + 2x^3)$$

$$f(-x) = -x^3(-x - 2x^3) = x^3(x + 2x^3) = f(x)$$ よって偶関数である
