### (1)
$$f_{(x)} = |x-1| + |x-2| + |x-3|$$

$x > 3$ のとき  $f_{(x)} = x-1+x-2+x-3 = 3x-6$  最小値$3$($x=3$ を含むとき)

$2 < x \leq 3$ のとき  $f_{(x)} = x-1+x-2-x+3 = x$  最小値$2$($x=2$ を含むとき)

$1 < x \leq 2$ のとき  $f_{(x)} = x-1-x+2-x+3 = -x+4$  最小値$2$

$x \leq 1$ のとき  $f_{(x)} = -x+1-x+2-x+3 = -3x+6$  最小値$3$

これから最小値は$2$  $x=2$のとき

### (2)
$$g_{(x)} = |x-1| + |x-2| + |x-3| + |x-4|$$

$4 < x$ のとき  $f_{(x)} = x-1+x-2+x-3+x-4 = 4x-10$  最小値$6$($x=4$ を含むとき)

$3 < x \leq 4$ のとき  $f_{(x)} = x-1+x-2+x-3-x+4 = 2x-2$  最小値$4$($x=3$ を含むとき)

$2 < x \leq 3$ のとき  $f_{(x)} = x-1+x-2-x+3-x+4 = 4$  最小値$4$

$1 < x \leq 2$ のとき  $f_{(x)} = x-1-x+2-x+3-x+4 = -2x+8$  最小値$4$

$x \leq 1$ のとき  $f_{(x)} = -x+1-x+2-x+3-x+4 = -4x+10$  最小値$6$

これから最小値は$4$  $2 \leq x \leq 3$のとき
