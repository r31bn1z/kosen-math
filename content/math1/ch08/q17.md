### (1)
$y = x + 2$  $x$ と $y$ を入れ替えると

$$x = y + 2$$  $$y = x - 2$$

### (2)
$y = \sqrt{x + 2}$  $x$ と $y$ を入れ替えると

$$x = \sqrt{y + 2}$$  $$x^2 = y + 2$$  $$y = x^2 - 2$$  ただし $x \geq 0$

### (3)
$y = 1 - x^2$  $(x \geq 0)$  $x$ と $y$ を入れ替えると

$$x = 1 - y^2$$  $$y = \sqrt{1 - x}$$  ただし $x \leq 1$

### (4)
$$y = \dfrac{2 - x}{x - 1}$$  $x$ と $y$ を入れ替えると

$$x = \dfrac{2 - y}{y - 1} = -1 + \dfrac{1}{y - 1}$$  $$x + 1 = \dfrac{1}{y - 1}$$  $$y - 1 = \dfrac{1}{x + 1}$$  $$y = \dfrac{1}{x + 1} + 1$$

### (5)
$$y = \dfrac{4x + 3}{x + 2}$$  $x$ と $y$ を入れ替えると

$$x = \dfrac{4y + 3}{y + 2} = 4 - \dfrac{5}{y + 2}$$  $$4 - x = \dfrac{5}{y + 2}$$  $$y + 2 = -\dfrac{5}{x - 4}$$  $$y = -\dfrac{5}{x - 4} - 2$$
