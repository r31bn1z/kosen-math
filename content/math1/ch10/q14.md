### (1)
$\log_a x = \log_b x = \beta$ とおくと

$$a^{\beta} = b^{\beta} = x$$

とならなければならない

この等号が成り立つには $a = b$ 又は $\beta = 0 (x = 1)$ であるので

$a = b$ $x = 1$

### (2)
$$\log_a x + \log_b y = \log_a y + \log_b x$$

$\log_a \dfrac{x}{y} = \log_b \dfrac{x}{y} = \beta$ とおくと(1)と同様に考えて

この等号が成り立つには $a = b$ 又は $\beta = 0 \left(\dfrac{x}{y} = 1\right)$ であるので

$a = b$ $x = y$
