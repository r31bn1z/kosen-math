$0 < b < a < 1$ から $\log_a b > 1$ 条件１

$0 < a^2 < b < 1$ から $1 < \log_a b < \log_a a^2$ 条件２

それぞれの式を右から①、②、・・・、⑤と番号をつけると

① $\log_a b > 1$

② $\log_b a = \dfrac{\log_a a}{\log_a b} = \dfrac{1}{\log_a b} < 1$（負にはならない）

③ $\log_a \dfrac{a}{b} = \log_a a - \log_a b = 1 - \log_a b < 0$

④ $\log_b \dfrac{b}{a} = \log_b b - \log_b a = 1 - \dfrac{\log_a a}{\log_a b} = 1 - \dfrac{1}{\log_a b} < 1$（負にはならない）

⑤ $\dfrac{1}{2} = \dfrac{1}{2\log_a a} = \dfrac{1}{\log_a a^2} < 1$（負にはならない）

⑤ $\dfrac{1}{2} = 1 - \dfrac{1}{2} = 1 - \dfrac{1}{\log_a a^2} < 1$（負にはならない）

条件１から①が最大（１以上となるのは①のみ）

条件１から③が最小（負になるのは③のみ）

条件２から⑤＜②

条件２から④＜⑤

これから③＜④＜⑤＜②＜①

$$\log_a \dfrac{a}{b} < \log_b \dfrac{b}{a} < \dfrac{1}{2} < \log_b a < \log_a b$$
