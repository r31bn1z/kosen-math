### (1)

$$\log_2(x-1) > 2 \qquad x-1 > 2^2 \qquad x > 5$$

### (2)

$$\log(x-3) + \log x < 1 \qquad \log x(x-3) < 1 \qquad x(x-3) < 10^1 \qquad x^2 - 3x - 10 < 0 \qquad (x-5)(x+2) < 0$$

$$-2 < x < 5 \qquad \text{与式の定義域が } x > 3 \text{ であるので} \qquad 3 < x < 5$$

### (3)

$$2\log(x-4) \leq \log(x+2) \qquad (x-4)^2 \leq x+2 \qquad x^2 - 8x + 16 \leq x+2 \qquad x^2 - 9x + 14 \leq 0$$

$$(x-7)(x-2) \leq 0 \qquad 2 \leq x \leq 7$$

$$\text{与式の定義域が } x > 4 \text{ であるので} \qquad 4 < x \leq 7$$

### (4)

$$\log_{\frac{1}{2}} x - 1 > \log_{\frac{1}{2}}(1-x) \qquad -\log_2 x - 1 > -\log_2(1-x) \qquad \log_2 x + 1 < \log_2(1-x)$$

$$2x < 1-x \qquad 3x < 1 \qquad x < \frac{1}{3} \qquad \text{与式の定義域が } 0 < x < 1 \text{ であるので} \qquad 0 < x < \frac{1}{3}$$

### (5)

$$\log x^3 < (\log x)^2 \qquad \log x(3 - \log x) < 0 \qquad \log x < 0 \qquad 3 - \log x < 0 \qquad 0 < x < 1 \qquad 1000 < x$$

### (6)

$$2\log x^2 > 3 + (\log x)^2 \qquad (\log x)^2 - 2\log x^2 + 3 < 0 \qquad (\log x - 3)(\log x - 1) < 0 \qquad 10 < x < 1000$$
