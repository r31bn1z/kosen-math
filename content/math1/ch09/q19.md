### (1)
$$3^{3x-2} > 9^{2x+1} = 3^{2(2x+1)} = 3^{4x+2}$$

$$3x - 2 > 4x + 2 \qquad x < -4$$

### (2)
$$4^x - 2^x \leq 2 \qquad 2^{2x} - 2^x - 2 \leq 0 \qquad (2^x - 2)(2^x + 1) \leq 0 \qquad x \leq 1$$

### (3)
$$(0.25)^x - 1.125(0.5)^x + 0.125 < 0$$

$$(0.5^x - 0.125)(0.5^x - 1) < 0 \qquad 0 < x < 3$$
