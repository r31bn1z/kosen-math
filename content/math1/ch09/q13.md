$$0.5^{\frac{1}{2}} = \left(\frac{1}{2}\right)^{\frac{1}{2}} = 2^{-\frac{1}{2}}$$

$$2^{\frac{1}{3}}$$

$$0.5^{-2} = \left(\frac{1}{2}\right)^{-2} = 2^{2}$$

$$0.5^{0} = 1$$

$$2^{-0.2} = 2^{-\frac{1}{5}}$$

これらの大小関係は以下のようになる

$$2^{-\frac{1}{2}} < 2^{-\frac{1}{5}} < 1 < 2^{\frac{1}{3}} < 2^{2}$$

よって

$$0.5^{\frac{1}{2}} < 2^{-0.2} < 0.5^{0} < 2^{\frac{1}{3}} < 0.5^{-2}$$
