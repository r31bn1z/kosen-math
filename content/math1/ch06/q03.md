### (1)

$$A \cap B = \{x \mid 0 < x \leq 2\}$$

### (2)

$$A \cup B = \{x \mid -2 \leq x < 3\}$$

### (3)

$$\overline{A} = \{x \mid x < -2,\ 2 < x\}$$

### (4)

$$\overline{B} = \{x \mid x \leq 0,\ 3 \leq x\}$$

$$\overline{A} \cup \overline{B} = \{x \mid x \leq 0,\ 2 < x\}$$

### (5)

$$\overline{A} \cap \overline{B} = \{x \mid x < -2,\ 3 \leq x\}$$
