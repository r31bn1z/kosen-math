$$\sin\theta + \cos\theta = a$$

$$(\sin\theta + \cos\theta)^2 = a^2$$

$$\sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = a^2 \qquad 2\sin\theta\cos\theta = a^2 - 1 \qquad \sin\theta\cos\theta = \frac{1}{2}(a^2-1)$$

これから

$$\sin^3\theta + \cos^3\theta = (\sin\theta + \cos\theta)^3 - 3\sin^2\theta\cos\theta - 3\sin\theta\cos^2\theta$$

$$= (\sin\theta + \cos\theta)^3 - 3\sin\theta\cos\theta(\sin\theta + \cos\theta) = a^3 - \frac{3}{2}(a^2-1)a = a^3 - \frac{3}{2}a^3 + \frac{3}{2}a = -\frac{1}{2}a^3 + \frac{3}{2}a$$
