$$3x^2 - 2x - 4 = 0 \qquad x^2 - \frac{2}{3}x - \frac{4}{3} = 0$$

解が α、β なので与式は $(x-\alpha)(x-\beta) = 0$ のかたちとなるので $x^2 - (\alpha+\beta)x + \alpha\beta = 0$

これから $\alpha + \beta = \dfrac{2}{3}$、$\alpha\beta = -\dfrac{4}{3}$、$\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta = \dfrac{28}{9}$ となる

### (1)

$$\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha+\beta}{\alpha\beta} = \frac{\dfrac{2}{3}}{-\dfrac{4}{3}} = -\frac{1}{2}$$

### (2)

$$\frac{1}{(\alpha+1)} + \frac{1}{(\beta+1)} = \frac{\alpha+\beta+2}{(\alpha+1)(\beta+1)} = \frac{\dfrac{2}{3}+2}{\alpha\beta+(\alpha+\beta)+1} = \frac{\dfrac{8}{3}}{-\dfrac{4}{3}+\dfrac{2}{3}+1} = \frac{\dfrac{8}{3}}{\dfrac{-4+2+3}{3}} = 8$$

### (3)

$$\frac{\beta}{\alpha} + \frac{\alpha}{\beta} = \frac{\beta^2+\alpha^2}{\alpha\beta} = \frac{\dfrac{28}{9}}{-\dfrac{4}{3}} = -\frac{7}{3}$$

### (4)

$$(\alpha-\beta)^2 = \alpha^2+\beta^2-2\alpha\beta = \frac{28}{9} - 2\cdot\left(-\frac{4}{3}\right) = \frac{28+24}{9} = \frac{52}{9}$$

### (5)

$$\alpha^3+\beta^3 = (\alpha+\beta)(\alpha^2-\alpha\beta+\beta^2) = \frac{2}{3}\cdot\left(\frac{28}{9}+\frac{4}{3}\right) = \frac{2}{3}\cdot\frac{40}{9} = \frac{80}{27}$$

### (6)

$$(|\alpha|-|\beta|)^2 = \alpha^2 - 2|\alpha||\beta| + \beta^2 = \frac{28}{9} - 2\cdot\left|-\frac{4}{3}\right| = \frac{28}{9} - \frac{8}{3} = \frac{4}{9} \qquad |\alpha|-|\beta| = \pm\frac{2}{3}$$
