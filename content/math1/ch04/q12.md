$$3x^2 + 6x - 7 = 0$$

$$x = \frac{-3 \pm \sqrt{9+21}}{3} = \frac{-3 \pm \sqrt{30}}{3}$$

ここで $\alpha = \dfrac{-3+\sqrt{30}}{3}$、$\beta = \dfrac{-3-\sqrt{30}}{3}$ とおくと与式は

$$(x-\alpha)(x-\beta) = 0$$ と書けるので $$x^2 - (\alpha+\beta)x + \alpha\beta = 0$$ となり

$$\alpha\beta = \frac{9-30}{9} = -\frac{7}{3} \qquad \alpha+\beta = \frac{-6}{3} = -2 \qquad \text{となる}$$

### (1)

$$\alpha^2\beta + \alpha\beta^2 = \alpha\beta(\alpha+\beta) = -\frac{7}{3}\cdot(-2) = \frac{14}{3}$$

### (2)

$$\alpha^3+\beta^3 = (\alpha+\beta)(\alpha^2-\alpha\beta+\beta^2) = (\alpha+\beta)\{(\alpha+\beta)^2-3\alpha\beta\} = (-2)\left\{(-2)^2-3\left(-\frac{7}{3}\right)\right\} = -2\cdot(4+7) = -22$$

### (3)

$$\frac{\beta}{\alpha}+\frac{\alpha}{\beta} = \frac{\beta^2+\alpha^2}{\alpha\beta} = \frac{(\alpha+\beta)^2-2\alpha\beta}{\alpha\beta} = \frac{(-2)^2-2\left(-\frac{7}{3}\right)}{-\frac{7}{3}} = -\frac{26}{7}$$
