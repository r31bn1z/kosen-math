$$x^2 - 7x + 12 = 0 \qquad (x-3)(x-4) = 0 \qquad x = 3, 4$$

これから$\alpha + \beta$ と $\alpha\beta$ が $3,4$ のどちらかであることになる

$$x^2 - mx + n = 0 \qquad (x-\alpha)(x-\beta) = 0 \qquad x = \alpha, \beta \quad \text{であり}$$

$$x^2 - (\alpha+\beta)x + \alpha\beta = 0 \quad \text{の形であるので} \qquad m = \alpha + \beta \qquad n = \alpha\beta \quad \text{となる}$$

判別式 $D = m^2 - 4n > 0$ となるので $m^2 > 4n$

これから $\alpha + \beta = 4$ $\alpha\beta = 3$ であれば判別式を満足するので

$m = 4$ $n = 3$ となり、このとき $\alpha = 1$ $\beta = 3$ となる
