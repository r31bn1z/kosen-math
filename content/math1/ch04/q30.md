### (1)
$$x^2 - (m-1)x + m = 0$$

$$x = \frac{(m-1) \pm \sqrt{(m-1)^2 - 4m}}{2} = \frac{(m-1) \pm \sqrt{m^2 - 2m + 1 - 4m}}{2} = \frac{(m-1) \pm \sqrt{m^2 - 6m + 1}}{2}$$

解が $2:3$ であるとき

$$2:3 = \frac{(m-1) - \sqrt{m^2 - 6m + 1}}{2} : \frac{(m-1) + \sqrt{m^2 - 6m + 1}}{2}$$

$$2 \cdot \frac{(m-1) + \sqrt{m^2 - 6m + 1}}{2} = 3 \cdot \frac{(m-1) - \sqrt{m^2 - 6m + 1}}{2}$$

$$2(m-1) + 2\sqrt{m^2 - 6m + 1} = 3(m-1) - 3\sqrt{m^2 - 6m + 1}$$

$$m - 1 = 5\sqrt{m^2 - 6m + 1} \qquad (m-1)^2 = 25(m^2 - 6m + 1)$$

$$m^2 - 2m + 1 = 25(m^2 - 6m + 1) \qquad 24m^2 - 148m + 24 = 0 \qquad (12m-2)(2m-12) = 0 \qquad m = 6, \frac{1}{6}$$

$m = 6$ のとき解は $2,3$   $m = \dfrac{1}{6}$ のとき解は $-\dfrac{1}{2}, -\dfrac{1}{3}$

### (2)
$$\frac{(m-1) + \sqrt{m^2 - 6m + 1}}{2} - \frac{(m-1) - \sqrt{m^2 - 6m + 1}}{2} = 1$$

$$(m-1) + \sqrt{m^2 - 6m + 1} - (m-1) + \sqrt{m^2 - 6m + 1} = 2$$

$$\sqrt{m^2 - 6m + 1} = 1 \qquad m^2 - 6m + 1 = 1 \qquad m^2 - 6m = 0 \qquad m(m-6) = 0 \qquad m = 0, 6$$

$m = 6$ のとき解は $2,3$   $m = 0$ のとき解は $0, -1$

### (3)
$$\frac{(m-1) + \sqrt{m^2 - 6m + 1}}{2} = 2 \cdot \frac{(m-1) - \sqrt{m^2 - 6m + 1}}{2}$$

$$(m-1) + \sqrt{m^2 - 6m + 1} = 2(m-1) - 2\sqrt{m^2 - 6m + 1}$$

$$m-1=3\sqrt{m^2-6m+1} \qquad (m-1)^2=9(m^2-6m+1) \qquad m^2-2m+1=9(m^2-6m+1)$$

$$8m^2-52m+8=0 \qquad 4m^2-26m+4=0 \qquad m=\frac{13\pm\sqrt{169-16}}{4}=\frac{13\pm\sqrt{153}}{4}=\frac{13\pm3\sqrt{17}}{4}$$

$m=\dfrac{13+3\sqrt{17}}{4}$ のとき

$m$ を求める際に $m^2-2m+1=9(m^2-6m+1)$ という条件式が求まっているので

$$\frac{m^2-2m+1}{9}=(m^2-6m+1) \qquad \frac{(m-1)^2}{9}=(m^2-6m+1)$$

$$\frac{(m-1)+\sqrt{m^2-6m+1}}{2}=\frac{(m-1)+\sqrt{\dfrac{(m-1)^2}{9}}}{2}=\frac{\dfrac{9+3\sqrt{17}}{4}+\dfrac{9+3\sqrt{17}}{12}}{2}=\frac{3+\sqrt{17}}{2}$$

解は $\dfrac{3+\sqrt{17}}{2}, \dfrac{3+\sqrt{17}}{4}$

同様に $m=\dfrac{13-3\sqrt{17}}{4}$ のとき解は $\dfrac{3-\sqrt{17}}{2}, \dfrac{3-\sqrt{17}}{4}$
