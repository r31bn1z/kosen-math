２直線の交点は

$$2x + 3y + 7 = 0 \qquad y = -\frac{2}{3}x - \frac{7}{3}$$

これを他方の方程式に代入して

$$3x - 4\left(-\frac{2}{3}x - \frac{7}{3}\right) - 15 = 0 \qquad 9x + 8x + 28 - 45 = 0 \qquad 17x = 17 \qquad x = 1 \qquad y = -3 \qquad \text{よって}(1,-3)$$

### (1)
点$(1,-3)$と$(0,0)$を通るので

$$\text{傾きは}\frac{-3-0}{1-0} = -3 \qquad \text{これから} \qquad y = -3x + b \qquad (0,0)\text{を通るので} \qquad b = 0$$

$$y = -3x$$

### (2)
点$(1,-3)$と$(0,-2)$を通るので

$$\text{傾きは}\frac{-3-(-2)}{1-0} = -1 \qquad \text{これから} \qquad y = -x + b \qquad (0,-2)\text{を通るので} \qquad b = -2$$

$$y = -x - 2$$

### (3)

$$2x + y - 3 = 0 \qquad y = -2x + 3 \qquad \text{傾きは}-2$$

$$y = -2x + b \qquad (1,-3)\text{を通るので} \qquad b = -1$$

$$y = -2x - 1$$

### (3)

$$5x + 2y - 5 = 0 \qquad y = -\frac{5}{2}x + \frac{5}{2} \qquad \text{傾きは}-\frac{5}{2}\text{なので垂直な直線の傾きは}\frac{2}{5}$$

$$y = \frac{2}{5}x + b \qquad (1,-3)\text{を通るので} \qquad b = -\frac{17}{5}$$

$$y = \frac{2}{5}x - \frac{17}{5}$$
