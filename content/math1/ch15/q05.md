### (1)
傾きが $3$ なので

$$y = 3x + b$$

点$(0,2)$を通るので

$$2 = b$$

これから $y = 3x + 2$

### (2)
傾きが$-3$なので

$$y = -3x + b$$

点$(2,0)$を通るので

$$0 = -6 + b \qquad b = 6$$

これから $y = -3x + 6$

### (3)
傾きが $0$ なので

$$y = b$$

点$(3,4)$を通るので

$$4 = b$$

これから $y = 4$

### (4)
$y$切片が $8$ なので点$(0,8)$を通る

点$(2,-2)$、$(0,8)$を通るので傾きは

$$\frac{-2-8}{2-0} = -5$$

$$y = -5x + b$$

点$(2,-2)$を代入して

$$-2 = -10 + b \qquad b = 8$$

これから $y = -5x + 8$

### (5)
点$(1,2)$、$(4,5)$を通るので傾きは

$$\frac{2-5}{1-4} = 1$$

$$y = x + b$$

点$(1,2)$を代入して

$$2 = 1 + b \qquad b = 1$$

これから $y = x + 1$

### (6)
点$(1,2)$、$(1,-2)$は共に$x=1$であるので

これから $x = 1$

### (7)
点$(0,3)$、$(2,0)$を通るので傾きは

$$\frac{3-0}{0-2} = -\frac{3}{2}$$

$$y = -\frac{3}{2}x + b$$

点$(0,3)$を代入して

$$3 = b$$

これから $y = -\frac{3}{2}x + 3$

### (8)
点$(-1,3)$、$(1,-1)$を通るので傾きは

$$\frac{3-(-1)}{-1-1}=-2$$

$$y=-2x+b$$

点$(-1,3)$を代入して

$$3=2+b \qquad b=1$$

これから $y=-2x+1$
