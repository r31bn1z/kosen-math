$$3x - 2y + 4 = 0$$

$$y = \frac{3}{2}x + 2$$

傾き $\frac{3}{2}$

この直線と垂直な直線の傾きは $-\frac{2}{3}$ となる

$$y = -\frac{2}{3}x + b$$

これか点$(9,9)$を通るので $9 = -6 + b$ $b = 15$

$$y = -\frac{2}{3}x + 15$$

交点は $\frac{3}{2}x + 2 = -\frac{2}{3}x + 15$ $9x + 12 = -4x + 90$ $13x = 78$ $x = 6$ これから $y = 11$

交点は$(6,11)$

垂線の長さは

$$\sqrt{(9-6)^2 + (9-11)^2} = \sqrt{13}$$
