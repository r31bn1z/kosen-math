A から B の距離は$(7,1)$なので

D から C の距離も$(7,1)$である

$$D = (2 - 7, -2 - 1) = (-5, -3)$$ となる

$$AB = \sqrt{(-3-4)^2 + (2-3)^2} = 5\sqrt{2}$$

$$BC = \sqrt{(4-2)^2 + \left(3-(-2)\right)^2} = \sqrt{29}$$

これから辺の長さは

$$2\left(5\sqrt{2} + \sqrt{29}\right) = 10\sqrt{2} + 2\sqrt{29}$$
