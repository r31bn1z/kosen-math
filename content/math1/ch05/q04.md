### (1)
$$-3x^2 + x + 1 = -4x + 3$$

$$3x^2 - 5x + 2 = 0 \qquad (3x-2)(x-1) = 0 \qquad x = \frac{2}{3}, 1$$

$x = 1$ のとき $y = -1$ $x = \dfrac{2}{3}$のとき $y = \dfrac{1}{3}$

よって共有点の個数は $2$ つであり座標は$(1,-1), \left(\dfrac{2}{3}, \dfrac{1}{3}\right)$となる

### (2)
$$-3x^2 + x + 1 = -5x + 4$$

$$3x^2 - 6x + 3 = 0 \qquad (3x-3)(x-1) = 0 \qquad x = 1$$

$x = 1$ のとき $y = -1$

よって共有点の個数は $1$ つであり座標は$(1,-1)$

### (3)
$$-3x^2 + x + 1 = -3x + 5$$

$$3x^2 - 4x + 4 = 0 \qquad x = \frac{2 \pm \sqrt{4-12}}{3} = \frac{2 \pm 2\sqrt{2}i}{3}$$

よって共有点はなく虚数解は$\dfrac{2 \pm 2\sqrt{2}i}{3}$
