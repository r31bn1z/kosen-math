### (1)

$y + b = x^2 - 2x$ と考えると $y = x^2 - 2x - b$

これが$y = x$と接するので

$$x^2 - 2x - b = x \qquad x^2 - 3x - b = 0 \qquad x = \frac{3 \pm \sqrt{9 + 4b}}{2}$$

$9 + 4b = 0$ となればよいので $b = -\dfrac{9}{4}$ $\quad y - \dfrac{9}{4} = x^2 - 2x$ これから y 軸方向に$\dfrac{9}{4}$平行移動する

### (2)

$y = (x-a)^2 - 2(x-a)$と考えると $y = x^2 - 2ax + a^2 - 2x + 2a = x^2 - 2(a+1)x + a^2 + 2a$

これが$y = x$と接するので

$$x^2 - 2(a+1)x + a^2 + 2a = x \qquad x^2 - (2a+3)x + a^2 + 2a = 0$$

$$x = \frac{(2a+3) \pm \sqrt{(2a+3)^2 - 4(a^2+2a)}}{2}$$

$(2a+3)^2 - 4(a^2+2a) = 0$ となればよいので $4a^2 + 12a + 9 - 4a^2 - 8a = 0 \quad 4a = -9 \quad a = -\dfrac{9}{4}$

$$y = \left(x + \frac{9}{4}\right)^2 - 2\left(x + \frac{9}{4}\right)$$ これから x 軸方向に$-\dfrac{9}{4}$平行移動

### (3)

x 軸方向に$-3$なので

$$y = (x+3)^2 - 2(x+3) = x^2 + 6x + 9 - 2x - 6 = x^2 + 4x + 3$$

$y + b = x^2 + 4x + 3$ と考えると $y = x^2 + 4x + 3 - b$

これが$y = x$と接するので

$$x^2 + 4x + 3 - b = x \qquad x^2 + 3x + 3 - b = 0 \qquad x = \frac{-3 \pm \sqrt{9 - 4(3-b)}}{2}$$

$9 - 4(3-b) = 0$ となればよいので $9 - 12 + 4b = 0 \quad 4b = 3 \quad b = \dfrac{3}{4}$ $\qquad y + \dfrac{3}{4} = x^2 + 4x + 3$

これから y 軸方向に$-\dfrac{3}{4}$平行移動
