$$x^2 + 2mx + (2m^2 - 1) = 0$$

解を持つためには判別式$D = 4m^2 - 4(2m^2 - 1) = -4m^2 + 4 \geq 0$ $-1 \leq m \leq 1$であればよい

$$x = -m \pm \sqrt{m^2 - 2m^2 + 1} = -m \pm \sqrt{1 - m^2}$$

$\sqrt{1-m^2} \geq 0$から$-1 \leq m \leq 0$では少なくとも$1$つの正の解を持つ

$0 < m \leq 1$の範囲で少なくとも$1$つの正の解を持つのは

$$-m + \sqrt{1-m^2} \geq 0 \qquad m^2 \leq 1 - m^2 \qquad 2m^2 \leq 1 \qquad 0 < m \leq \frac{1}{\sqrt{2}}$$

これから

$$-1 \leq m \leq \frac{1}{\sqrt{2}}$$
