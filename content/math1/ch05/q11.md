### (1)
$$x^2 - 6x + 5 = (x-5)(x-1) > 0$$

下に凸であることから $x < 1$ $5 < x$

### (2)
$$x^2 + 4x - 32 = (x+8)(x-4) \leq 0$$

下に凸であることから $-8 \leq x \leq 4$

### (3)
$$2x^2 + 9x + 9 = (2x+3)(x+3) < 0$$

下に凸であることから $-3 < x < -\dfrac{3}{2}$

### (4)
$$3x^2 + 7x + 4 = (3x+4)(x+1) > 0$$

下に凸であることから $x < -\dfrac{4}{3}$ $-1 < x$

### (5)
$$7x^2 - 25x + 12 = (7x-4)(x-3) \geq 0$$

下に凸であることから $x \leq \dfrac{4}{7}$ $3 \leq x$

### (6)
$$8x \geq x^2 + 16 \qquad x^2 - 8x + 16 \leq 0 \qquad (x-4)^2 \leq 0 \qquad x = 4$$

### (7)
$$x^2 \geq 9 \qquad x^2 - 9 \geq 0 \qquad (x-3)(x+3) \geq 0$$

下に凸であることから $x \leq -3$ $3 \leq x$

### (8)
$$4x + 3x^2 \leq 0 \qquad x(3x+4) \leq 0$$

下に凸であることから $-\dfrac{4}{3} \leq x \leq 0$

### (9)
$x^2 + x < 1$  $x^2 + x - 1 < 0$

$x^2 + x - 1 = 0$ のとき $x = \dfrac{-1 \pm \sqrt{1+4}}{2} = \dfrac{-1 \pm \sqrt{5}}{2}$ であるので

下に凸であることから $\dfrac{-1-\sqrt{5}}{2} < x < \dfrac{-1+\sqrt{5}}{2}$

### (10)
$x^2 + x + 1 > 0$

$x^2 + x + 1 = 0$ のとき $x = \dfrac{-1 \pm \sqrt{1-4}}{2} = \dfrac{-1 \pm \sqrt{3}i}{2}$

下に凸であることから 全ての実数となる

### (11)
$4x^2 - 12x + 9 = (2x-3)^2 < 0$

下に凸であり頂点で x 軸と接するので解なし

### (12)
$9x^2 - 24x + 16 = (3x-4)^2 > 0$

下に凸であり頂点で x 軸と接するので 全ての実数となる
