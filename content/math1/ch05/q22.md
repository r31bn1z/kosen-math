$$x^2 + (10-2m)x + (2m^2-4m-2) = 0$$

実数解を持つには判別式 $D = (10-2m)^2 - 4(2m^2-4m-2) \geq 0$ となればよい

$$100 - 40m + 4m^2 - 8m^2 + 16m + 8 = -4m^2 - 24m + 108 = -4(m^2+6m-27) \geq 0$$

$$(m+9)(m-3) \leq 0 \quad -9 \leq m \leq 3$$

$$x = (5-m) \pm \sqrt{(5-m)^2 - (2m^2-4m-2)} = (5-m) \pm \sqrt{-m^2-6m+27}$$

２つの解の積は

$$(5-m)^2 - (-m^2-6m+27) = 25 - 10m + m^2 + m^2 + 6m - 27 = 2m^2 - 4m - 2$$

$f(m) = 2m^2-4m-2$ とすると $f(m) = 2(m^2-2m)-2 = 2(m-1)^2-4$

よって最小値は$m=1$のとき$-4$

最大値は$m=-9$のとき$196$
