2次関数$y = ax^2 + bx + c$が常に直線$y = x - 2$の上方であるためには

下に凸の2次関数であり$y = x - 2$との交点はないということである

下に凸であるので$a > 0$である

$$ax^2 + bx + c = x - 2 \qquad ax^2 + (b - 1)x + c + 2 = 0$$

としたとき

判別式$D = (b - 1)^2 - 4a(c + 2) < 0$となれば交点を持たない

これから

$$a > 0 \qquad (b - 1)^2 < 4a(c + 2)$$
