### (1)
$x^2 < 9$  $(x-3)(x+3) < 0$  $-3 < x < 3$

$x^2 > 3x$  $x(x-3) > 0$  $x < 0$ $3 < x$

これから $-3 < x < 0$

### (2)
$x^2 - 4 < 0$  $(x-2)(x+2) < 0$  $-2 < x < 2$

$2x^2 - 3x + 1 > 0$  $(2x-1)(x-1) > 0$  $x < \dfrac{1}{2}$ $1 < x$

これから $-2 < x < \dfrac{1}{2}$ $1 < x < 2$

### (3)
$x^2 + 2x \geq 35$  $(x+7)(x-5) \geq 0$  $x \leq -7$ $5 \leq x$

$6x^2 - 7x - 5 > 0$  $(3x-5)(2x+1) > 0$  $x < -\dfrac{1}{2}$ $\dfrac{5}{3} < x$

これから $x \leq -7$ $5 \leq x$

### (4)
$x^2 - 7x + 10 > 0$  $(x-2)(x-5) > 0$  $x < 2$ $5 < x$

$x^2 - 8x - 7 = 0$ のとき $x = 4 \pm \sqrt{16+7} = 4 \pm \sqrt{23}$ なので $x < 4 - \sqrt{23}$ $4 + \sqrt{23} < x$

これから $4 - \sqrt{23} < x < 2$ $5 < x < 4 + \sqrt{23}$

### (5)
$2x^2 \leq 4x + 5$  $2x^2 - 4x - 5 = 0$ のとき $x = \dfrac{2 \pm \sqrt{4+10}}{2} = \dfrac{2 \pm \sqrt{14}}{2}$ $\dfrac{2 - \sqrt{14}}{2} \leq x \leq \dfrac{2 + \sqrt{14}}{2}$

$3x^2 - 7x - 10 = 0$ のとき $(3x-10)(x+1) = 0$ $-1 < x < \dfrac{10}{3}$

これから $\dfrac{2 - \sqrt{14}}{2} < x < \dfrac{2 + \sqrt{14}}{2}$

### (6)
$x^2 - 4x + 4 > 0$  $(x-2)^2 > 0$  $x \neq 2$

$x^2 - 3x + 2 \leq 0$  $(x-2)(x-1) \leq 0$  $1 \leq x \leq 2$  これから $1 \leq x < 2$
