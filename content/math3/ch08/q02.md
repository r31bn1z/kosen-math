### (1)
$$\int_1^2\int_1^{x^2} (x^2+2y)\,dy\,dx = \int_1^2 \left[x^2y+y^2\right]_1^{x^2} dx = \int_1^2 x^4+x^4-x^2-1\,dx = \int_1^2 2x^4-x^2-1\,dx$$

$$= \left[\frac{2}{5}x^5-\frac{1}{3}x^3-x\right]_1^2 = \frac{136}{15}$$

順序入れ替え

$$\int_1^4\int_{\sqrt{y}}^2 (x^2+2y)\,dx\,dy = \int_1^4 \left[\frac{1}{3}x^3+2xy\right]_{\sqrt{y}}^2 dy = \int_1^4 \frac{8}{3}+4y-\frac{1}{3}y^{\frac{3}{2}}-2y^{\frac{3}{2}}\,dy$$

$$= \int_1^4 \frac{8}{3}+4y-\frac{7}{3}y^{\frac{3}{2}}\,dy = \left[\frac{8}{3}y+2y^2-\frac{14}{15}y^{\frac{5}{2}}\right]_1^4 = \frac{136}{15}$$

### (2)
$$\int_2^4\int_4^{x^2} \frac{x}{y^2}\,dy\,dx = \int_2^4 \left[-\frac{x}{y}\right]_4^{x^2} dx = \int_2^4 -\frac{1}{x}+\frac{1}{4}x\,dx = \left[-\log x+\frac{1}{8}x^2\right]_2^4 = \frac{3}{2}-\log 2$$

順序入れ替え

$$\int_4^{16}\int_{\sqrt{y}}^4 \frac{x}{y^2}\,dx\,dy = \int_4^{16} \left[\frac{1}{2}\frac{x^2}{y^2}\right]_{\sqrt{y}}^4 dy = \int_4^{16} \frac{8}{y^2}-\frac{1}{2y}\,dy = \left[-\frac{8}{y}-\frac{1}{2}\log y\right]_4^{16} = \frac{3}{2}-\log 2$$

### (3)
$$\int_0^3\int_0^{2-\frac{2}{3}x} \left(1-\frac{x+y}{3}\right) dy\,dx = \int_0^3 \left[y-\frac{x}{3}y-\frac{1}{6}y^2\right]_0^{2-\frac{2}{3}x} dx = \int_0^3 \frac{4}{3}-\frac{8}{9}x+\frac{4}{27}x^2\,dx$$

$$= \left[\frac{4}{3}x-\frac{4}{9}x^2+\frac{4}{81}x^3\right]_0^3 = \frac{4}{3}$$

順序入れ替え

$$\int_0^2\int_0^{3-\frac{3}{2}y} \left(1-\frac{x+y}{3}\right) dx\,dy = \int_0^2 \left[x-\frac{1}{6}x^2-\frac{y}{3}x\right]_0^{3-\frac{3}{2}y} dy = \int_0^2 \frac{3}{2}-y+\frac{1}{8}y^2\,dy$$

$$= \left[\frac{3}{2}y-\frac{1}{2}y^2+\frac{1}{24}y^3\right]_0^2 = \frac{4}{3}$$

### (4)

$$\int_0^1 \int_x^{2x} 2x^2 y \, dy\, dx = \int_0^1 \left[x^2y^2\right]_x^{2x} dx = \int_0^1 4x^4 - x^4 \, dx = \int_0^1 3x^4 \, dx = \left[\frac{3}{5}x^5\right]_0^1 = \frac{3}{5}$$

順序入れ替え

$$\int_0^1 \int_{\frac{y}{2}}^{y} 2x^2 y\, dx\, dy + \int_1^2 \int_{\frac{y}{2}}^{1} 2x^2 y\, dx\, dy = \int_0^1 \left[\frac{2}{3}x^3y\right]_{\frac{y}{2}}^{y} dx + \int_1^2 \left[\frac{2}{3}x^3y\right]_{\frac{y}{2}}^{1} dx$$

$$= \int_0^1 \frac{7}{12}y^4\, dy + \int_1^2 \frac{2}{3}y - \frac{1}{12}y^4\, dy = \left[\frac{7}{60}y^5\right]_0^1 + \left[\frac{1}{3}y^2 - \frac{1}{60}y^5\right]_1^2 = \frac{3}{5}$$
