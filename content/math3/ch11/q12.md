### (1)
$z^2 = 2i$

$z = r(\cos\theta + i\sin\theta)$ とおくと与式は

$r^2(\cos\theta + i\sin\theta)^2 = 2i$ $r^2(\cos 2\theta + i\sin 2\theta) = 2i$ これから

$r^2 = 2$ $r = \sqrt{2}$

$2\theta = \frac{\pi}{2} + 2k\pi$ $\theta = \frac{\pi}{4} + k\pi$

$k = 0$ のとき $\theta = \frac{\pi}{4}$ $k = 1$ のとき $\theta = \frac{5}{4}\pi$ これから

$z_1 = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right) = 1 + i$

$z_2 = \sqrt{2}\left(\cos\frac{5}{4}\pi + i\sin\frac{5}{4}\pi\right) = -1 - i$

### (2)
$z^2 = 1 + \sqrt{3}i$

$z = r(\cos\theta + i\sin\theta)$ とおくと与式は

$r^2(\cos\theta + i\sin\theta)^2 = 1 + \sqrt{3}i$ $r^2(\cos 2\theta + i\sin 2\theta) = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$ これから

$r = \sqrt{2}$

$2\theta = \frac{\pi}{3} + 2k\pi$ $\theta = \frac{\pi}{6} + k\pi$

$k = 0$ のとき $\theta = \frac{\pi}{6}$ $k = 1$ のとき $\theta = \frac{7}{6}\pi$ これから

$z_1 = \sqrt{2}\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right) = \frac{\sqrt{6}}{2} + \frac{\sqrt{2}}{2}i$

$z_2 = \sqrt{2}\left(\cos\frac{7}{6}\pi + i\sin\frac{7}{6}\pi\right) = -\frac{\sqrt{6}}{2} - \frac{\sqrt{2}}{2}i$

### (3)
$z^3 = -i$

$z = r(\cos \theta + i \sin \theta)$ と置くと与式は

$r^3(\cos 3\theta + i \sin 3\theta) = -i = \cos \frac{3}{2}\pi + i \sin \frac{3}{2}\pi$ これから

$r^3 = 1$ $r = 1$

$3\theta = \frac{3}{2}\pi + 2k\pi$ $\theta = \frac{1}{2}\pi + \frac{2}{3}k\pi$

$k = 0$ のとき $\theta = \frac{\pi}{2}$ $k = 1$ のとき $\theta = \frac{7}{6}\pi$ $k = 2$ のとき $\theta = \frac{11}{6}\pi$ これから

$z_1 = \cos \frac{1}{2}\pi + i \sin \frac{1}{2}\pi = i$

$z_2 = \cos \frac{7}{6}\pi + i \sin \frac{7}{6}\pi = -\frac{\sqrt{3}}{2} - \frac{1}{2}i$

$z_3 = \cos \frac{11}{6}\pi + i \sin \frac{11}{6}\pi = \frac{\sqrt{3}}{2} - \frac{1}{2}i$

### (4)
$z^4 = -8 + 8\sqrt{3}i$

$z = r(\cos \theta + i \sin \theta)^4 = -8 + 8\sqrt{3}i$ $r^4(\cos 4\theta + i \sin 4\theta) = 8\{2(\cos \frac{2}{3}\pi + i \sin \frac{2}{3}\pi)\}$ これから

$r^4 = 16$ $r = 2$

$4\theta = \frac{2}{3}\pi + 2k\pi$ $\theta = \frac{\pi}{6} + \frac{1}{2}k\pi$

$k = 0$ のとき $\theta = \frac{\pi}{6}$ $k = 1$ のとき $\theta = \frac{2}{3}\pi$

$k = 2$ のとき $\theta = \frac{7}{6}\pi$ $k = 3$ のとき $\theta = \frac{5}{3}\pi$ これから

$z_1 = 2(\cos \frac{\pi}{6} + i \sin \frac{\pi}{6}) = \sqrt{3} + i$ $z_2 = 2(\cos \frac{2}{3}\pi + i \sin \frac{2}{3}\pi) = -1 + \sqrt{3}i$

$z_3 = 2(\cos \frac{7}{6}\pi + i \sin \frac{7}{6}\pi) = -\sqrt{3} - i$ $z_4 = 2(\cos \frac{5}{3}\pi + i \sin \frac{5}{3}\pi) = 1 - \sqrt{3}i$
