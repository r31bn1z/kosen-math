$ax^3 + bx^2 + cx + d = 0$

$\alpha$がこの式の解であるので$x$に$\alpha$を代入して

$$a\alpha^3 + b\alpha^2 + c\alpha + d = 0 \quad ①$$

両辺の共役複素数を考えると

$$a\bar{\alpha}^3 + b\bar{\alpha}^2 + c\bar{\alpha} + \bar{d} = 0$$

$a,b,c,d$は実数であるので

$$a\bar{\alpha}^3 + b\bar{\alpha}^2 + c\bar{\alpha} + d = 0 \quad ②$$

①、②から考えると $\bar{\alpha}$もこの方程式の解であるといえる
