点$0,α,β$が正三角形の頂点なので

$$|α| = |β|$$
$$\angle α0β = \angle 0αβ = \angle 0βα = \frac{\pi}{3}$$
となる

$$\text{arg}\left(\frac{α - 0}{β - 0}\right) = \text{arg}\left(\frac{α}{β}\right) = \pm\frac{\pi}{3}$$
であるので

$$\text{arg}\left(\frac{α}{β}\right)^3 = \pm π$$
これから

$$\left(\frac{α}{β}\right)^3 = -1$$

$$α^3 + β^3 = 0$$

$$(α + β)(α^2 - αβ + β^2) = 0$$

ここで$α + β ≠ 0$から

$$α^2 - αβ + β^2 = 0$$
が必要十分条件である
