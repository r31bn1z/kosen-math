### (1)

$|z - (3 - 2i)| = 3$

$|z - (3 - 2i)| = 3$ これから $(3 - 2i)$ を中心とした半径 $3$ の円

### (2)

$|z + 3 - 4i| = 5$

$|z - (-3 + 4i)| = 5$ これから $(-3 + 4i)$ を中心とした $5$ の円

### (3)

$|z - 3| = |z + 2i|$

$3$ と $-2i$ を結ぶ線分の垂直二等分線

### (4)

$|z + 2| = 2|z - 1|$

両辺２乗すると $(z + 2)(\bar{z} + 2) = 4(z - 1)(\bar{z} - 1)$

$(z\bar{z} + 2z + 2\bar{z} + 4) = 4(z\bar{z} - z - \bar{z} + 1)$ $3z\bar{z} - 6z - 6\bar{z} = 0$ $z\bar{z} - 2z - 2\bar{z} = 0$

$(z - 2)(\bar{z} - 2) = 4$ $|z - 2| = 2$

これから $2$ を中心とした半径 $2$ の円
