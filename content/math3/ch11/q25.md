### (1)
$(z-w)(\cos\theta + i\sin\theta) + w$ の式について

$z = 5-3i$, $w = 1-i$, $\theta = \frac{\pi}{2}$ から

$$\{(5-3i)-(1-i)\}\left(\cos\frac{\pi}{2} + i\sin\frac{\pi}{2}\right) + (1-i) = (4-2i) + (1-i) = 3 + 3i$$

### (2)
$(z-w)(\cos\theta + i\sin\theta) + w$ の式について

$z = -2+5i$, $w = 1+2i$, $\theta = \frac{2}{3}\pi$ から

$$\{(-2+5i)-(1+2i)\}\left(\cos\frac{2}{3}\pi + i\sin\frac{2}{3}\pi\right) + (1+2i) = (-3+3i)\left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) + 1+2i$$

$$= \frac{3}{2} - \frac{3}{2}\sqrt{3} - i\left(\frac{3}{2} + \frac{3}{2}\sqrt{3}\right) + 1+2i$$

$$= \frac{5-3\sqrt{3}}{2} + i\frac{1-3\sqrt{3}}{2}$$
