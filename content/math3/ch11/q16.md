$\alpha = a + bi$，$\beta = c + di$ とおくと

$$\alpha + \beta = (a+c) + (b+d)i$$

実数であるには $b = -d$ となる

$$\alpha\beta = (a+bi)(c+di) = (ac - bd) + (ad + bc)i$$

実数であるには $ad + bc = 0$ となる

$b = -d$ から $-ab + bc = 0$ $a = c$ これから

$\alpha = a + bi$ なら $\beta = a - bi$ となり 共役複素数となる
