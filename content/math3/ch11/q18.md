$$|\alpha + \beta|^2 + |\alpha - \beta|^2 = 2(|\alpha|^2 + |\beta|^2)$$

左辺 = $(\alpha + \beta)(\overline{\alpha + \beta}) + (\alpha - \beta)(\overline{\alpha - \beta})$

$= \alpha\overline{\alpha} + \alpha\overline{\beta} + \overline{\alpha}\beta + \beta\overline{\beta} + \alpha\overline{\alpha} - \alpha\overline{\beta} - \overline{\alpha}\beta + \beta\overline{\beta}$

$= |\alpha|^2 + |\beta|^2 + |\alpha|^2 + |\beta|^2$

$= 2(|\alpha|^2 + |\beta|^2) = $ 右辺

よって与式は成り立つ
