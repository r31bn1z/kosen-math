### (1)

$$\angle BAC = \arg \frac{\gamma - \alpha}{\beta - \alpha} = \arg \frac{(4-7i)-(2+3i)}{(5+4i)-(2+3i)} = \arg \frac{2+4i}{3+i} = \arg \frac{(2+4i)(3-i)}{10} = \arg(1+i)$$

よって $\angle BAC = \frac{\pi}{4}$

### (2)

$$\angle BAC = \arg \frac{\gamma - \alpha}{\beta - \alpha} = \arg \frac{(\sqrt{3}+i)-(-2i)}{(\sqrt{3}-i)-(-2i)} = \arg \frac{\sqrt{3}+3i}{\sqrt{3}+i} = \arg \frac{(\sqrt{3}+3i)(\sqrt{3}-i)}{4} = \arg \frac{1}{2}(3+\sqrt{3}i)$$

$$= \arg \sqrt{3}\left(\frac{\sqrt{3}}{2} + \frac{1}{2}i\right)$$

よって $\angle BAC = \frac{\pi}{6}$

### (3)

$$\angle BAC = \arg \frac{\gamma - \alpha}{\beta - \alpha} = \arg \frac{(2-5i)-(5-4i)}{(6-2i)-(5-4i)} = \arg \frac{-3-i}{1+2i} = \arg \frac{(-3-i)(1-2i)}{5} = \arg(-1+i)$$

よって $\angle BAC = \frac{3}{4}\pi$
