### (1)
$3-2i$ と $1+5i$

距離 $h = \sqrt{(3-1)^2+(2+5)^2} = \sqrt{4+49} = \sqrt{53}$

### (2)
$-2+i$ と $-3-i$

$h = \sqrt{(-2+3)^2+(1+1)^2} = \sqrt{1+4} = \sqrt{5}$

### (3)
$4+3i$ と $8$

$h = \sqrt{(4-8)^2+3^2} = \sqrt{16+9} = \sqrt{25} = 5$

### (4)
$6$ と $2i$

$h = \sqrt{6^2+2^2} = \sqrt{36+4} = \sqrt{40} = 2\sqrt{10}$
