$x = \frac{\sqrt{3}+i}{2} = \frac{\sqrt{3}}{2} + \frac{1}{2}i = \cos\frac{\pi}{6} + i\sin\frac{\pi}{6}$ これを与式に代入すると

$$\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right)^{3m} + \frac{1}{\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right)^{3m}}$$

$$= \cos\frac{m\pi}{2} + i\sin\frac{m\pi}{2} + \cos\frac{m\pi}{2} - i\sin\frac{m\pi}{2} = 2\cos\frac{m\pi}{2} \quad \text{それから}$$

m：奇数 → 与式は 0

m：４の倍数 → 与式は 2

m：４の倍数以外の偶数 → 与式は-2
