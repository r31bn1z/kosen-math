### (1)
$$(4x^2 y - 3y^2)dx + (x^3 - 3xy)dy = 0$$

積分因数を $x$ だけの関数 $\lambda_{(x)}$ とするとすると

$$P = 4x^2 y - 3y^2、Q = x^3 - 3xy$$として

$$\frac{1}{Q}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{1}{x^3 - 3xy}(3x^2 - 3y - 4x^2 + 6y) = -\frac{1}{x}$$

$$\lambda = \exp\left\{-\int -\frac{1}{x}dx\right\} = x$$

これを与式にかけると

$$(4x^3 y - 3xy^2)dx + (x^4 - 3x^2y)dy = 0$$

$$A = 4x^3 y - 3xy^2、B = x^4 - 3x^2 y$$とおくと
$$\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = 4x^3 - 6xy$$ よって完全微分系である

$$\int Adx = x^4 y - \frac{3}{2}x^2 y^2 = g$$とするとき
$$\frac{\partial g}{\partial y} = x^4 - \frac{3}{2} \cdot 2x^2 y = x^4 - 3x^2y$$
$$B - \frac{\partial g}{\partial y} = 0$$ これから

$$2x^4 y - 3x^2 y^2 = C$$
（C は任意定数）

### (2)
$$(y + xy + \sin y)dx + (x + \cos y)dy = 0$$

$$P = y + xy + \sin y、Q = x + \cos y$$とおき $\lambda$ を積分因数として

$$\frac{1}{Q}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{1}{x + \cos y}\{1-(1+x+\cos y)\} = -1$$

$$\lambda = \exp\left\{-\int -1dx\right\} = e^x$$

これを与式の両辺にかけて

$$(ye^x + xye^x + e^x \sin y)dx + (xe^x + e^x \cos y)dy = 0$$

$$A = ye^x + xye^x + e^x \sin y、B = xe^x + e^x \cos y$$とおくと

$$\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = e^x + xe^x + e^x \cos y$$ よって完全微分系である

$$\int Adx = xye^x + e^x \sin y = g$$とするとき
$$\frac{\partial g}{\partial y} = xe^x + e^x \cos y$$
$$B - \frac{\partial g}{\partial y} = 0$$ これから

$$e^x(xy + \sin y) = C$$
（C は任意定数）

### (3)
$$3x^2 y dx + (2x^3 - 4y^2) dy = 0$$

$P = 3x^2 y, Q = 2x^3 - 4y^2$ とおき、$\lambda$ を積分因数とするとき

$$\frac{1}{P}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{1}{3x^2 y}(6x^2 - 3x^2) = \frac{1}{y} \quad \lambda = \exp\left(\int_y dy\right) = y \quad \text{これを与式の両辺にかけて}$$

$$3x^2 y^2 dx + (2x^3 y - 4y^3) dy = 0$$

$A = 3x^2 y^2, B = 2x^3 y - 4y^3$ とおくと $\displaystyle \frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = 6x^2 y$ よって完全微分系である

$$\int A dx = x^3 y^2 = g \text{ とするとき } \frac{\partial g}{\partial y} = 2x^3 y \quad B - \frac{\partial g}{\partial y} = -4y^3 \quad \int\left(B - \frac{\partial g}{\partial y}\right)dy = y^4 \quad \text{これから}$$

$$x^3 y^2 - y^4 = C \quad \text{（C \text{は任意定数}）}$$

### (4)
$$(y^3 + 2xy^2 + y + 2x)dx + x(2y^2 + xy + 1)dy = 0$$

$P = y^3 + 2xy^2 + y + 2x, Q = x(2y^2 + xy + 1)$ とおき $\lambda$ を積分因数とすると

$$\frac{1}{P}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{1}{y^3 + 2xy^2 + y + 2x}\{2y^2 + 2xy + 1 - (3y^2 + 4xy + 1)\} = \frac{-y}{y^2 + 1}$$

$$\lambda = \exp\left(\int \frac{-y}{y^2 + 1} dy\right) = \exp\left(-\frac{1}{2}\log(y^2 + 1)\right) = \frac{1}{\sqrt{y^2 + 1}} \quad \text{これを与式の両辺にかけて}$$

$$\frac{1}{\sqrt{y^2 + 1}}(y^3 + 2xy^2 + y + 2x)dx + \frac{x}{\sqrt{y^2 + 1}}(2y^2 + xy + 1)dy = 0$$

$A = \displaystyle \frac{1}{\sqrt{y^2 + 1}}(y^3 + 2xy^2 + y + 2x), B = \frac{x}{\sqrt{y^2 + 1}}(2y^2 + xy + 1)$ とおくと

$$\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = \frac{1}{\sqrt{y^2 + 1}}(2y^2 + 2xy + 1) \quad \text{よって完全微分系である}$$

$$\int Adx = \sqrt{y^2 + 1}(xy + x^2) = g \text{ とするとき } \frac{\partial g}{\partial y} = \frac{y}{\sqrt{y^2 + 1}}(xy + x^2) + \sqrt{y^2 + 1} \cdot x \quad B - \frac{\partial g}{\partial y} = 0$$

これから

$$\sqrt{y^2 + 1}(xy + x^2) = C \quad \text{（C \text{は任意定数}）}$$

### (5)
$$(x^3y^3 - y)dx + (x^3y^3 - x)dy = 0$$

$P = x^3y^3 - y, \quad Q = x^3y^3 - x$ とおき $\lambda$ を積分因数すると

$$\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) \frac{1}{xP - yQ} = \{3x^2y^3 - 1 - (3x^2y^3 - 1 - (3x^2y^3 - 1))\} \frac{1}{x^3y^3 - xy - (x^3y^3 - xy)} = \frac{3}{xy}$$

$$\lambda = \exp\left(\int -\frac{3}{xy}dxy\right) = \frac{1}{x^3y^3}$$ これを与式の両辺にかけて

$$\left(1 - \frac{1}{x^3y^2}\right)dx + \left(1 - \frac{1}{x^2y^3}\right)dy = 0$$

$$A = 1 - \frac{1}{x^3y^2}, \quad B = 1 - \frac{1}{x^2y^3}$$ とおくと $$\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = \frac{2}{x^3y^3}$$ よって完全微分系である

$$\int Adx = x + \frac{1}{2x^2y^3} = g$$ とするとき $$\frac{\partial g}{\partial y} = -\frac{1}{x^2y^3}$$, $$B - \frac{\partial g}{\partial y} = 1$$ これから

$$x + \frac{1}{2x^2y^3} + y = C$$ （$C$ は任意定数）
