### (1)
$$(x+y)^2 \frac{dy}{dx} = 4$$

$x+y=u$ とおくと $\dfrac{dy}{dx} = \dfrac{du}{dx} - 1$ これから

$$u^2\left(\frac{du}{dx} - 1\right) = 4 \qquad \frac{du}{dx} = \frac{4+u^2}{u^2}$$

$$\int \frac{u^2}{4+u^2}\,du = \int dx \qquad \int\left(1 - \frac{4}{4+u^2}\right)du = \int dx \qquad u - 2\tan^{-1}\frac{u}{2} = x + C \qquad \text{元に戻して}$$

$$x + y - 2\tan^{-1}\frac{x+y}{2} = x + C$$

$$y = 2\tan^{-1}\frac{x+y}{2} + C \qquad (\text{C \text{は任意定数}})$$

### (2)
$$\frac{dy}{dx} = \frac{2x-4y+3}{x-2y-1} \qquad x-2y-1=u \text{ とおくと} \qquad \frac{dy}{dx} = \frac{1}{2}\left(1-\frac{du}{dx}\right) \qquad \text{これから}$$

$$\frac{1}{2}\left(1-\frac{du}{dx}\right) = \frac{2u+5}{u} \qquad 1 - \frac{du}{dx} = \frac{4u+10}{u} \qquad \frac{du}{dx} = \frac{-3u-10}{u}$$

$$-\int \frac{u}{3u+10}\,du = \int dx \qquad -\int\left(\frac{1}{3} - \frac{10}{3}\cdot\frac{1}{10+3u}\right)du = \int dx$$

$$-\frac{1}{3}u + \frac{10}{9}\log(10+3u) = x + C_1 \qquad 9C_1 = C_2 \text{ とおくと}$$

$$-3u + 10\log(3u+10) = 9x + C_2 \qquad \text{元に戻して}$$

$$-3x+6y+3+10\log(3x-6y-3+10) = 9x + C_2 \qquad -\frac{1}{2}(C_2-3) = C \text{ とおくと}$$

$$6x - 3y - 5\log(3x-6y+7) = C \qquad (\text{C \text{は任意定数}})$$

### (3)

$$\frac{dy}{dx} + \frac{y}{x} = (3x+2)xy \qquad xy = u \text{ とおくと} \qquad y + x\frac{dy}{dx} = \frac{du}{dx}$$

与式を整理して $x\dfrac{dy}{dx} + y = (3x+2)x^2 y$ これから

$$\frac{du}{dx} = ux(3x+2)$$

$$\int \frac{1}{u} du = \int x(3x+2) dx \qquad \log u = x^3 + x^2 + C \qquad \text{元に戻して}$$

$$\log xy = x^3 + x^2 + C \qquad (\text{C \text{は任意定数}})$$

### (4)

$$x\frac{dy}{dx} - y = \frac{y^2 - x^2}{x^2 - 1} \qquad y = xu \text{ とおくと} \qquad \frac{dy}{dx} = u + x\frac{du}{dx} \qquad \text{これから}$$

$$x\left(u + x\frac{du}{dx}\right) - xu = \frac{x^2 u^2 - x^2}{x^2 - 1} \qquad \frac{du}{dx} = \frac{u^2 - 1}{x^2 - 1}$$

$$\int \frac{1}{u^2 - 1} du = \int \frac{1}{x^2 - 1} dx \qquad \frac{1}{2}\log\frac{u-1}{u+1} = \frac{1}{2}\left(\log\frac{x-1}{x+1} + C_1\right) \qquad e^{C_1} = C \text{ とおくと}$$

$$\frac{(u-1)(x+1)}{(u+1)(x-1)} = C \qquad (u-1)(x+1) = C(u+1)(x-1) \qquad \text{元に戻して}$$

$$\left(\frac{y}{x} - 1\right)(x+1) = C\left(\frac{y}{x} + 1\right)(x-1) \qquad (y-x)(x+1) = C(y+x)(x-1) \qquad (\text{C \text{は任意定数}})$$
