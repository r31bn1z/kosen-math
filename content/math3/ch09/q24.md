$y' = x + 2xy$
$\frac{dy}{dx} = x + 2xy$
$\frac{dy}{dx} - 2xy = x$

$P = -2x$、$Q = x$ とおくと
$\int Pdx = -x^2$ これから

$y = e^{x^2} \{ \int e^{-x^2} dx + C \} = e^{x^2} \{-\frac{1}{2} e^{-x^2} + C\} = -\frac{1}{2} + Ce^{x^2}$

$e^{x^2}$ をマクローリン展開すると $f_{(x)} = e^{x^2}$ として

$f'_{(x)} = 2xe^{x^2}$
$f''_{(x)} = 2e^{x^2} + 4x^2 e^{x^2}$
$$f'''_{(x)} = 12xe^{x^2} + 8x^3 e^{x^2}$$

$f^{(4)}_{(x)} = 4e^{x^2} + 8x^2 e^{x^2} + 8e^{x^2} + 16x^2 e^{x^2} + 24x^2 e^{x^2} + 16x^4 e^{x^2}$ これから

$e^{x^2} = 1 + \frac{2}{2!} x^2 + \frac{12}{4!} x^4 + \cdots$ よって

$$y = -\frac{1}{2} + C\left(1 + x^2 + \frac{x^4}{2!} + \frac{x^6}{3!} + \cdots + \frac{x^{2n}}{n!} + \cdots\right)$$（$C$は任意定数）
