### (1)
$$2ydx - xdy = 0$$

$P = 2y$、$Q = -x$ とおき $\lambda$ を積分因数として

$$f_{(x)} = \frac{1}{Q}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{-1}{x}(-1-2) = \frac{3}{x}$$ and $$\int f_{(x)}dx = 3\log x$$

$$\lambda_{(x)} = e^{-3\log x} = \frac{1}{x^3}$$ これを与式の両辺にかけて

$$2\frac{y}{x^3}dx - \frac{1}{x^2}dy = 0$$ and $$2ydy = xdy$$

$$2\int\frac{1}{x}dx = \int\frac{1}{y}dy$$ and $$2\log x + C_1 = \log y$$ and $$e^{C_1} = C$$ とおくと

$$Cx^2 = y$$ （C は任意定数）

### (2)
$$(x-y)dx + xdy = 0$$

$P = x - y$、$Q = x$ とおき $\lambda$ を積分因数として

$$\frac{1}{Q}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{2}{x}$$ and $$\lambda = \exp\left(-\int\frac{2}{x}dx\right) = \frac{1}{x^2}$$ これを与式の両辺にかけて

$$\frac{x-y}{x^2}dx + \frac{1}{x}dy = 0$$

$A = \frac{x-y}{x^2}$、$B = \frac{1}{x}$ とおくと $$\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = -\frac{1}{x^2}$$ よって完全微分式である

$$\int Adx = \log x + \frac{y}{x} = g$$ とおくと $$\frac{\partial g}{\partial y} = \frac{1}{x}$$ and $$B - \frac{\partial g}{\partial y} = 0$$ これから

$$\log x + \frac{y}{x} = C$$ （C は任意定数）

### (3)
$$y(y - x)dx + x^2dy = 0$$

$\lambda$を積分因数とする。令$x = x^m y^n$と仮定して与式の両辺にかけて

$$(x^m y^{n+1} - x^{m+1}y^{n+1})dx + x^{m+2}y^n dy = 0$$

$$P = x^m y^{n+2} - x^{m+1}y^{n+1}、Q = x^{m+2}y^n$$として

$$\frac{\partial P}{\partial y} = (n + 2)x^m y^{n+1} - (n+1)x^{m+1}y^n \quad \frac{\partial Q}{\partial x} = (m+2)x^{m+1}y^n$$

完全微分系となるには$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$とならばよいので

$$(n + 2)x^m y^{n+1} - (n+1)x^{m+1}y^n = (m + 2)x^{m+1}y^n \quad (m + n + 3)x - (n + 2)y = 0 \quad \therefore m = -1, n = -2$$

よって$\lambda = \frac{1}{xy^2}$となる。これを与式の両辺にかけて

$$\left(\frac{1}{x} - \frac{1}{y}\right)dx + \frac{x}{y^2}dy = 0$$

$$A = \frac{1}{x} - \frac{1}{y}、B = \frac{x}{y^2}$$とおくと $\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = -\frac{1}{y^2}$ よって完全微分系である

$$\int Adx = \log x - \frac{x}{y} = g$$とするのと $\frac{\partial g}{\partial y} = \frac{x}{y^2}$、$B - \frac{\partial g}{\partial y} = 0$ これから

$$\log x - \frac{x}{y} = C \quad（C\text{は任意定数）}$$

### (4)
$$(x^2 \cos x - y)dx + xdy = 0$$

$$P = x^2 \cos x - y、Q = x$$とおき$\lambda$を積分因数として

$$\frac{1}{Q}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{2}{x} \quad \lambda = \exp\left(-\int \frac{2}{x}dx\right) = \frac{1}{x^2}$$これを与式の両辺にかけて

$$\left(\cos x - \frac{y}{x^2}\right)dx + \frac{1}{x}dy = 0$$

$$A = \cos x - \frac{y}{x^2}、B = \frac{1}{x}$$とおくと $\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = -\frac{1}{x^2}$ よって完全微分系である

$$\int Adx = \sin x + \frac{y}{x} = g$$
とするとき $\frac{\partial g}{\partial y} = \frac{1}{x}$, $B - \frac{\partial g}{\partial y} = 0$ これから

$x\sin x + y = Cx$ （C は任意定数）

### (5)

$y(y^2 + 1)dx + x(y^2 - 1)dy = 0$

$\lambda$ を積分因数とする。今 $\lambda = x^m y^n$ と仮定して与式の両辺にかけて

$(x^m y^{n+3} + x^m y^{n+1})dx + (x^{m+1} y^{n+2} - x^{m+1} y^n)dy = 0$

$P = x^m y^{n+3} + x^m y^{n+1}$, $Q = x^{m+1} y^{n+2} - x^{m+1} y^n$ とおくと

$\frac{\partial P}{\partial y} = (n+3)x^m y^{n+2} + (n+1)x^m y^n$, $\frac{\partial Q}{\partial x} = (m+1)x^m y^{n+2} - (m+1)x^m y^n$

完全微分系となるには $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ とならばよいので

$(n+3)x^m y^{n+2} + (n+1)x^m y^n = (m+1)x^m y^{n+2} - (m+1)x^m y^n$

$(m - n - 2)y^2 - (m + n + 2) = 0$ $\therefore m = 0, n = -2$

よって $\lambda = \frac{1}{y^2}$ となる。これを与式の両辺にかけて

$$\left(y + \frac{1}{y}\right)dx + \left(x - \frac{x}{y^2}\right)dy = 0$$

$A = y + \frac{1}{y}$, $B = x - \frac{x}{y^2}$ とおくと $\frac{\partial A}{\partial y} - \frac{\partial B}{\partial x} = 1 - \frac{1}{y^2}$ よって完全微分系である

$$\int Adx = xy + \frac{x}{y} = g$$
として $\frac{\partial g}{\partial y} = x - \frac{x}{y^2}$, $B - \frac{\partial g}{\partial y} = 0$ これから

$xy + \frac{x}{y} = C$ （C は任意定数）

### (6)
$(x^2 + y + 1)dx - xdy = 0$

$P = x^2 + y + 1$、$Q = -x$ とおき、$\lambda$を積分因数として

$$\frac{1}{Q}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = \frac{2}{x}$$

$$\lambda = \exp\left(-\int \frac{2}{x}dx\right) = \frac{1}{x^2}$$ これを与式の両辺にかけると

$$\left(1 + \frac{y}{x^2} + \frac{1}{x^2}\right)dx - \frac{1}{x}dy = 0$$

$A = 1 + \frac{y}{x^2} + \frac{1}{x^2}$、$B = -\frac{1}{x}$ とおくと $\frac{\partial A}{\partial y} = \frac{\partial B}{\partial x} = \frac{1}{x^2}$ よって完全微分系である

$\int Adx = x - \frac{y}{x} - \frac{1}{x} = g$ とするも $\frac{\partial g}{\partial y} = -\frac{1}{x}$、$B - \frac{\partial g}{\partial y} = 0$ これから

$$x^2 - y - 1 = Cx$$ （C は任意定数）
