### (1)
$xy' + y = 1 - x^2$

$y' + \frac{1}{x}y = \frac{1}{x} - x$

$P = \frac{1}{x}$、$Q = \frac{1}{x} - x$ とおくと $\int Pdx = \log x$ これから

$$y = e^{-\log x}\left[\int e^{\log x}\left(\frac{1}{x} - x\right)dx + C\right] = \frac{1}{x}\int (1 - x^2)dx + C] = \frac{1}{x}\left[x - \frac{1}{3}x^3 + C\right]$$

$$= 1 - \frac{1}{3}x^2 + \frac{C}{x}$$（$C$ は任意定数）

### (2)
$(1 + x^2)y' = xy + 1$    $y' = \frac{x}{1 + x^2}y = \frac{1}{1 + x^2}$

$P = -\frac{x}{x^2 + 1}$、$Q = \frac{1}{1 + x^2}$ とおくと $\int Pdx = -\frac{1}{2}\log(x^2 + 1) = \log(x^2 + 1)^{-\frac{1}{2}}$ これから

$$y = \sqrt{x^2 + 1}\left[\int \left(\frac{1}{\sqrt{x^2 + 1}} - \frac{1}{x^2 + 1}\right)dx + C\right]$$

$$\int \frac{1}{\sqrt{x^2 + 1}} - \frac{1}{x^2 + 1}dx \quad x = \tan \theta \text{ とおくと} \quad dx = \frac{1}{\cos^2 \theta}d\theta \text{ これから}$$

$$= \int \frac{1}{\sqrt{\frac{\sin^2 \theta + \cos^2 \theta}{\cos^2 \theta}}} \cdot \frac{1}{\frac{\sin^2 \theta + \cos^2 \theta}{\cos^2 \theta}}d\theta = \int \cos \theta d\theta = \sin \theta \quad \text{元に戻して}$$

$$= \sin(\tan^{-1}x) \to \frac{x}{\sqrt{x^2 + 1}} \text{ これから}$$

$$y = \sqrt{x^2 + 1}\left[\frac{x}{\sqrt{x^2 + 1}} + C\right] = x + C\sqrt{x^2 + 1}$$（$C$ は任意定数）

### (3)
$xy' + y = \log x$   $y' + \frac{1}{x}y = \frac{1}{x}\log x$

$P = \frac{1}{x}$，$Q = \frac{1}{x}\log x$ とおくと $\int Pdx = \log x$ これから

$y = \frac{1}{x}\left\{\int\left(x \cdot \frac{1}{x} dx + C\right)\right\} = \frac{1}{x}(x \log x - x + C) = \log x - 1 + \frac{C}{x}$   （$C$ は任意定数）

### (4)
$y'\cos x + y \sin x = \sin x \cdot \cos^2 x$   $y' + y \cdot \frac{\sin x}{\cos x} = \sin x \cdot \cos x$

$P = \frac{\sin x}{\cos x}$，$Q = \sin x \cdot \cos x$ とおくと $\int Pdx = \int \frac{\sin x}{\cos x} dx$ $\cos x = t$ とおくと

$\int Pdx = \int \left(-\frac{1}{t}\right) dt = -\log t$  元に戻して $\int Pdx = -\log(\cos x)$  これから

$y = \cos x\left\{\int \frac{\sin x \cdot \cos x}{\cos x} dx + C\right\} = \cos x\{\int \sin x dx + C\} = \cos x(-\cos x + C)$

$= C \cos x - \cos^2 x$   （$C$ は任意定数）

### (5)
$(2x + 1)y' - x + y = 0$   $y' + \frac{x}{2x+1}y = \frac{x}{2x+1}$

$P = \frac{1}{2x+1}$，$Q = \frac{x}{2x+1}$ とおくと $\int Pdx = \frac{1}{2}\log(2x+1)$  これから

$y = \frac{1}{\sqrt{2x+1}}\left\{\int\sqrt{2x+1} \cdot \frac{x}{2x+1} dx + C\right\} = \frac{1}{\sqrt{2x+1}} \cdot \frac{1}{2}\left[\int\sqrt{2x+1} - \frac{1}{2x+1} dx + C\right]$

$= \frac{1}{\sqrt{2x+1}} \cdot \frac{1}{2}\left[\frac{1}{3}(2x+1)^{3/2} - \sqrt{2x+1}\right] + C\} = \frac{1}{6}(2x+1) - \frac{1}{2} + \frac{C}{\sqrt{2x+1}}$

$= \frac{x-1}{3} + \frac{C}{\sqrt{2x+1}}$   （$C$ は任意定数）

### (6)

$$(1+x^2)y'+xy = 0$$

$$y'+\frac{x}{1+x^2}y = \frac{1}{1+x^2}$$

$$P=\frac{x}{1+x^2}, \quad Q=\frac{1}{1+x^2} \text{ とおくと } \int Pdx = \frac{1}{2}\log(1+x^2)$$

$$y = \frac{1}{\sqrt{1+x^2}}\left\{\int\frac{\sqrt{1+x^2}}{1+x^2}dx+C\right\} = \frac{1}{\sqrt{1+x^2}}\left\{\int\frac{1}{\sqrt{1+x^2}}dx+C\right\}$$

$$= \frac{1}{\sqrt{1+x^2}}\left(\log|x+\sqrt{x^2+1}|+C\right) \quad \text{（C \text{は任意定数}）}$$
