### (1)

$$y' + y = xy^2 \quad \frac{1}{y^2}y' + \frac{1}{y} = x$$

$u = \frac{1}{y}$ とおくと $\frac{du}{dx} = -\frac{1}{y^2}\frac{dy}{dx}$ これから

$$-\frac{du}{dx} + u = x \quad \frac{du}{dx} - u = -x$$

$P = -1, Q = -x$ とおくと $\int Pdx = -x$

$$u = e^x \left\{ \int e^{-x}(-x)dx + C \right\} = e^x \left\{ xe^{-x} - \int e^{-x}dx + C \right\} = e^x \left\{ xe^{-x} + e^{-x} + C \right\} = x + 1 + Ce^x \text{ 元に戻して}$$

$$\frac{1}{y} = x + 1 + Ce^x \quad 1 = y(x + 1 + Ce^x) \quad (C\text{は任意定数})$$

（別）

$$y' + y = xy^2 \text{ であったとき } \frac{1}{y^3}y' + \frac{1}{y^2} = x$$

$u = \frac{1}{y^2}$ とおくと $\frac{du}{dx} = -\frac{2}{y^3}\frac{dy}{dx}$ これから

$$-\frac{1}{2}\frac{du}{dx} + u = x \quad \frac{du}{dx} - 2u = -2x$$

$P = -2, Q = -2$ とおくと $\int Pdx = -2x$ これから

$$u = e^{2x}\left\{\int e^{-2x}(-2x)dx + C\right\} = e^{2x}\{xe^{-2x} - \int e^{-2x}dx + C\} = e^{2x}\left\{xe^{-2x} + \frac{1}{2}e^{-2x} + C\right\} = x + \frac{1}{2} + Ce^{2x}$$

元に戻して

$$\frac{1}{y^2} = x + \frac{1}{2} + Ce^{2x} \quad 1 = y^2\left(x + \frac{1}{2} + Ce^{2x}\right) \quad 2C = C \text{ と書き直して } y^2(Ce^{2x} + 2x + 1) = 2$$

### (2)

$$2xyy' - y^2 + x = 0 \quad y' - \frac{1}{2x}y = -\frac{1}{2}y^{-1}$$

$u = \frac{1}{y^2} = y^2$ とおくと $\frac{dy}{dx} = \frac{1}{2\sqrt{u}}\frac{du}{dx}$ これから

$$\frac{1}{2\sqrt{u}} \cdot \frac{du}{dx} = \frac{1}{2x}\sqrt{u} = -\frac{1}{2}\sqrt{u}$$

$$\frac{du}{dx} - \frac{1}{x}u = -1$$

$P = -\frac{1}{x}$, $Q = -1$ とおくと $\int Pdx = -\log x$ これから

$$u = x\left[\int -\frac{1}{x}dx + C\right] = x(-\log x + C)$$

$$y^2 = x(C - \log x) \quad (C \text{は任意定数})$$

### (3)

$$xy' + y = y^2 \log x$$

$$y' + \frac{1}{x}y = \frac{1}{x}\log x \cdot y^2$$

$u = \frac{1}{y}$ とおくと $\frac{du}{dx} = -\frac{1}{y^2}\frac{dy}{dx}$ これから

$$-\frac{du}{dx} + \frac{1}{x}u = \frac{1}{x}\log x$$

$$\frac{du}{dx} - \frac{1}{x}u = -\frac{1}{x}\log x$$

$P = -\frac{1}{x}$, $Q = -\frac{1}{x}\log x$ とおくと $\int Pdx = -\log x$ これから

$$u = x\left[\int -\frac{1}{x^2}\log x dx + C\right] = x\left[-\log x \cdot \left(-\frac{1}{x}\right) - \int \frac{1}{x^2}dx + C\right] = x\left[\frac{\log x}{x} + \frac{1}{x} + C\right] = \log x + 1 + Cx$$

元に戻して整理すると

$$1 = y(\log x + 1 + Cx) \quad (C \text{は任意定数})$$

### (4)

$$y' + y = y^2(\cos x - \sin x)$$

$u = \frac{1}{y}$ とおくと $\frac{dy}{dx} = -\frac{1}{u^2}\frac{du}{dx}$ これから

$-\frac{1}{u^2}\frac{du}{dx} + \frac{1}{u} = -\frac{1}{u^2}(\cos x - \sin x)$ $\quad$ $\frac{du}{dx} - u = -(\cos x - \sin x)$

$P = -1, Q = -(\cos x - \sin x)$ とおくと $\quad$ $\int Pdx = -x$ これから

$u = e^x\{\int e^x(-\cos x + \sin x)dx + C\}$

$I = \int e^x(-\cos x + \sin x)dx$ とおくと

$= -e^x(-\cos x + \sin x) + \int e^x(\sin x + \cos x)dx$

$= -e^x(-\cos x + \sin x) - e^x(\sin x + \cos x) + \int e^x(\cos x - \sin x)dx = -e^x(2\sin x) - I$

$2I = -e^x(2\sin x)$ $\quad$ $I = -e^x\sin x$ これから

$u = e^x(-e^x\sin x + C)$ 元に戻して整理すると

$$1 = y(Ce^x - e^x\sin x)$$
 (C は任意定数)
