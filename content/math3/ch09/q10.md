### (1)

$(y-2x)dx + xdy = 0$

$P = y - 2x$、$Q = x$ とおくと $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 1$ よって完全微分である

$\int Pdx = xy - x^2 = g$ とするとき $\frac{\partial g}{\partial y} = x$ これから

$xy - x^2 + \int (x-x)dy = C$   $xy - x^2 = C$ （$C$ は任意定数）

### (2)

$(y+3x)dx + xdy = 0$

$P = y + 3x$、$Q = x$ とおくと $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 1$ よって完全微分である

$\int Pdx = xy + \frac{3}{2}x^2 = g$ とするとき $\frac{\partial g}{\partial y} = x$ これから

$xy + \frac{3}{2}x^2 + \int (x-x)dy = C_1$   $xy + \frac{3}{2}x^2 = C_1$   $2C_1 = C$ とおくと

$3x^2 + 2xy = C$ （$C$ は任意定数）

### (3)

$2xydx + (1+x^2)dy = 0$

$P = 2xy$、$Q = 1 + x^2$ とおくと $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 2x$ よって完全微分である

$\int Pdx = x^2 y = g$ とするとき $\frac{\partial g}{\partial y} = x^2$ これから

$x^2 y + \int (1 + x^2 - x^2)dy = C$   $x^2 y + y = C$

（$C$ は任意定数）

### (4)
$$(x^2 - y)dx + (y^2 - x)dy = 0$$

$$P = x^2 - y, \quad Q = y^2 - x \text{ とおくと}$$

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = -1 \text{ よって完全微分系である}$$

$$\int Pdx = \frac{1}{3}x^3 - xy = g \text{ とするど} \quad \frac{\partial g}{\partial y} = -x \text{ これから}$$

$$\frac{1}{3}x^3 - xy + \int(y^2 - x + x)dy = C_1$$

$$\frac{1}{3}x^3 - xy + \frac{1}{3}y^3 = C_1, \quad 3C_1 = C \text{ とおくと}$$

$$x^3 - 3xy + y^3 = C \quad （C \text{は任意定数}）$$

### (5)
$$(x^2 - 4xy - 2y^2)dx + (y^2 - 4xy - 2x^2)dy = 0$$

$$P = x^2 - 4xy - 2y^2, \quad Q = y^2 - 4xy - 2x^2 \text{ とおくと}$$

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = -4x - 4y \text{ よって完全微分系である}$$

$$\int Pdx = \frac{1}{3}x^3 - 2x^2y - 2xy^2 = g \text{ とするど} \quad \frac{\partial g}{\partial y} = -2x^2 - 4xy \text{ これから}$$

$$\frac{1}{3}x^3 - 2x^2y - 2xy^2 + \int(y^2 - 4xy - 2x^2 + 2x^2 + 4xy)dy = C_1$$

$$\frac{1}{3}x^3 - 2x^2y - 2xy^2 + \frac{1}{3}y^3 = C_1$$

$$3C_1 = C \text{ とおくと}$$

$$x^3 - 6x^2y - 6xy^2 + y^3 = C \quad （C \text{は任意定数}）$$
