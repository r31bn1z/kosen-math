### (1)
$(4xy-3)d + 2x^2 ydy = 0$

$(4xy-3) + 2x^2 \frac{dy}{dx} = 0$ と置くと $xy = u$ と置くと
$x \frac{dy}{dx} = \frac{du}{dx} - y = \frac{du}{dx} - \frac{u}{x}$ これから

$4u - 3 + 2x\left(\frac{du}{dx} - \frac{u}{x}\right) = 0$ と $2x\frac{du}{dx} + 2u - 3 = 0$

$\int \frac{1}{3-2u} du = \int \frac{1}{2x} dx$ と $-\frac{1}{2}\log(3-2u) = \frac{1}{2}(\log x + C_1)$ と $-C_1 = C$ と置くと

$C = x(3-2u)$ 元に戻して $C = x(3-2xy)$ （$C$ は任意定数）

### (2)
$y(1+xy)dx + x(1-xy)dy = 0$

$\frac{dy}{dx} = -\frac{y(1+xy)}{x(1-xy)}$ と $xy = u$ と置くと
$\frac{dy}{dx} = \frac{1}{x^2}\left(x\frac{du}{dx} - u\right)$ これから

$\frac{1}{x^2}\left(x\frac{du}{dx} - u\right) = -\frac{u(1+u)}{x(1-u)}$ と $x\frac{du}{dx} = -\frac{2u^2}{1-u}$

$-\int \frac{1-u}{2u^2} du = \int dx$ と $\frac{1}{2}\int\left(-\frac{1}{u^2} + \frac{1}{u}\right) du = \int \frac{1}{x}dx$

$\frac{1}{2}\left(\frac{1}{u} + \log u\right) = \log x + C_1$ と $2C_1 = C_2$ と置くと

$\log u - \log x^2 = -\frac{1}{u} + C_2$ と $e^{C_2} = C_3$ と置くと

$\frac{u}{x^2} = C_3 e^{-\frac{1}{u}}$ 元に戻して

$\frac{xy}{x^2} = C_3 e^{-\frac{1}{xy}}$ と $C_3^{-1} = C$ と置くと

$$y = Ce^{-\frac{1}{xy}}$$
（$C$ は任意定数）
