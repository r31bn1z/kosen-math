### (1)
$f_{(v)} = mg - Rv$

$m\frac{dv}{dt} = mg - Rv$ $\frac{dv}{dt} = g - \frac{R}{m}v$

$\int \frac{m}{gm - Rv} dv = \int dt$ $-\frac{m}{R}\log|gm - Rv| = t + C_1$

$\log|gm - Rv| = -\frac{Rt + RC_1}{m}$ $e^{-\frac{Rt}{m}} = C$ とおくと

$gm - Rv = Ce^{-\frac{Rt}{m}}$ $v = \frac{gm}{R} - \frac{C}{R}e^{-\frac{Rt}{m}}$ $k = \sqrt{\frac{R}{mg}}$ とおくと

$v = \frac{1}{k^2} + \frac{C}{k^2}e^{-k^2gt} = \frac{1}{k^2}(1 + Ce^{-k^2gt})$ （$C$ は任意定数）

### (2)
$f_{(v)} = mg - Rv^2$

$m\frac{dv}{dt} = mg - Rv^2$ $\frac{dv}{dt} = g - \frac{R}{m}v^2$

$\int \frac{1}{\frac{R}{m}v^2 - g} dv = -\int dt$ $\frac{m}{R} \cdot \frac{1}{2\sqrt{\frac{mg}{R}}} \log\left|v - \sqrt{\frac{mg}{R}}\right| = -t + C_1$ $k = \sqrt{\frac{R}{mg}}$ とおくと

$\frac{1}{2gk}\log\left|\frac{kv-1}{kv+1}\right| = -t + C_1$

$\log\left|\frac{kv-1}{kv+1}\right| = -2gkt + 2gkC_1$ $e^{2gkt}C$ とおくと

$\frac{kv-1}{kv+1} = Ce^{-2gkt}$ $1 - \frac{2}{kv+1} = Ce^{-2gkt}$ $kv + 1 = \frac{2}{1 + Ce^{-2gkt}}$

$v = \frac{1}{k} \cdot \frac{1 - Ce^{-2gkt}}{1 + Ce^{-2gkt}}$ （$C$ は任意定数）

### (3)

$f_{(v)} = mg - R \cdot e^{av}$

$m\frac{dv}{dt} = mg - R \cdot e^{av}$

$\int \frac{m}{mg - R \cdot e^{av}} dv = \int dt$ $\int \frac{me^{-av}}{mge^{-av} - R} dv = \int dt$ $-\frac{1}{ag}\log(mge^{-av} - R) = t + C_1$

$\log(mge^{-av} - R) = -ag(t + C_1)$ $e^{-agC_1} = C$ と おくと

$mge^{-av} - R = Ce^{-agt}$ $e^{-av} = \frac{1}{mg}(Ce^{-agt} + R)$

$v = -\frac{1}{a}\log\left\{\frac{1}{mg}(Ce^{-agt} + R)\right\}$ $k = \sqrt{\frac{R}{mg}}$ と おくと

$v = -\frac{1}{a}\log\left\{\frac{1}{mg}(Ce^{-agt} + R)\right\}$ （C は比定数）
