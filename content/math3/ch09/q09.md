原点から接線までの距離は接線の方程式が

$y = y'x$ であるので

点 $P(x,y)$ から直線 $y - y'x = 0$ までの距離 $h$ は

$$h = \frac{|y - y'x|}{\sqrt{1+(-y')^2}} = |x|$$

$$(y-xy')^2 = (1+y'^2)x^2 \qquad y^2 - 2xyy' + x^2y'^2 = x^2 + x^2y'^2 \qquad y^2 - 2xyy' = x^2$$

$$-\frac{1}{2}\cdot\frac{y}{x} + y' = -\frac{x}{2y}$$

$\dfrac{y}{x} = u$ とおくと $y' = u + xu'$ これから

$$-\frac{1}{2}u + \left(u + x\frac{du}{dx}\right) = -\frac{1}{2u} \qquad x\frac{du}{dx} = \frac{-1-u^2}{2u}$$

$$\int \frac{-2u}{u^2+1}\,du = \int \frac{1}{x}\,dx \qquad -\log(u^2+1) = \log x + C_1 \qquad e^{-C_1} = C \text{とおくと}$$

$$x(u^2+1) = C \qquad \text{元に戻して整理すると}$$

$$y^2 + x^2 = Cx \qquad (\text{C \text{は任意定数}})$$
