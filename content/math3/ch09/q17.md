### (1)
$y' + (2x-1)y - (x-1)y^2 = x$

1つの特殊解を見いだすために $y$ に值を代入して考えるも

$y_1 = 1$ が1つの特殊解となる

$y = 1 + v$ とおくと $\frac{dy}{dx} = \frac{dv}{dx}$ これから

$\frac{dv}{dx} + (2x-1)(1+v) - (x-1)(1+v)^2 = x$ および $\frac{dv}{dx} + v = (x-1)v^2$

$u = \frac{1}{v}$ とおくと $\frac{du}{dx} = -\frac{1}{v^2}\frac{dv}{dx}$ これから

$\frac{du}{dx} - u = -(x-1)$

$P = -1$、$Q = -x + 1$ とおくと $\int Pdx = -x$

$u = e^x\{\int e^{-x}(-(x-1))dx + C\} = e^x\{(x-1)e^{-x} - \int e^{-x}dx + C\} = e^x\{(x-1)e^{-x} + e^{-x} + C\} = x + Ce^x$

元に戻して

$1 + v(x + Ce^x)$ 元に戻して

$y = 1 + \frac{1}{x + Ce^x}$

（Cは任意定数）

### (2)
$$y' - \frac{y}{x} + y^2 = x^2$$

１つの特殊解は $y_1 = x$ $y = x + v$ とおくと $\frac{dy}{dx} = 1 + \frac{dv}{dx}$ これから

$$1 + \frac{dv}{dx} = \frac{x+v}{x} + (x+v)^2 = x^2$$

$$\frac{dv}{dx} + (2x - \frac{1}{x})v = -v^2$$

$u = \frac{1}{v}$ とおくと $\frac{dv}{dx} = -\frac{1}{u^2}\frac{du}{dx}$ これから

$$-\frac{1}{u^2}\frac{du}{dx} + (2x - \frac{1}{x})\frac{1}{u} = -\frac{1}{u^2}$$

$$\frac{du}{dx} - (2x - \frac{1}{x})u = 1$$

$P = -(2x - \frac{1}{x})$、$Q = 1$ とおくと $\int Pdx = -(x^2 - \log x)$

$$u = e^{x^2 - \log x} \{\int e^{-x^2 + \log x} dx + C\} = \frac{1}{x}e^{x^2}\{\int xe^{-x^2} dx + C\} = \frac{1}{x}e^{x^2}\{-\frac{1}{2}e^{-x^2} + C\} = -\frac{1}{2x} + C\frac{1}{x}e^{x^2}$$

元に戻して

$$\frac{1}{v} = -\frac{1}{2x} + C\frac{1}{x}e^{x^2}$$

元に戻して

$$\frac{1}{x-y} = -\frac{1}{2x} + C\frac{1}{x}e^{x^2} = \frac{-1 + Ce^{x^2}}{2x}$$

$$y = x + \frac{2x}{Ce^{x^2} - 1}$$
（C は任意定数）
