$y = f_{(x)}$ とおくと

$y' = f'_{(x)}$

点 $P(x, y)$ と点 $(0, 2y)$ を通るので傾き $f'_{(x)}$ は

$$f'_{(x)} = -\frac{y}{x}$$ となる

$$\frac{dy}{dx} = -\frac{y}{x}$$

$$\int \frac{1}{y} dy = -\int \frac{1}{x} dx \qquad \log y = -(\log x + C_1) \qquad \log xy = -C_1 \qquad e^{-C_1} = C \ \text{とおくと}$$

$$xy = C \qquad (C \text{は任意定数})$$
