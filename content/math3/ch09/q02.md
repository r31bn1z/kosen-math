### (1)

$$y = 2Cx^2 \qquad C = \dfrac{y}{2x^2} \qquad ① \qquad y' = 4Cx \qquad ②$$

①、②から C を消去して

$$y' = \dfrac{2y}{x} \qquad xy' = 2y$$

### (2)

$$y = Ce^{\frac{x}{2}} \qquad C = \dfrac{y}{e^{\frac{x}{2}}} \qquad ① \qquad y' = \dfrac{C}{2}e^{\frac{x}{2}} \qquad ②$$

①、②から C を消去して

$$y' = \dfrac{y}{2} \qquad 2y' = y$$

### (3)

$$y^2 = C - e^{2x}$$

微分すると

$$2yy' = -2e^{2x} \qquad yy' + e^{2x} = 0$$

### (4)

$$y = x^2 + Cx$$

微分すると

$$y' = 2x + C \qquad C = y' - 2x$$

これを与式に代入して

$$y = x^2 + (y' - 2x)x = x^2 + xy' - 2x^2 \qquad xy' - y - x^2 = 0$$

### (5)

$$y = C(x + C)$$

微分すると

$$y' = C$$

これを与式に代入して

$$y = y'(x + y')$$

### (6)

$$y = C(1 + \cos x)$$

微分すると

$$y' = -C\sin x \qquad C = -\dfrac{y'}{\sin x}$$

これを与式に代入すると

$$y = -\dfrac{y'}{\sin x}(1 + \cos x) \qquad (1 + \cos x)y' + y\sin x = 0$$
