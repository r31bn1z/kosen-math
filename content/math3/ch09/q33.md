### (1)
$$y^2 = Cx$$

$$2yy' = C$$ これを与式に代入して

$$y^2 = 2yy'x$$ と $$y = 2yy'$$ （曲線群の微分方程式）

$$y = 2x\left(-\frac{1}{y'}\right)$$ $$yy' + 2x = 0$$ （直交曲線の微分方程式）

$$y\frac{dy}{dx} + 2x = 0$$

$$\int ydy = \int -2xdx$$ $$\frac{1}{2}y^2 = -x^2 + C_1$$ $$2C_1 = C$$ とおくと

$$y^2 + 2x^2 = C$$ （C は任意定数）（直交曲線）

### (2)
$$x^2 + y^2 = Cx$$

$$2x + 2yy' = C$$ これを与式に代入して

$$x^2 + y^2 = (2x + 2yy')x$$ と $$y^2 - x^2 = 2xyy'$$ （曲線群の微分方程式）

$$y^2 - x^2 = 2xy\left(-\frac{1}{y'}\right)$$ $$(x^2 - y^2)y' = 2xy$$ （直交曲線の微分方程式）

$$\frac{dy}{dx} = \frac{2xy}{x^2}$$ $$\frac{dy}{dx} = \frac{2}{\frac{x}{y} - \frac{y}{x}}$$ $$\frac{y}{x} = u$$ といると $$\frac{dy}{dx} = u + x\frac{du}{dx}$$ これから

$$u + x\frac{du}{dx} = \frac{2}{1-u}$$ $$x\frac{du}{dx} = \frac{u^3 + u}{1-u^2}$$

$$\int \frac{1-u^2}{u^3+u}du = \int \frac{1}{x}dx$$ $$\int \left(\frac{1}{u} - \frac{2u}{u^2-1}\right)du = \int \frac{1}{x}dx$$

$$\log \frac{u}{u^2+1} = \log x + C_1$$ $$e^{C_1} = C_2$$ とおくと

$$\frac{u}{x(u^2+1)} = C_2$$ 元に戻して

$$\frac{\frac{y}{x}}{\frac{y^2+x^2}{x}} \cdot \frac{1}{x} = C_2$$ $$\frac{1}{C_2} = C$$ として $$x^2 + y^2 = Cy$$ （直交曲線）
