### (1)
$(y + e^x \sin y)dx + (x + e^x \cos y)dy = 0$

$P = y + e^x \sin y$、$Q = x + e^x \cos y$ とおくと $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 1 + e^x \cos y$ よって完全微分系である

$$\int Pdx = yx + e^x \sin y = g$$

とすると $\frac{\partial g}{\partial y} = x + e^x \cos y$

$$\int \left(Q - \frac{\partial g}{\partial y}\right)dy = \int 0dy = 0$$
これから

$$yx + e^x \sin y = C$$

### (2)
$(2xy^2 + 1 + e^x \cos y)dx + (2x^2 y - e^x \sin y)dy = 0$

$P = 2xy^2 + 1 + e^x \cos y$、$Q = 2x^2 y - e^x \sin y$ とおくと

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 4xy - e^x \sin y$$
よって完全微分系である

$$\int Pdx = x^2 y^2 + x + e^x \cos y = g$$
とすると $\frac{\partial g}{\partial y} = 2x^2 y - e^x \sin y$ $Q - \frac{\partial g}{\partial y} = 0$ これから

$$x^2 y^2 + x + e^x \cos y = C$$
（$C$ は任意定数）

### (3)
$(y \log x - x)dx + (y + x \log x - x)dy = 0$

$P = y \log x - x$、$Q = y + x \log x - x$ とおくと $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = \log x$ よって完全微分系である

$$\int Pdx = y(x \log x - x) - \frac{1}{2} x^2 = g$$
とすると $\frac{\partial g}{\partial y} = x \log x - x$

$$\int \left(Q - \frac{\partial g}{\partial y}\right)dy = \int ydy = \frac{1}{2} y^2$$
これから

$$y(x \log x - x) - \frac{1}{2} x^2 + \frac{1}{2} y^2 = C$$
（$C$ は任意定数）

### (4)
$$\{\sin y + (1-y)\cos x\}dx + \{(1+x)\cos y - \sin x\}dy = 0$$

$P = \sin y + (1-y)\cos x$、$Q = (1+x)\cos y - \sin x$ とおくと

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = \cos y - \cos x$$ よって完全微分系である

$$\int Pdx = x \sin y + (1-y)\sin x = g$$

とすると $\frac{\partial g}{\partial y} = x\cos y - \sin x$

$$\int \left(Q - \frac{\partial g}{\partial y}\right)dy = \int \cos y dy = \sin y$$ これから

$x \sin y + (1-y)\sin x + \sin x = C$ 〜 $(1+x)\sin y + (1-y)\sin x = C$ （$C$ は任意定数）
