### (1)
$(2x - y + 1) - (x - 2y + 5)y' = 0$ → $(2x - y + 1)dx - (x - 2y + 5)dy = 0$

$P = 2x - y + 1$, $Q = -x + 2y - 5$ とおくと $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = -1$ よって完全微分系である

$\int P dx = x^2 - yx + x = g$ とすると $\frac{\partial g}{\partial y} = -x$

$\int (Q - \frac{\partial g}{\partial y})dy = y^2 - 5y$ これから

$x^2 - xy + x + y^2 - 5y = C$ （$C$ は任意定数）

### (2)
$\frac{dy}{dx} = \frac{2x - 5y + 3}{2x + 4y - 6}$ → $\begin{cases} 2x - 5y + 3 = 0 \\ 2x + 4y - 6 = 0 \end{cases}$ この連立方程式を解くと $(x, y) = (1, 1)$ これから

$x = X + 1, y = Y + 1$ とすると $\frac{dY}{dX} = \frac{2X - 5Y}{2X + 4Y} = \frac{2 - 5\frac{Y}{X}}{2 + 4\frac{Y}{X}}$

$\frac{Y}{X} = u$ とおくと $\frac{dY}{dX} = u + X\frac{du}{dX}$ これから

$u + X\frac{du}{dX} = \frac{2 - 5u}{2 + 4u}$ → $X\frac{du}{dX} = \frac{-4u^2 - 7u + 2}{2 + 4u} = \frac{-(4u - 1)(u + 2)}{2(2u + 1)}$

$\int \frac{2u + 1}{(4u - 1)(u + 2)}du = -\frac{1}{2}\int \frac{1}{X}dx$ → $\int (\frac{2}{4u - 1} + \frac{1}{u + 2})du = -\frac{1}{2}\int \frac{1}{X}dx$

$\frac{1}{6}\log(4u - 1) + \frac{1}{3}\log(u + 2) = -\frac{1}{2}\log x + C_1$ → $6C_1 = C_2$ において

$\log(4u - 1) + \log(u + 2)^2 + \log X^3 = C_2$ → $e^{C_2} = C$ において

$(4u - 1)(u + 2)^2 X^3 = C$ 元に戻して

$(\frac{4Y}{X} - 1)(\frac{Y}{X} + 2)^2 X^3 = C$ → $(4Y - X)(Y + 2X)^2 = C$ 元に戻して

$(4y - x - 3)(y + 2x + 3)^2 = C$ （$C$ は任意定数）

### (3)
$(x-2y-1)dx = (2x-4y+1)dy$     $(x-2y-1)dx-(2x-4y+1)dy=0$

$P = x-2y-1, Q=-2x+4y-1$ とおくと     $\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}=-2$ よって完全微分系である

$\int Pdx = \frac{1}{2}x^2-2xy-x = g$ とするとき     $\frac{\partial g}{\partial y}=-2x$

$\int\left(Q-\frac{\partial g}{\partial y}\right)dy = 2y^2-y$ これから

$\frac{1}{2}x^2-2xy-x+2y^2-y = C_1$     $2C_1 = C$ とおくと

$x^2-4xy-2x+4y^2-2y = C$     整理して

$(x-2y)^2-2(x+y) = C$     （C は任意定数）

### (4)
$(x+y+1)+(2x+2y-1)y'=0$     $(x+y+1)dx+(2x+2y-1)dy=0$

$\frac{dy}{dx}=-\frac{x+y+1}{2x+2y-1}$     $x+y+1=u$ とおくと     $\frac{dy}{dx}=\frac{du}{dx}-1$ これから

$\frac{du}{dx}-1=-\frac{u}{2u-3}$     $\frac{du}{dx}=\frac{u-3}{2u-3}$

$\int\frac{2u-3}{u-3}du = \int dx$     $\int\left(2+\frac{3}{u-3}\right)du = \int dx$     $2u+3\log(u-3)=x+C$     元に戻して

$2(x+y+1)+3\log(x+y-2) = x+C$

$x+2y+3\log(x+y-2)=C$     （C は任意定数）
