### (1)

$$y'-2y=e^x$$

$P=-2$、$Q=e^x$ とおくと $\int P dx=-2x$ これから

$$y=e^{2x}\left(\int e^{-2x}\cdot e^x dx+C\right)=e^{2x}(-e^{-x}+C)=Ce^{2x}-e^x$$

（C は任意定数）

### (2)

$$y'+3y=x^2+1$$

$P=3$、$Q=x^2+1$ とおくと $\int P dx=3x$ これから

$$y=e^{-3x}\left\{\int e^{3x}(x^2+1)dx+C\right\}=e^{-3x}\left\{\frac{1}{3}(x^2+1)e^{3x}-\frac{1}{3}\int 2xe^{3x}dx+C\right\}$$

$$=e^{-3x}\left\{\frac{1}{3}(x^2+1)e^{3x}-\frac{2}{9}xe^{3x}+\frac{2}{9}\int e^{3x}dx+C\right\}=e^{-3x}\left\{\frac{1}{3}(x^2+1)e^{3x}-\frac{2}{9}xe^{3x}+\frac{2}{27}e^{3x}+C\right\}$$

$$=Ce^{-3x}+\frac{1}{27}(9x^2-6x+11)$$

（C は任意定数）

### (3)

$$y'+y=\sin x$$

$P=1$、$Q=\sin x$ とおくと $\int P dx=x$ これから

$$y=e^{-x}\left\{\int e^x \sin x\,dx+C\right\}$$

$I=\displaystyle\int e^x \sin x\,dx$ とおくと

$$=-e^x\cos x+\int e^x \cos x\,dx=-e^x\cos x+e^x\sin x-\int e^x \sin x\,dx=-e^x\cos x+e^x\sin x-I$$

$$I=\frac{1}{2}e^x(\sin x-\cos x)$$ これから

$$y=e^{-x}\left\{\frac{1}{2}e^x(\sin x-\cos x)+C\right\}=Ce^{-x}+\frac{1}{2}(\sin x-\cos x)$$

（C は任意定数）

### (4)
$$y' + xy = x$$

$P = x$ 、 $Q = x$ とおくと $\displaystyle \int P dx = \frac{1}{2} x^2$ これから

$$y = e^{-\frac{1}{2}x^2} \left\{ \int e^{\frac{1}{2}x^2} x\, dx + C \right\} = e^{-\frac{1}{2}x^2} \left\{ e^{\frac{1}{2}x^2} + C \right\} = 1 + Ce^{-\frac{1}{2}x^2}$$  (C は任意定数)

### (5)
$$y' + e^x y = 3e^x$$

$P = e^x$ 、 $Q = 3e^x$ とおくと $\displaystyle \int P dx = e^x$ これから

$$y = e^{-e^x} \left\{ \int e^{e^x} 3e^x\, dx + C \right\} = e^{-e^x} \left\{ 3e^{e^x} + C \right\} = 3 + Ce^{-e^x}$$  (C は任意定数)

### (6)
$$y' + y \cos x = e^{-\sin x}$$

$P = \cos x$ 、 $Q = e^{-\sin x}$ とおくと $\displaystyle \int P dx = \sin x$ これから

$$y = e^{-\sin x} \left\{ \int e^{\sin x} \cdot e^{-\sin x}\, dx + C \right\} = e^{-\sin x} \left\{ \int dx + C \right\} = e^{-\sin x} \{ x + C \}$$  (C 任意定数)
