$$I = \int_0^{2\pi} (x\cos\theta + y\sin\theta - \theta)^2\, d\theta$$

$$= \int_0^{2\pi} (x^2\cos^2\theta + xy\cos\theta\sin\theta - x\theta\cos\theta + xy\cos\theta\sin\theta$$

$$+ y^2\sin^2\theta - y\theta\sin\theta - x\theta\cos\theta - y\theta\sin\theta + \theta^2)\,d\theta$$

$$= \int_0^{2\pi} (x^2\cos^2\theta + y^2\sin^2\theta + \theta^2 + 2xy\cos\theta\sin\theta - 2x\theta\cos\theta - 2y\theta\sin\theta)\,d\theta$$

$$= \left[x^2\left(\frac{1}{2}\theta - \frac{1}{4}\sin 2\theta\right) + y^2\left(\frac{1}{2}\theta + \frac{1}{4}\sin 2\theta\right) + \frac{1}{3}\theta^3\right]_0^{2\pi} - 2x[\theta\sin\theta]_0^{2\pi} + \int_0^{2\pi} \sin\theta\, d\theta$$

$$- 2y[\theta(-\cos\theta)]_0^{2\pi} - \int_0^{2\pi} \cos\theta\, d\theta$$

$$= \pi x^2 + \pi y^2 + \frac{8}{3}\pi^3 + 4\pi y$$

$$= \pi x^2 + \frac{8}{3}\pi^3 + \{\pi(y+2)^2 - 4\pi\}$$

これから

$x = 0$、$y = -2$ のとき最小となり

$$I = \frac{8}{3}\pi^3 - 4\pi \quad \text{となる}$$
