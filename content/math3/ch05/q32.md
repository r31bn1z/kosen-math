### (1)

$$\log 2 + \log 3 + \cdots \log(n-1) < \int_1^n \log x\,dx < \log 2 + \log 3 + \cdots + \log n$$

$$\log k < \log x < \log(k+1) \qquad (k < x < k+1)$$

とおく

両辺$k \sim k+1$で積分すると

$$\log k < \int_k^{k+1} \log x\,dx < \log(k+1)$$

前半の不等式を①、後半の不等式を②とおく

②において$k = 1,2,\cdots,n-1$として和をとると

$$\left(\int_1^2\int_2^3\cdots\int_{n-1}^n\right)\log x\,dx < \log 2 + \log 3 + \cdots \log n$$

$$\int_1^n \log x\,dx < \log 2 + \log 3 + \cdots + \log n$$

①で$k = 1,2,\cdots,n-1$として和をとると

$$\log 1 + \log 2 + \cdots + \log(n-1) < \int_1^n \log x\,dx$$

$\log 1 = 0$から

$$\log 2 + \log 3 + \cdots \log(n-1) < \int_1^n \log x\,dx$$

よって与式は証明された。

### (2)
$$n\log n - n + 1 < \log n! < (n+1)\log n - n + 1$$

$$\log n! = \sum_{k=1}^{n} \log k$$

$\log k < \log x < \log(k+1)$ $(k<x<k+1)$とおく

両辺 $k \sim k+1$ で積分すると

$$\log k < \int_{k}^{k+1} \log x\,dx < \log(k+1)$$

前半の不等式を①、後半の不等式を②とおくと

②において $k = 1,2,\cdots,n-1$ として和をとると

$$\left(\int_{1}^{2}+\int_{2}^{3}+\cdots\int_{n-1}^{n}\right)\log x\,dx < (\log 2+\log 3+\cdots\log n)$$

$$\int_{1}^{n}\log x\,dx < \log(1\cdot 2\cdot 3\cdots\cdots n)$$

$$n\log n - n + 1 < \log n!$$

同様に①において $k = 1,2,\cdots,n-1$ として和をとると

$$(\log 1+\log 2+\cdots+\log(n-1) < \int_{1}^{n}\log x\,dx$$

両辺に $\log n$ を加えると

$$\log n! < (n+1)\log n - n + 1$$

よって証明された

### (3)
$$n^n e^{-n+1} < n! < n^{n+1}e^{-n+1}$$

$$n^n e^{-n}e < n! < n^{n+1}e^{-n}e$$

$$n^n e^{-n}e < n! < n^n e^{\log n}e^{-n}e$$

両辺を $\dfrac{1}{n}$ 乗して

$$ne^{-1}e^{\frac{1}{n}} < \sqrt[n]{n!} < ne^{\frac{1}{n}\log n}e^{-1}e^{\frac{1}{n}}$$

$$e^{-1}e^{\frac{1}{n}} < \frac{\sqrt[n]{n!}}{n} < e^{-1+\frac{1}{n}+\frac{1}{n}\log n}$$

$n \to \infty$ とすると

$$-1 \le \lim_{n\to\infty}\log\frac{\sqrt[n]{n!}}{n} \le -1$$

$$\lim_{n\to\infty}\frac{\sqrt[n]{n!}}{n} \cong e^{-1}$$

また $-1+\dfrac{1}{n} < -1+\dfrac{1}{n}+\dfrac{1}{n}\log n$ $(n=1,2,\cdots)$は明らかであるので、与式は証明された
