### (1)
$$\int_0^{x^2} f_{(t)}dt = F_{(x^2)} - F_{(0)}$$

$t = x^2$ なので $dt = 2xdx$  $dx = \dfrac{1}{2x}dt$

$$\frac{d}{dt}(F_{(x^2)} - F_{(0)}) = f_{(x^2)}$$

から

$$2x\frac{d}{dx}(F_{(x^2)} - F_{(0)}) = 2xf_{(x^2)}$$

### (2)
$$\int_{kx}^{x^2-kx} f_{(kt)}dt = \frac{1}{k}(F_{k(x^2-kx)} - F_{(kkx)})$$

$F_{(k(x^2-kx))}$：$k(x^2-kx) = t$ から $k(2x-k)dx = dt$

$F_{(kkx)}$：$kkx = t$ から $k^2dx = dt$

$$\int_{kx}^{x^2-kx} f_{(kt)}dt = \frac{1}{k}(F_{k(x^2-kx)} - F_{(kkx)})$$ これを微分すると

$$\frac{df_{(x)}}{dx} = \frac{df_{(t)}}{dt}\cdot\frac{dt}{dx}$$ より

それぞれ  $\dfrac{dt}{dx} = \dfrac{k(2x-k)dx}{dx} = k(2x-k)$   $\dfrac{dt}{dx} = k^2$ から

$$\left\{\frac{1}{k}(F_{k(x^2-kx)} - F_{(kkx)})\right\}' = \frac{1}{k}\cdot\frac{dF_{k(x^2-kx)}}{dt}\cdot\frac{dt}{dx} - \frac{1}{k}\cdot\frac{dF_{(kkx)}}{dt}\cdot\frac{dt}{dx}$$

$$=\frac{1}{k}f_{(k(x^2-kx))}\cdot k(2x-k) - \frac{1}{k}f_{(kkx)}k^2 = (2x-k)\cdot f_{(k(x^2-kx))} - k\cdot f_{(kkx)}$$
