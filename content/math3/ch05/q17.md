$$2x^2 - 3xy + 2y^2 = 1$$

$$2y^2 - 3xy + (2x^2 - 1) = 0$$

$$y = \dfrac{3x \pm \sqrt{9x^2 - 8(2x^2 - 1)}}{4}$$

$y$ が２つの実数解を持つには

$$9x^2 - 8(2x^2 - 1) > 0 \qquad -7x^2 > -8 \qquad x^2 < \dfrac{8}{7} \qquad \therefore -\sqrt{\dfrac{8}{7}} < x < \sqrt{\dfrac{8}{7}}$$

これから

$$S = \int_{-\sqrt{\frac{8}{7}}}^{\sqrt{\frac{8}{7}}} \dfrac{3x + \sqrt{8 - 7x^2}}{4}\,dx - \int_{-\sqrt{\frac{8}{7}}}^{\sqrt{\frac{8}{7}}} \dfrac{3x - \sqrt{8 - 7x^2}}{4}\,dx = \int_{-\sqrt{\frac{8}{7}}}^{\sqrt{\frac{8}{7}}} \dfrac{\sqrt{8 - 7x^2}}{2}\,dx$$

この関数は偶感数であることから次のように書き換えることが出来る

$$= 2\int_{0}^{\sqrt{\frac{8}{7}}} \dfrac{\sqrt{8 - 7x^2}}{2}\,dx = \int_{0}^{\sqrt{\frac{8}{7}}} \sqrt{8 - 7x^2}\,dx = \sqrt{7}\int_{0}^{\sqrt{\frac{8}{7}}} \sqrt{\dfrac{8}{7} - x^2}\,dx$$

$$= \left[\dfrac{\sqrt{7}}{2}\left\{x\sqrt{\dfrac{8}{7} - x^2} + \dfrac{8}{7}\sin^{-1}\dfrac{x}{\sqrt{8/7}}\right\}\right]_{0}^{\sqrt{\frac{8}{7}}} = \dfrac{\sqrt{7}}{2}\left(\dfrac{8}{7} \cdot \dfrac{\pi}{2}\right) = \dfrac{2}{\sqrt{7}}\pi$$
