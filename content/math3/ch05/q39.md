### (1)

$I_n = \displaystyle\int_0^\infty x^n e^{-x^2}\,dx$ ただし $I_0 = \displaystyle\int_0^\infty e^{-x^2}\,dx = \dfrac{\sqrt{\pi}}{2}$ $I_n = \dfrac{n-1}{2}I_{n-2}$ $I_0 = \dfrac{\sqrt{\pi}}{2}$ $I_1 = \dfrac{1}{2}$

$$I_2 = \frac{2-1}{2}I_0 = \frac{\sqrt{\pi}}{4}$$

$$I_3 = \frac{3-1}{2}I_1 = \frac{2}{2}\cdot\frac{1}{2}$$

$$I_4 = \frac{4-1}{2}I_2 = \frac{3}{2}\cdot\frac{1}{2}\cdot\frac{\sqrt{\pi}}{2}$$

$$I_5 = \frac{5-1}{2}I_3 = \frac{4}{2}\cdot\frac{2}{2}\cdot\frac{1}{2}$$

よって n が偶数の時 $$I_n = \frac{n-1}{2}\cdot\frac{n-3}{2}\cdot\cdots\cdot\frac{3}{2}\cdot\frac{1}{2}\cdot\frac{\sqrt{\pi}}{2}$$

n が奇数の時 $$I_n = \frac{n-1}{2}\cdot\frac{n-3}{2}\cdot\cdots\cdot\frac{4}{2}\cdot\frac{2}{2}\cdot\frac{1}{2}$$

### (2)

$I_n = \displaystyle\int_0^1 (\log x)^n\,dx$  $I_n = -nI_{n-1}$  $I_0 = 1$

$I_1 = -1$  $I_0 = -1$

$$I_2 = -2\cdot I_1 = -2\cdot(-1)\cdot I_0 = -2\cdot(-1)\cdot 1 = 2$$

$$I_3 = -3\cdot I_2 = -6$$

よって

$$I_n = -n\cdot\{-(n-1)\}\cdot\{-(n-2)\}\cdot\cdots\cdot(-3)\cdot(-2)\cdot(-1)\cdot 1 = (-1)^n\cdot n!$$
