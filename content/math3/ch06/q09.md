$$a^2 = b^2 + c^2 - 2bc\cos A$$

$$a = \sqrt{b^2 + c^2 - 2bc\cos A}$$

$$\frac{da}{db} = \frac{2b - 2c\cos A}{2\sqrt{b^2 + c^2 - 2bc\cos A}} = \frac{b - c\cos A}{a}$$

$$\frac{da}{dc} = \frac{2c - 2b\cos A}{2\sqrt{b^2 + c^2 - 2bc\cos A}} = \frac{c - b\cos A}{a}$$

$$\frac{da}{dA} = \frac{2bc\sin A}{2\sqrt{b^2 + c^2 - 2bc\cos A}} = \frac{bc\sin A}{a}$$

これから

$$\Delta a = \frac{b - c\cos A}{a}\Delta b + \frac{c - b\cos A}{a}\Delta c + \frac{bc\sin A}{a}\Delta A$$

余弦定理 $a = b\cos C + c\cos B$  $b = c\cos A + a\cos C$  $c = a\cos B + b\cos A$

正弦定理 $$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

これより

$$\Delta a \cong \cos C \cdot \Delta b + \cos B \cdot \Delta c + c\sin B \cdot \Delta A$$
