### (1)
$f_x = 1$ $f_y = 2$

$$\int f_x dx = x + C_1 \qquad \int f_y dy = 2y + C_2$$

これから

$$f_{(x,y)} = x + 2y + C \qquad (\text{C \text{は積分定数}})$$

### (2)
$f_x = x$ $f_y = y$

$$\int f_x dx = \frac{1}{2}x^2 + C_1 \qquad \int f_y dy = \frac{1}{2}y^2 + C_2$$

これから

$$f_{(x,y)} = \frac{1}{2}x^2 + \frac{1}{2}y^2 + C \qquad (\text{C \text{は積分定数}})$$

### (3)
$f_x = 3x - 2$ $f_y = -3y$

$$\int f_x dx = \frac{3}{2}x^2 - 2x + C_1 \qquad \int f_y dy = -\frac{3}{2}y^2 + C_2$$

これから

$$f_{(x,y)} = \frac{3}{2}(x^2 - y^2) - 2x + C \qquad (\text{C \text{は積分定数}})$$

### (4)
$f_{xy} = 0$

$$f_x = f_{(y)} + C_1 \quad \rightarrow \quad f = F_{(y)} + C_2$$

$$f_y = f_{(x)} + C_3 \quad \rightarrow \quad f = F_{(x)} + C_4$$

よって

$$f = F_{(x)} + F_{(y)} + C \qquad (\text{C \text{は積分定数}})$$

ただし $F_{(x)}$ は x のみの関数、 $F_{(y)}$ は y のみの関数である
