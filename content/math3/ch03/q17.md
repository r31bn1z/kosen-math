### (1)
$$e^x \cos x \cong 1 + x - \frac{x^3}{3} - \frac{x^4}{6}$$

$|x| \cong 0$と考えると、マクローリン展開で

$f = e^x \cos x$とおくと

$$f' = e^x \cos x - e^x \sin x \qquad f'{}_{(0)} = 1$$

$$f'' = e^x \cos x - e^x \sin x - e^x \sin x - e^x \cos x = -2e^x \sin x \qquad f''{}_{(0)} = 0$$

$$f''' = -2e^x \sin x - 2e^x \cos x \qquad f'''{}_{(0)} = -2$$

$$f^{(4)} = -2e^x \sin x - 2e^x \cos x - 2e^x \cos x + 2e^x \sin x \qquad f^{(4)}{}_{(0)} = -4$$

これから

$f = 1 + x - \dfrac{x^3}{3} - \dfrac{x^4}{6}$ よって与式が成り立つ

### (2)
$$\log(1+\sin x) \cong x - \frac{x^2}{2} + \frac{x^3}{6}$$

$|x| \cong 0$と考えると、マクローリン展開で

$f = \log(1+\sin x)$とおくと

$$f' = \frac{\cos x}{1+\sin x} \qquad f'{}_{(0)} = 1$$

$$f'' = \frac{-\sin x \cdot (1+\sin x) - \cos x \cdot \cos x}{(1+\sin x)^2} = \frac{-\sin x - 1}{(1+\sin x)^2} \qquad f''{}_{(0)} = -1$$

$$f''' = \frac{-\cos x \cdot (1+\sin x)^2 + (1+\sin x) \cdot 2 \cdot 2(1+\sin x) \cdot \cos x}{(1+\sin x)^4}$$

$$= \frac{\cos x \cdot (-1 - 2\sin x - \sin^2 x + 2 - 4\sin x + 2\sin^2 x)}{(1+\sin x)^4} \qquad f'''{}_{(0)} = 1$$

これから

$f \cong x - \dfrac{x^2}{2} + \dfrac{x^3}{6}$ よって与式が成り立つ

### (3)

$$\tan^{-1} x \cong x - \frac{x^3}{3}$$

$|x| \cong 0$ と考えると、マクローリン展開で

$f = \tan^{-1} x$ とおくと

$$f' = \frac{1}{1+x^2} \qquad f'(0) = 1$$

$$f'' = \frac{-2x}{(1+x^2)^2} \qquad f''(0) = 0$$

$$f''' = \frac{-2(1+x^2)^2 + 2x(1+x^2)\cdot 2 \cdot 2x}{(1+x^2)^4} \qquad f'''(0) = -2$$

これから

$$f \cong x - \frac{x^3}{3} \qquad \text{よって与式が成り立つ}$$
