### (1)

$$y = e^x + 2e^{-x}$$

$$y' = e^x - 2e^{-x} \qquad y'' = e^x + 2e^{-x}$$

$y'=0$ のとき  $e^x - 2e^{-x} = 0$  $e^x = 2e^{-x}$  $\log e^x = \log 2e^{-x} = \log 2 + \log e^{-x}$

$$x = \log 2 - x \qquad \therefore x = \frac{1}{2}\log 2$$

$x = \dfrac{1}{2}\log 2$ のとき  $y'' = e^{\frac{1}{2}\log 2} + 2e^{-\frac{1}{2}\log 2} > 0$ （極小）

これから $x = \dfrac{1}{2}\log 2$ のとき極小値

$$y = e^{\frac{1}{2}\log 2} + 2e^{-\frac{1}{2}\log 2} = e^{\log\sqrt{2}} + 2e^{\log\frac{1}{\sqrt{2}}} = \sqrt{2} + \frac{2}{\sqrt{2}} = 2\sqrt{2}$$

### (2)

$$y = e^{-x}\sin x \qquad (0 \le x \le 2\pi)$$

$$y' = -e^{-x}\sin x + e^{-x}\cos x \qquad y'' = -(-e^{-x}\sin x + e^{-x}\cos x) - e^{-x}\cos x + e^{-x}(-\sin x) = -2e^{-x}\cos x$$

$y'=0$ のとき  $-e^{-x}\sin x + e^{-x}\cos x = 0$  $-e^{-x}(\sin x - \cos x) = 0$  $\therefore x = \dfrac{\pi}{4}, \dfrac{5}{4}\pi$

$x = \dfrac{\pi}{4}$ のとき  $y'' = -2e^{-\frac{\pi}{4}} \cdot \cos\dfrac{\pi}{4} = -\sqrt{2}e^{-\frac{\pi}{4}} < 0$ （極大）

$x = \dfrac{5}{4}\pi$ のとき  $y'' = -2e^{-\frac{5}{4}\pi} \cos\dfrac{5}{4}\pi = \sqrt{2}e^{-\frac{5}{4}\pi} > 0$ （極小）

これから

$x = \dfrac{\pi}{4}$ のとき極大値  $y = \dfrac{1}{\sqrt{2}}e^{-\frac{\pi}{4}}$    $x = \dfrac{5}{4}\pi$ のとき極小値  $y = -\dfrac{1}{\sqrt{2}}e^{-\frac{5}{4}\pi}$

### (3)

$$y = 2\sin x + \cos^2 x \qquad (0 \le x \le 2\pi)$$

$$y' = 2\cos x - 2\cos x \cdot \sin x \qquad\qquad y'' = -2\sin x + 2\sin x \cdot \sin x - 2\cos x \cdot \cos x$$

$y'=0$ のとき  $2\cos x - 2\cos x \cdot \sin x = 0$   $2\cos x(1-\sin x)=0$   $\cos x=0,\ \sin x=1$

$$\therefore\ x = \frac{\pi}{2},\ \frac{3}{2}\pi$$

$x=\dfrac{\pi}{2}$ のとき  $y'' = -2\sin\dfrac{\pi}{2}+2\sin^2\dfrac{\pi}{2}-2\cos^2\dfrac{\pi}{2} = -2+2=0$

$x=\dfrac{3}{2}\pi$ のとき  $y'' = -2\sin\dfrac{3}{2}\pi+2\sin^2\dfrac{3}{2}\pi-2\cos^2\dfrac{3}{2}\pi = 2+2=4>0$  （極小）

これから

$x=\dfrac{\pi}{2}$ のとき極大値 $y=2$   $x=\dfrac{3}{2}\pi$ のとき極小値 $y=-2$
