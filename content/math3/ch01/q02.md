### (1)

$$y = x^3 + x^2 - x - 1$$

$$y' = 3x^2 + 2x - 1 \qquad y'' = 6x + 2$$

$y'=0$ のとき

$$3x^2 + 2x - 1 = 0$$

$$(x+1)(3x-1) = 0 \qquad \therefore x = -1, \frac{1}{3}$$

$x=-1$ のとき $y'' = -6+2 = -4 < 0$ （極大）

$x=\dfrac{1}{3}$ のとき $y'' = 2+2 = 4 > 0$ （極小）

よって

$x=-1$ のとき 極大値 $y = 0$

$x=\dfrac{1}{3}$ のとき 極小値 $y = -\dfrac{32}{27}$

### (2)

$$y = (1-\sqrt{x})^2$$

$$y' = 2(1-\sqrt{x})\left(-\frac{1}{2\sqrt{x}}\right) = -\frac{1}{\sqrt{x}}(1-\sqrt{x}) = -\frac{1}{\sqrt{x}} + 1 \qquad y'' = -\left(-\frac{1}{2\sqrt{x^3}}\right) = \frac{1}{2\sqrt{x^3}}$$

$y'=0$ のとき

$$-\frac{1}{\sqrt{x}} + 1 = 0 \qquad \therefore x = 1$$

$x=1$ のとき $y'' = \dfrac{1}{2} > 0$ （極小）

よって

$x=1$ のとき 極小値 $y = 0$

### (3)

$$y = e^{-x^2}$$

$$y' = -2xe^{-x^2} \qquad y'' = -2\{e^{-x^2} + x(-2xe^{-x^2})\} = -2e^{-x^2} + 4x^2e^{-x^2}$$

$y' = 0$ のとき

$$-2xe^{-x^2} = 0 \qquad \therefore x = 0$$

$x = 0$ のとき $y'' = -2 < 0$ （極大）

よって

$x = 0$ のとき 極大値 $y = 1$

### (4)

$$y = \frac{\log x}{x}$$

$$y' = \frac{\dfrac{1}{x}\cdot x - \log x}{x^2} = \frac{1 - \log x}{x^2} \qquad y'' = \frac{-\dfrac{1}{x}x^2 - (1 - \log x)\cdot 2x}{x^4} = \frac{-x - 2x(1 - \log x)}{x^4} = \frac{-1 - 2(1 - \log x)}{x^3}$$

$y' = 0$ のとき

$$\frac{1 - \log x}{x^2} = 0$$

$$1 - \log x = 0 \qquad \therefore x = e$$

$x = e$ のとき $y'' = \dfrac{-1 - 2(1-1)}{e^3} = -\dfrac{1}{e^3} < 0$ （極大）

よって

$x = e$ のとき 極大値 $y = \dfrac{1}{e}$

### (5)

$$y = x + 2\cos x$$

$$y' = 1 - 2\sin x \qquad y'' = -2\cos x$$

$y'=0$ のとき

$$1 - 2\sin x = 0 \qquad \therefore x = \frac{1}{6}\pi, \frac{5}{6}\pi$$

$x = \dfrac{1}{6}\pi$ のとき $y'' = -2 \cdot \dfrac{\sqrt{3}}{2} = -\sqrt{3} < 0$ （極大）

$x = \dfrac{5}{6}\pi$ のとき $y'' = -2 \cdot \left(-\dfrac{\sqrt{3}}{2}\right) = \sqrt{3} > 0$ （極小）

よって

$x = \dfrac{1}{6}\pi$ のとき 極大値 $y = \dfrac{1}{6}\pi + \sqrt{3}$

$x = \dfrac{5}{6}\pi$ のとき 極小値 $y = \dfrac{5}{6}\pi - \sqrt{3}$
