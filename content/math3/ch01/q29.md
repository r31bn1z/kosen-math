### (1)
$$y = e^{ax} \log x$$

$$y' = ae^{ax} \log x + e^{ax} \frac{1}{x}$$

$x = e$ のとき  $y' = ae^{ae} + e^{ae-1}$

$$y'' = a^2 e^{ax} \log x + ae^{ax} \frac{1}{x} + \frac{ae^{ax}x - e^{ax}}{x^2}$$

$x = e$ のとき  $y'' = a^2 e^{ae} + ae^{ae-1} + ae^{ae-1} - e^{ae-2}$

$y' = y''$ から  $ae^{ae} + e^{ae-1} = a^2 e^{ae} + ae^{ae-1} + ae^{ae-1} - e^{ae-2}$

$$a + \frac{1}{e} = a^2 + \frac{a}{e} + \frac{a}{e} - \frac{1}{e^2}$$   $$a^2 + a(\frac{2}{e} - 1) - (\frac{1}{e^2} + \frac{1}{e}) = 0$$

この２次式の判別式は

$$(1 - \frac{2}{e})^2 + 4(\frac{1}{e^2} + \frac{1}{e}) = 1 - \frac{4}{e} + \frac{4}{e^2} + \frac{4}{e^2} + \frac{4}{e} = 1 + \frac{8}{e^2} > 0$$   よって２つの実数解を持つ

２つの解をそれぞれ $\alpha, \beta$ とおくと

$$\alpha \cdot \beta = -(\frac{1}{e^2} + \frac{1}{e})$$  から  $\alpha$ と $\beta$ の符号は異なる

### (1)

から$(\alpha - \beta)^2 = 1 + \frac{8}{e^2} > 2$　　よって平均値は正、及び$\sqrt{2}$以上離れている

○$(\alpha - \beta)^2 = 1 + \frac{8}{e^2}$  （判別式と同じになる理由）

今２つの解を$\alpha, \beta$としているので方程式は  $(x - \alpha)(x - \beta) = 0$  と考えられる。

展開すると  $$x^2 - (\alpha + \beta)x + \alpha\beta = 0$$

解の公式から  $$x = \frac{(\alpha + \beta) \pm \sqrt{(\alpha + \beta)^2 - 4\alpha\beta}}{2}$$

この判別式は  $$(\alpha + \beta)^2 - 4\alpha\beta = \alpha^2 + 2\alpha\beta + \beta^2 - 4\alpha\beta = \alpha^2 - 2\alpha\beta + \beta^2 = (\alpha - \beta)^2$$
