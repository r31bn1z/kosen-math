### (1)

$$y = 15x + 6x^2 - x^3 - 20$$

$$y' = 15 + 12x - 3x^2 \qquad y'' = 12 - 6x$$

$y'=0$ のとき  $15+12x-3x^2=0$  $3(5-x)(1+x)=0$  $\therefore x=-1,5$

$x=-1$ のとき  $y''=12+6=18>0$ （極小）

$x=5$ のとき  $y''=12-30=-18<0$ （極大）

$y''=0$ のとき  $12-6x=0$  $\therefore x=2$

### (2)

$$y = x^4 - 6x^2 + 8x$$

$$y' = 4x^3 - 12x + 8 \qquad y'' = 12x^2 - 12$$

$y'=0$ のとき  $4x^3-12x+8=0$  $4(x-1)(x-1)(x+2)=0$  $\therefore x=-2,1$

$x=-2$ のとき  $y''=42-12=36>0$ （極小）

$x=1$ のとき  $y''=12-12=0$

$y''=0$ のとき  $12x^2=12$  $\therefore x=\pm1$

### (3)

$$y = (x-5)^2 \sqrt{x} \qquad （\text{定義域} x \geq 0）$$

$$y' = 2(x-5)\sqrt{x} + (x-5)^2 \frac{1}{2\sqrt{x}}$$

$$y'' = 2\sqrt{x} + 2(x-5)\frac{1}{2\sqrt{x}} + 2(x-5)\frac{1}{2\sqrt{x}} + (x-5)^2\left(-\frac{1}{4\sqrt{x^3}}\right) = 2\sqrt{x} + (x-5)\frac{2}{\sqrt{x}} - (x-5)^2 \frac{1}{4\sqrt{x^3}}$$

$y'=0$ のとき

$$2(x-5)\sqrt{x} + (x-5)^2 \frac{1}{2\sqrt{x}} = 0 \qquad (x-5)\left\{2\sqrt{x} + \frac{1}{2\sqrt{x}}(x-5)\right\} = 0$$

$$2\sqrt{x} + \frac{1}{2\sqrt{x}}(x-5) = \frac{4x+x-5}{2\sqrt{x}} = \frac{5x-5}{2\sqrt{x}} \qquad (x-5)\frac{5x-5}{2\sqrt{x}} = 0 \qquad \therefore x = 5, 1$$

$x=1$ のとき $y'' = -10 < 0$ （極大）

$x=5$ のとき $y'' = 2\sqrt{5} > 0$ （極小）

$y''=0$ のとき

$$2\sqrt{x} + (x-5)\frac{2}{\sqrt{x}} - (x-5)^2 \frac{1}{4\sqrt{x^3}} = \frac{15x^2-30x-25}{4\sqrt{x^3}} = 0 \qquad 3x^2-6x-5=0$$

$$x = 1 \pm \frac{2}{3}\sqrt{6} \qquad x \geq 0 \text{から} \qquad \therefore x = 1 + \frac{2}{3}\sqrt{6}$$

### (4)

$$y = \frac{1-\sin x}{\cos x} \qquad (\text{定義域} \ \cos x \neq 0)$$

$$y' = \frac{-\cos x \cdot \cos x + (1-\sin x)\cdot \sin x}{\cos^2 x} = \frac{-\cos^2 x + \sin x - \sin^2 x}{\cos^2 x} = \frac{\sin x - 1}{1-\sin^2 x}$$

$$= \frac{\sin x - 1}{-(\sin x -1)(\sin x+1)} = -\frac{1}{\sin x+1}$$

$$y'' = -\frac{-\cos x}{(\sin x+1)^2} = \frac{\cos x}{(1+\sin x)^2}\cdot\frac{1-\sin x}{1-\sin x} = \frac{\cos x\cdot(1-\sin x)}{(1+\sin x)(1-\sin^2 x)} = \frac{\cos x\cdot(1-\sin x)}{(1+\sin x)\cos^2 x} = \frac{1-\sin x}{\cos x\cdot(1+\sin x)}$$

$y'=0$ のとき $-\dfrac{1}{\sin x+1}=0$ ∴解なし

$y''=0$ のとき $\dfrac{1-\sin x}{\cos x\cdot(1+\sin x)}=0$ $1-\sin x=0$ ∴$x=\dfrac{\pi}{2},\dfrac{2}{3}\pi$ （定義域外である）
