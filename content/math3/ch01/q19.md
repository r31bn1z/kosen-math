### (1)

$$\sin^{-1}(-x) = -\sin^{-1}x$$

$\sin^{-1}(-x) = \omega$ として  $\sin\omega = -x$

$-\sin^{-1}x = l$ として  $\sin(-l) = -\sin l = x$  $\sin l = -x$

よって $\sin l = \sin\omega$ なので与式は成り立つ。

### (2)

$$\cos^{-1}(-x) = \pi - \cos^{-1}x$$

$\cos^{-1}(-x) = \omega$ として  $\cos\omega = -x$

$\pi - \cos^{-1}x = l$ として  $\cos(\pi - l) = \cos(-l) = -\cos l = x$  $\cos l = -x$

よって $\cos l = \cos\omega$ なので与式は成り立つ。

### (3)

$$\tan^{-1}(-x) = -\tan^{-1}x$$

$\tan^{-1}(-x) = \omega$ として  $\tan\omega = -x$

$-\tan^{-1}x = l$ として  $\tan(-l) = -\tan l = x$  $\tan l = -x$

よって $\tan l = \tan\omega$ なので与式は成り立つ。

### (4)

$$\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$$

$\sin^{-1}(-x) = \omega$ として  $\sin\omega = \cos\left(\dfrac{\pi}{2} - \omega\right) = -x$

$\cos^{-1}x = \dfrac{\pi}{2} - \omega = \dfrac{\pi}{2} - \sin^{-1}x$

よって与式は成り立つ。
