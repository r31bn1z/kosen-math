### (1)

$$x < \tan x \qquad \left(0 < x < \frac{\pi}{2}\right)$$

$\tan x - x > 0$ となればよい

左辺 $= y = \tan x - x$ として

$$y' = \frac{1}{\cos^2 x} - 1$$

$y'=0$ のとき  $\dfrac{1}{\cos^2 x} - 1 = 0$  $\cos^2 x = 1$  $x = -\pi, 0, \pi$

$0 < x < \dfrac{\pi}{2}$ から  $\therefore x \cong 0$

| $x$  | $0$ | $\cdots$ | $\dfrac{\pi}{2}$ |
|------|-----|----------|------------------|
| $y'$ | $0$ | $+$      | $+$              |
| $y$  | $0$ |          | $\infty$         |

よって $\tan x - x > 0$ が成り立つので与式は成り立つ。

### (2)

$$\tan x - x < 0 \qquad \left(-\frac{\pi}{2} < x < 0\right)$$

### (1)

と同様に考えると

| $x$  | $-\dfrac{\pi}{2}$ | $\cdots$ | $0$      |
|------|-------------------|----------|----------|
| $y'$ | $-$               | $-$      | $0$      |
| $y$  | $-\infty$         |          | $0$      |

よって $\tan x - x < 0$ が成り立つので与式は成り立つ。

### (3)

$$\tan^{-1} x < x \qquad (0 < x < \infty)$$

$$\tan^{-1} x - x < 0 \text{ となればよい}$$

左辺 $= y = \tan^{-1} x - x$ として

$$y' = \frac{1}{1+x^2} - 1 = \frac{-x^2}{1+x^2}$$

$y'=0$ のとき  $\dfrac{-x^2}{1+x^2}=0$  $\therefore x \cong 0$

| $x$ | $0$ | $\cdots$ | $\infty$ |
|---|---|---|---|
| $y'$ | $0$ | $-$ | $-$ |
| $y$ | $0$ | | $-\infty$ |

よって $\tan^{-1} x - x < 0$ が成り立つので与式は成り立つ。
