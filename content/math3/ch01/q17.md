$$y = x^3 + 3ax^2 + 3bx + c$$ ①

$$y' = 3x^2 + 6ax + 3b \qquad y'' = 6x + 6a$$

$x = -1$ のとき極値をとるので

$$3 - 6a + 3b = 0$$ ②

$(0,3)$ が変曲点なので $x = 0$ のとき $y'' = 0$

$$0 + 6a = 0 \qquad \therefore a = 0$$

これを②に代入して

$$3 - 0 + 3b = 0 \qquad \therefore b = -1$$

$(0,3)$ を通るので①から $\qquad \therefore c = 3$

よって $a = 0 \quad b = -1 \quad c = 3$
