$$\frac{1}{x+1} < \log(x+1) - \log x < \frac{1}{x}$$

$\log(x+1) - \log x$ において

$$\frac{f_{(b)} - f_{(a)}}{b-a} = f'_{(c)} \quad (a < c < b) \quad \text{から} \quad f_{(x)} = \log x \quad \text{となり}$$

$$\frac{\log(x+1) - \log x}{(x+1)-x} = \log(x+1) - \log x = \frac{1}{c} \quad \text{となる } c \text{ が存在する} \qquad \text{(\text{平均値の定理})}$$

$x>0$ の範囲では $\dfrac{1}{x+1} = \{\log(x+1)\}' < \dfrac{1}{x} = (\log x)'$ が成り立ち

$$\frac{1}{x+1} < \log(x+1) - \log x < \frac{1}{x} \text{ が成り立つ}$$
