### (1)

$$y = xe^{1-x}$$

$$y' = e^{1-x} - xe^{1-x}$$

$y'=0$ のとき  $e^{1-x} - xe^{1-x} = 0$   $e^{1-x}(1-x) = 0$   $\therefore x=1$

$$y'' = -e^{1-x} - e^{1-x} + xe^{1-x}$$

$x=1$ のとき  $y'' = -1-1+1 = -1 < 0$  （極大）

$y''=0$ のとき  $-e^{1-x} - e^{1-x} + xe^{1-x} = 0$   $\therefore x=2$

これから

| x | ・・・ | 1 | ・・・ | 2 | ・・・ |
|---|---|---|---|---|---|
| y' | + | 0 | - | - | - |
| y'' | - | - | - | 0 | + |
| y |  | 1 |  | $2/e$ |  |

### (2)

$$y = x^2 \log x \qquad （\text{定義域} x>0）$$

$$y' = 2x\log x + x^2 \cdot \frac{1}{x} = 2x\log x + x$$

$y'=0$ のとき  $2x\log x + x = 0$   $x(2\log x + 1) = 0$   $x=0, \dfrac{1}{\sqrt{e}}$   $x>0$から   $\therefore x = \dfrac{1}{\sqrt{e}}$

$$y'' = 2\log x + 2x \cdot \frac{1}{x} + 1 = 2\log x + 3$$

$x = \dfrac{1}{\sqrt{e}}$ のとき  $-1+3 = 2 > 0$  （極小）

$y''=0$ のとき  $2\log x + 3 = 0$   $\therefore x = e^{-3/2}$

これから

| x | 0 | ・・・ | $e^{-3/2}$ | ・・・ | $1/\sqrt{e}$ | ・・・ |
|---|---|---|---|---|---|---|
| y' | ／ | - | - | - | 0 | + |
| y'' | ／ | - | 0 | + | + | + |
| y | 0 |  | $-3/2e^3$ |  | $-1/2e$ |  |
