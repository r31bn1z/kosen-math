$$\alpha(x-1) < x^{\alpha} - 1 < \alpha x^{\alpha-1}(x-1)$$

$$\frac{f_{(b)} - f_{(a)}}{b-a} = f'_{(c)}$$ から

$$f_{(x)} = x^{\alpha} \qquad b = x、\ a = 0$$

$$f'_{(x)} = \alpha x^{\alpha - 1}$$

区間 $[1, x]$ から平均値の定理より

$$\frac{x^{\alpha} - 1^{\alpha}}{x - 1} = \alpha C^{\alpha - 1} \qquad ①$$

C の範囲は $1 < C < x$ なので

$$1^{\alpha - 1} < C^{\alpha - 1} < x^{\alpha - 1} \qquad \alpha < \alpha C^{\alpha - 1} < \alpha x^{\alpha - 1}$$

これを①に代入して

$$\alpha < \frac{x^{\alpha} - 1}{x - 1} < \alpha x^{\alpha - 1} \qquad \therefore \alpha(x-1) < x^{\alpha} - 1 < \alpha x^{\alpha-1}(x-1)$$
