### (1)

$$yy'' + (y')^2 = 0$$

$y' = P$ と置くと $y'' = P\frac{dP}{dy}$ これから与式は

$$yP\frac{dP}{dy} + P^2 = 0 \quad y\frac{dP}{dy} = -P$$

$$\int \frac{1}{P}dP = \int -\frac{1}{y}dy \quad \log P = -\log y + C_1 \quad e^{C_1} = C_2 \text{ と置くと}$$

$$P = \frac{C_2}{y}$$

$$\int y dy = \int C_2 dx \quad \frac{1}{2}y^2 = C_2 x + C_3 \quad 2C_2 = A, 2C_3 = B \text{ と置くと}$$

$$y^2 = Ax + B$$

（A,B は任意定数）

### (2)

$$yy'' + 2(y')^2 - 2yy' = 0$$

$y' = P$ と置くと $y'' = P\frac{dP}{dy}$ これから与式は

$$yP\frac{dP}{dy} + 2P^2 - 2yP = 0 \quad y\frac{dP}{dy} + 2P - 2y = 0 \quad \frac{dP}{dy} + \frac{2}{y}P = 2$$

$$\alpha = \frac{2}{y}, \beta = 2 \text{ と置くと} \quad \int \alpha dy = 2\log y \quad \text{これから}$$

$$P = \frac{1}{y^2}\left[\int y^2 dy + C_1\right] = \frac{2y^3 + 3C_1}{3y^2} \quad \text{元に戻して}$$

$$\frac{dy}{dx} = \frac{2y^3 + 3C_1}{3y^2} \quad \frac{3}{2}C_1 = C_2 \text{ と置くと}$$

$$\frac{1}{2}\int \frac{3y^2}{y^3 + C_2}dy = \int dx \quad \frac{1}{2}\log|y^3 + C_2| = x + C_3 \quad e^{2C_3} = C_4 \text{ と置くと}$$

$$y^3 + C_2 = C_4 e^{2x} \quad -C_2 = A, C_4 = B \text{ と置くと}$$

$$y^3 = A + Be^{2x}$$

（A,B は任意定数）

### (3)
$(1-x^2)y'' + xy' = ax$

$y' = P$ とおくと与式は

$(1-x^2)P' + xP = ax$

$P' + \frac{x}{1-x^2}P = \frac{ax}{1-x^2}$

$\alpha = \frac{x}{1-x^2}$、$\beta = \frac{ax}{1-x^2}$ とおくと $\int adx = -\frac{1}{2}\log(1-x^2)$

$$P = \sqrt{1-x^2}\left\{\int \frac{ax}{(1-x^2)^{3/2}}dx + C_1\right\} = \sqrt{1-x^2}\left\{\frac{a}{\sqrt{1-x^2}} + C_1\right\} = a + C_1\sqrt{1-x^2}$$ 元に戻して

$y' = a + C_1\sqrt{1-x^2}$

ここで$|x| > 1$のとき $y = ax + C_1\{x\sqrt{x^2-1} - \log|x+\sqrt{x^2-1}|\} + C_2$

$|x| < 1$のとき $y = ax + C_1\{x\sqrt{1-x^2} + \sin^{-1}x\} + C_2$

$C_1 = A$、$C_2 = B$ とおくと

$|x| > 1$: $y = ax + A\{x\sqrt{x^2-1} - \log|x+\sqrt{x^2-1}|\} + B$

$|x| < 1$: $y = ax + A\{x\sqrt{1-x^2} + \sin^{-1}x\} + B$ （$A,B$は任意定数）
