### (1)
$$\frac{d^2x}{dt^2} = -g$$から $x' = P$ とおくと

$$P' = -g \quad P = -gt + C_1 \quad \text{元に戻して}$$

$$x' = -gt + C_1 \quad x = -\frac{1}{2}gt^2 + C_1 t + C_2 \quad C_1 = A 、C_2 = B \text{とおくと}$$

$$x = -\frac{1}{2}gt^2 + At + B$$（$A, B$は任意定数）

### (2)
$x = 0$のときの（１）から

$$0 = -\frac{1}{2}gt^2 + v_0 t \quad t\left(-\frac{1}{2}gt + v_0\right) = 0 \quad ∴ t = 0, \frac{2v_0}{g}$$

$t = 0$は投げだしたときなので

$$t = \frac{2v_0}{g}$$
