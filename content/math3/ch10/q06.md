### (1)

$y'' - 2y' - 15y = 0$ $[x = 0 \text{ のとき } y = 5, y' = 1]$

特性方程式は $s^2 - 2s - 15 = 0$ $(s-5)(s+3) = 0$ $\therefore s = 5, -3$ これから

$$y = Ae^{5x} + Be^{-3x}$$

$y(0) = 5$ から $5 = A + B$ ①

$y$ を微分して $y' = 5Ae^{5x} - 3Be^{-3x}$

$y'(0) = 1$ から $1 = 5A - 3B$ ②

①、②から $A = 2, B = 3$ となる これから

$$y = 2e^{5x} + 3e^{-3x}$$

### (2)

$y'' + 2y' + 5y = 0$ $[x = 0 \text{ のとき } y = 2, y' = 1]$

特性方程式は $s^2 + 2s + 5 = 0$ $s = -1 \pm \sqrt{1-5} = -1 \pm 2i$ これから

$$y = e^{-x}(A \sin 2x + B \cos 2x)$$

$y(0) = 2$ から $2 = B$ ①

$y$ を微分して $y' = -e^{-x}(A \sin 2x + B \cos 2x) + e^{-x}(2A \cos 2x - 2B \sin 2x)$

$y'(0) = 1$ から $1 = -B + 2A$ ②

①、②から $A = \frac{3}{2}, B = 2$ これから

$$y = e^{-x}\left(\frac{3}{2} \sin 2x + 2 \cos 2x\right)$$

### (3)

$y'' - 5y' + 6y = e^{4x}$ 「$x = 0$のとき $y = 0, y' = 0$」

特性方程式式は $s^2 - 5s + 6 = 0$ $(s-2)(s-3) = 0$ $s = 2,3$

微分演算子 D を使って $(D^2 - 5D + 6)y_1 = e^{4x}$

$$y_1 = \frac{1}{D^2 - 5D + 6}e^{4x}$$ $D = 4$を代入して

$$= \frac{1}{4^2 - 5 \cdot 4 + 6}e^{4x} = \frac{1}{2}e^{4x}$$ これから

$$y = Ae^{2x} + Be^{3x} + \frac{1}{2}e^{4x}$$

$y(0) = 0$から $0 = A + B + \frac{1}{2}$ ①

y を微分すると $y' = 2Ae^{2x} + 3Be^{3x} + 2e^{4x}$

$y'(0) = 0$から $0 = 2A + 3B + 2$ ②

①、②から $A = \frac{1}{2}, B = -1$ これから

$$y = \frac{1}{2}e^{2x} - e^{3x} + \frac{1}{2}e^{4x}$$
