### (1)
$$y''-6y'+8y = e^x$$

特性方程式は $s^2 - 6s + 8 = 0$ $(s-4)(s-2) = 0$ $∴ s = 2,4$

微分演算子 D を使って $(D^2 - 6D + 8)y_1 = e^x$

$$y_1 = \frac{1}{D^2 - 6D + 8} e^x \quad D = 1 \text{を代入して}$$

$$= \frac{1}{3} e^x \quad \text{これから}$$

$$y = Ae^{2x} + Be^{4x} + \frac{1}{3}e^x \quad (A,B \text{は任意定数})$$

### (2)
$$y''-4y'+8y = e^{2x}$$

特性方程式は $s^2 - 4s + 8 = 0$ $∴ s = 2 ± 2i$

微分演算子 D を使って $(D^2 - 4D + 8)y_1 = e^{2x}$

$$y_1 = \frac{1}{D^2 - 4D + 8} e^{2x} \quad D = 2 \text{を代入して}$$

$$= \frac{1}{4} e^{2x} \quad \text{これから}$$

$$y = e^{2x}(A \sin 2x + B \cos 2x) + \frac{1}{4}e^{2x} \quad (A,B \text{は任意定数})$$

### (3)
$$y''-y'-2y = x^2 + x$$

特性方程式は $s^2 - s - 2 = 0$ $(s-2)(s+1) = 0$ $∴ s = 2,-1$

微分演算子 D を使って $(D^2 - D - 2)y_1 = x^2 + x$

$$y_1 = \frac{1}{D^2 - D - 2}(x^2 + x) = -\frac{1}{2}x^2 - \frac{1}{2} \quad \text{これから}$$

$$y = Ae^{-x} + Be^{2x} - \frac{1}{2}(x^2 + 1) \quad (A,B \text{は任意定数})$$

### (4)
$$y''+4y'+13y = x$$

特性方程式は $s^2 + 4s + 13 = 0$ $\therefore s = -2 \pm 3i$

微分演算子 D を使って $(D^2 + 4D + 13)y_1 = x$

$$y_1 = \frac{1}{D^2+4D+13}x = \frac{1}{13}x - \frac{4}{169}$$ これから

$$y = e^{-2x}(A\sin 3x + B\cos 3x) + \frac{1}{13}x - \frac{4}{169}$$ (A,B は任意定数)

### (5)
$$y''-2y'+5y = e^x \cos 2x$$

特性方程式は $s^2 - 2s + 5 = 0$ $\therefore s = 1 \pm 2i$

微分演算子 D を使って $(D^2 - 2D + 5)y_1 = e^x \cos 2x$

$$y_1 = \frac{1}{D^2-2D+5}e^x \cos 2x = e^x \text{Re}\left\{\frac{1}{(D+1)^2 - 2(D+1) + 5}e^{2ix}\right\} = e^x \text{Re}\left\{\frac{1}{D^2+4}e^{2ix}\right\}$$

D = 2i を代入すると分母が 0 となるのでロピタルの公式をまねて

$$= e^x \text{Re}\left\{\lim_{k \to 2i} \frac{xe^{kx}}{2k}\right\} = e^x \frac{1}{4}x \text{Re}\left\{\frac{e^{2ix}}{i}\right\} = \frac{1}{4}xe^x \sin 2x$$ これから

$$y = e^x(A\sin 2x + B\cos 2x) + \frac{1}{4}xe^x \sin 2x$$ (A,B は任意定数)

### (6)
$$y''-3y'+2y = x + e^{2x} \cos x$$

特性方程式は $s^2 - 3s + 2 = 0$ $(s-2)(s-1) = 0$ $\therefore s = 2,1$

微分演算子 D を使って $(D^2 - 3D + 2)y_1 = x$

$$y_1 = \frac{1}{D^2-3D+2}x = -\frac{1}{2}x + \frac{3}{4}$$

$$(D^2 - 3D + 2)y_2 = e^{2x} \cos x$$

$$y_2 = \frac{1}{D^2-3D+2}e^{2x} \cos x = e^{2x} \text{Re}\left\{\frac{1}{(D+2)^2 - 3(D+2) + 2}e^{ix}\right\} = e^{2x} \text{Re}\left\{\frac{1}{D^2+D}e^{ix}\right\}$$

$D = i$を代入して

$$= e^{2x} \text{Re}\left\{ \frac{1}{-1+i} e^x \right\} - \frac{1}{2} e^{2x} \text{Re}\{(1+i)(\cos x + i \sin x)\} = -\frac{1}{2} e^{2x} (\cos x - \sin x)$$

これから

$$y = Ae^x + Be^{2x} + \frac{2x+3}{4} - \frac{1}{2} e^{2x} (\cos x - \sin x)$$
