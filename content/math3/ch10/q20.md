### (1)
$$x'_{(t)} = -x + 4y + 2e^{-t}$$ ①
$$y'_{(t)} = 2y + x$$ ②
$$x_{(0)} = 0, y_{(0)} = 0$$

②から $y'' = 2y' + x'$  $x' = y'' - 2y'$ ③

①+②から $x' + y' = 6y + 2e^{-t}$ ④

④を③に代入して $$y'' - 2y' + y' = 6y + 2e^{-t}$$  $$y'' - y' - 6y = 2e^{-t}$$

### (1)

から　$$y'' - y' - 6y = 2e^{-t}$$

特性方程式は $$s^2 - s - 6 = (s-3)(s+2) = 0$$ ∴ $s = 3, -2$

微分演算子 D を使って $$(D^2 - D - 6)y_1 = 2e^{-t}$$

$$y_1 = \frac{2}{D^2 - D - 6}e^{-t}$$  $D = -1$を代入して

$$= -\frac{1}{2}e^{-t}$$  これから

$$y = Ae^{3t} + Be^{-2t} - \frac{1}{2}e^{-t}$$ ⑤

$$y' = 3Ae^{3t} - 2Be^{-2t} + \frac{1}{2}e^{-t}$$ ⑥

⑤、⑥を（１）②に代入して整理すると

$$x = Ae^{3t} - 4Be^{-2t} + \frac{3}{2}e^{-t}$$ ⑦

$x_{(0)} = 0$から⑦は $$0 = A - 4B + \frac{3}{2}$$ ⑦'

$y_{(0)} = 0$から⑤は $$0 = A + B - \frac{1}{2}$$ ⑥'  これから $$A = \frac{1}{10}$$ $$B = \frac{2}{5}$$  よって

$$x = \frac{1}{10}e^{3t} - \frac{8}{5}e^{-2t} + \frac{3}{2}e^{-t}$$

$$y = \frac{1}{10}e^{3t} + \frac{2}{5}e^{-2t} - \frac{1}{2}e^{-t}$$
