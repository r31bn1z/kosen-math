### (1)

微分方程式は $$\frac{d^2x}{dt^2} + k\frac{dx}{dt} = g$$

速度 v は $\frac{dx}{dt} = v$ とおくと上式は $$v' + kv = g$$

$P = k$、$Q = g$ とおくと $$\int Pdt = kt$$ これから

$$v = e^{-kt}\left\{\int e^{kt} g dt + C_1\right\} = e^{-kt}\left\{\frac{g}{k}e^{kt} + C_1\right\}$$

$v_{(0)} = v_0$ なので

$$\frac{g}{k} + C_1 = v_0$$   $$C_1 = v_0 - \frac{g}{k}$$   これから

$$v = e^{-kt}\left\{\frac{g}{k}e^{kt} + v_0 - \frac{g}{k}\right\} = \frac{1}{k}\{g + (kv_0 - g)e^{-kt}\}$$

### (1)

から

$$v = \frac{1}{k}\{g + (kv_0 - g)e^{-kt}\}$$   $v = \frac{dx}{dt}$ から

$$\frac{dx}{dt} = \frac{1}{k}\{g + (kv_0 - g)e^{-kt}\}$$

$$\int dx = \int \frac{1}{k}\{g + (kv_0 - g)e^{-kt}\}dt$$

$$x = \frac{g}{k}t + \frac{1}{k}(kv_0 - g)\left(-\frac{1}{k}\right)e^{-kt} + C_2$$

$x_{(0)} = 0$ なので これから

$$C_2 = \frac{1}{k^2}(kv_0 - g)$$ これから

$$x = \frac{g}{k}t - \frac{1}{k^2}(kv_0 - g)e^{-kt} + \frac{1}{k^2}(kv_0 - g) = \frac{g}{k}t + \frac{g - kv_0}{k^2}(e^{-kt} - 1)$$
