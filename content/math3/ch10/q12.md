### (1)
$$y'' + 3y' = 2\sin x + \cos x$$

特性方程式は $s^2 + 3s = 0$ $s(s+3) = 0$ $\therefore s = 0, -3$

微分演算子 D を使って $(D^2 + 3D)y_1 = 2\sin x$

$$y_1 = \frac{2}{D^2 + 3D} \sin x = \mathrm{Im}\left(\frac{2}{D^2 + 3D} e^{ix}\right)$$ $D = i$ を代入して

$$= \mathrm{Im}\left(\frac{2}{-1 + 3i} e^{ix}\right) = \mathrm{Im}\left(\frac{2}{-10}(1+3i)e^{ix}\right) = \mathrm{Im}\left(-\frac{1}{5}(1+3i)(\cos x + i\sin x)\right) = -\frac{1}{5}(3\cos x + \sin x)$$

$(D^2 + 3D)y_2 = \cos x$

$$y_2 = \mathrm{Re}\left\{-\frac{1}{10}(1+3i)(\cos x + i\sin x)\right\} = -\frac{1}{10}(\cos x - 3\sin x)$$ これから

$$y = A + Be^{-3x} - \frac{1}{5}(3\cos x + \sin x) - \frac{1}{10}(\cos x - 3\sin x)$$

$$= A + Be^{-3x} + \frac{1}{10}(\sin x - 7\cos x)$$ (A,B は任意定数)

### (2)
$$y'' - 4y' + 3y = 1 + e^x$$

特性方程式は $s^2 - 4s + 3 = 0$ $(s-1)(s-3) = 0$ $\therefore s = 1,3$ これから

微分演算子 D を使って $(D^2 - 4D + 3)y_1 = e^x$

$$y_1 = \frac{1}{D^2 - 4D + 3} e^x$$ $D = 1$ を代入すると分母が $0$ となるので ロピタルの公式をまわって

$$= \lim_{k \to 1} \frac{xe^{kx}}{2k-4} = -\frac{1}{2}e^x$$

$(D^2 - 4D + 3)y_2 = 1$

$$y_2 = \frac{1}{D^2 - 4D + 3} = \frac{1}{3}$$ これから

$$y = Ae^x + Be^{3x} - \frac{1}{2}xe^x + \frac{1}{3}$$ (A,B は任意定数)

### (3)
$$y'' - 3y' + 2y = x^2 + e^x \sin x$$

特性方程式は $s^2 - 3s + 2 = 0$ $(s-2)(s-1) = 0$ $\therefore s = 2,1$

微分演算子 D を使って $(D^2 - 3D + 2)y_1 = x^2$

$$y_1 = \frac{1}{D^2 - 3D + 2} x^2 = \frac{1}{4}(2x^2 + 6x + 7)$$

$(D^2 - 3D + 2)y_2 = e^x \sin x$

$$y_2 = \frac{1}{D^2 - 3D + 2} e^x \sin x = \text{Im}\left\{\frac{1}{(D+1)^2 - 3(D+1) + 2}\right\} e^{ix} = e^x \text{Im}\left\{\frac{1}{D^2 + 2D + 1 - 3D - 3 + 2}\right\} e^{ix}$$

$$= e^x \text{Im}\left\{\frac{1}{D^2 - D}\right\} e^{ix}$$ $D = i を代入して$

$$= e^x \text{Im}\left\{\frac{1}{-1-i} e^{ix}\right\} = e^x \text{Im}\left\{-\frac{1}{2}(1-i)(\cos x + i \sin x)\right\} = -\frac{1}{2} e^x (\sin x - \cos x)$$ これから

$$y = Ae^x + Be^{2x} + \frac{1}{4}(2x^2 + 6x + 7) - \frac{1}{2} e^x (\sin x - \cos x)$$ （A,B は任意定数）

### (4)
$$y'' - 5y' + 4y = 2x^2 - x$$

特性方程式は $s^2 - 5s + 4 = 0$ $(s-4)(s-1) = 0$ $\therefore s = 4,1$

微分演算子 D を使って $(D^2 - 5D + 4)y_1 = 2x^2 - x$

$$y_1 = \frac{1}{D^2 - 5D + 4}(2x^2 - x) = \frac{1}{2}x^2 + x + 1$$ これから

$$y = Ae^{4x} + Be^x + \frac{1}{2}x^2 + x + 1$$ （A,B は任意定数）

### (5)
$$y'' + 2y' + 5y = \sin x$$

特性方程式は $s^2 + 2s + 5 = 0$ $s = -1 \pm 2i$

微分演算子 D を使って $(D^2 + 2D + 5)y_1 = \sin x$

$$y_1 = \text{Im}\left\{\frac{1}{D^2 + 2D + 5} e^{ix}\right\}$$ $D = i を代入して$

$$= \operatorname{Im}\left\{\frac{1}{-1+2i+5}e^{ix}\right\} = \operatorname{Im}\left\{\frac{1}{4+2i}e^{ix}\right\} = \operatorname{Im}\left\{\frac{4-2i}{16+4}e^{ix}\right\} = \frac{1}{10}\operatorname{Im}\{(2-i)(\cos x + i\sin x)\}$$

$$= \frac{1}{10}(2\sin x - \cos x) \quad \text{これから}$$

$$y = e^x(A\sin 2x + B\cos 2x) + \frac{1}{10}(2\sin x - \cos x) \quad \text{(A,B \text{は任意定数})}$$

### (6)

$$y'' - 2y' + y = x\sin x$$

特性方程式は $s^2 - 2s + 1 = 0$ $(s-1)^2 = 0$ $\therefore s = 1$

微分演算子 D を使って $(D^2 - 2D + 1)y_1 = x\sin x$

$$y_1 = \frac{1}{D^2 - 2D + 1}x\sin x = \operatorname{Im}\left\{\frac{x}{(D+i)^2 - 2(D-i) + 1}e^{ix}\right\} = \operatorname{Im}\left\{\frac{x}{D^2 + 2(i-1)D - 2i}e^{ix}\right\}$$

$$= \operatorname{Im}\left\{\left(-\frac{x}{2i} - \frac{1+i}{2i}\right)e^{ix}\right\} = \operatorname{Im}\left\{\frac{1}{2}(-i)(xi - 1 + i)(\cos x + i\sin x)\right\} = \frac{1}{2}(x\cos x - \sin x + \cos x) \quad \text{これから}$$

$$y = e^x(Ax + B) + \frac{1}{2}(x\cos x - \sin x + \cos x) \quad \text{(A,B \text{は任意定数})}$$
