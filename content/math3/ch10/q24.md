### (1)

$(1-x^2)\frac{d^2y}{dx^2} - x\frac{dy}{dx} + 4y = 0$

$x = \cos t$ とおくと $t = \cos^{-1} x$

$\frac{dy}{dx} = \frac{dy}{dt} \cdot \frac{dt}{dx}$

$\frac{dt}{dx} = \frac{-1}{\sqrt{1-x^2}} = \frac{-1}{\sin t}$

$$\frac{d^2y}{dx^2} = \left(\frac{d^2y}{dt^2} \cdot \frac{dt}{dx}\right)\frac{dt}{dx} + \frac{dy}{dt}\frac{d^2t}{dx^2}$$

$$\frac{d^2t}{dx^2} = \frac{-x}{\sqrt{(1-x^2)^3}} = \frac{-\cos t}{\sin^3 t}$$

ここから与式は

$(1-\cos^2 t)\left[\left(\frac{-1}{\sin t}\right)^2 \frac{d^2y}{dt^2} + \frac{-\cos t}{\sin t}\frac{dy}{dt}\right] - \cos t \cdot \frac{-1}{\sin t}\frac{dy}{dt} + 4y = 0$

$\frac{d^2y}{dt^2} + \frac{\cos t}{\sin t}\frac{dy}{dt} + \frac{\cos t}{\sin t}\frac{dy}{dt} + 4y = 0$

$\frac{d^2y}{dt^2} + 4y = 0$

特性方程式は $s^2 + 4 = 0$ $\therefore s = \pm 2i$ これから

$y = A\sin 2t + B\cos 2t$

元に戻して

$y = A\sin(2\cos^{-1} x) + B\cos(2\cos^{-1} x)$

$= A[2\sin(\cos^{-1} x)\cos(\cos^{-1} x)] + B[\cos^2(\cos^{-1} x) - \sin^2(\cos^{-1} x)]$

$= 2A\sqrt{1-x^2} \cdot x + B\{x^2 - (1-x^2)\}$ $2A = A$ 書き直して

$$= Ax\sqrt{1-x^2} + B(2x^2-1)$$

(A,B は任意定数)

### (2)

$4x\frac{d^2y}{dx^2} + 2\frac{dy}{dx} + y = 0$

$x = t^2$ とおくと $t = \sqrt{x}$

$\frac{dt}{dx} = \frac{1}{2\sqrt{x}} = \frac{1}{2t}$

$\frac{d^2t}{dx^2} = -\frac{1}{4\sqrt{x^3}} = -\frac{1}{4t^3}$ これから与式は

$4t^2\left[\left(\frac{1}{2t}\right)^2 \frac{d^2y}{dt^2} + \left(-\frac{1}{4t^3}\right)\frac{dy}{dt}\right] + 2 \cdot \frac{1}{2t}\frac{dy}{dt} + y = 0$

$\frac{d^2y}{dt^2} + y = 0$

特性方程式は $s^2 + 1 = 0$ $\therefore s = \pm i$ これから

$y = A\sin t + B\cos t$

元に戻して

$y = A\sin \sqrt{x} + B\cos \sqrt{x}$ (A,B は任意定数)

### (3)

$(x+1)\frac{d^2y}{dx^2} + x\frac{dy}{dx} - y = 0$

$y = e^{-x}u$ とおくと   $y' = -e^{-x}u + e^{-x}u'$   $y'' = e^{-x}u - 2e^{-x}u' + e^{-x}u''$  これから与式は

$(x+1)(e^{-x}u - 2e^{-x}u' + e^{-x}u'') + x(-e^{-x}u + e^{-x}u') - e^{-x}u = 0$  $(x+1)u'' - (x+2)u' = 0$

$u' = P$ とおくと  $(x+1)P' - (x+2)P = 0$  $P' - \frac{x+2}{x+1}P = 0$

$$\int \frac{1}{P}dP = \int \frac{x+2}{x+1}dx = \int\left(1 + \frac{1}{x+1}\right)dx$$

$\log P = x + \log(x+1) + C_1$  $e^{C_1} = C_2$ とおくと

$P = C_2 e^x(x+1)$  元に戻して

$u' = C_2 e^x(x+1)$

$u = C_2 \{e^x + xe^{-x} - \int e^x dx\} + C_3 = C_2 xe^{-x} + C_3$  $C_2 = A$、$C_3 = B$ として元に戻して

$y = Ax + Be^{-x}$  （A,B は任意定数）

### (4)

$x^2\frac{d^2y}{dx^2} - (2a-1)x\frac{dy}{dx} + a^2y = 0$

$y = x^a u$ とおくと  $y' = ax^{a-1}u + x^au'$   $y'' = a(a-1)x^{a-2}u + 2ax^{a-1}u' + x^au''$  これから与式は

$x^2\{a(a-1)x^{a-2}u + 2ax^{a-1}u' + x^au''\} - (2a-1)x(ax^{a-1}u + x^au') + a^2x^au = 0$

$xu' + u' = 0$  $u' = P$ とおくと

$xP' + P = 0$

$$\int \frac{1}{P}dP = -\int \frac{1}{x}dx$$

$\log P = -\log x + C_1$  $e^{C_1} = C_2$ とおくと

$P = C_2 \frac{1}{x}$  元に戻して

$u' = \frac{C_2}{x}$  $u = C_2 \log x + C_3$  $C_1 = A$、$C_2 = B$ として元に戻して

$y = x^a(A\log x + B)$  （A,B は任意定数）
