### (1)
$$\frac{dy_1}{dx} + ay_1 = 0$$

$$\int \frac{1}{y_1} dy_1 = \int -a dx \quad \log y_1 = -ax + C_1 \quad e^{C_1} = C_2 \text{ とおくと}$$

$$y_1 = C_2 e^{-ax} \quad \text{（C \text{は任意定数}）}$$

$$\frac{d^2 y_2}{dx^2} + by_2 = 0$$

特性方程式は $s^2 + b = 0$ $\therefore x = \pm\sqrt{bi}$ これから

$$y = A \sin \sqrt{bx} + B \cos \sqrt{bx} \quad \text{（A, B \text{は任意定数}）}$$

### (2)
$y_1 + y_2 = y$ とおくと

$$y = y_1 + y_2 = Ce^{-ax} + A \sin \sqrt{bx} + B \cos \sqrt{bx} \quad ①$$

$$y' = -aCe^{-ax} + A\sqrt{b} \cos \sqrt{bx} - B\sqrt{b} \sin \sqrt{bx} \quad ②$$

$$y'' = a^2 Ce^{-ax} - Ab \sin \sqrt{bx} - Bb \cos \sqrt{bx} \quad ③$$

$$y''' = -a^3 Ce^{-ax} - Ab\sqrt{b} \cos \sqrt{bx} + Bb\sqrt{b} \sin \sqrt{bx} \quad ④$$

①×b+③から $\quad by + y'' = C(b + a^2)e^{-ax} \quad ⑤$

②×b+④から $\quad by'+y''' = -aC(b+a^2)e^{-ax} \quad ⑥$

⑤×（-a）+⑥から $\quad -a(by + y'') = by' + y'''$

$$y''' + ay'' + by' + aby = 0$$

### (3)
$$y_1 y_2 = Ce^{-ax}(\sin \sqrt{bx} + B \cos \sqrt{bx}) \quad CA = A, CB = B \text{ と書き直すと}$$

$$= e^{-ax}(A \sin \sqrt{bx} + B \cos \sqrt{bx})$$

これから特性方程式の解は $s = -a \pm \sqrt{bi}$ となる

$$(s + a + \sqrt{bi})(s + a - \sqrt{bi}) = 0 \quad s^2 + 2as + a^2 + b = 0 \quad \text{これから}$$

$$y'' + 2ay' + (a^2 + b)y = 0$$
