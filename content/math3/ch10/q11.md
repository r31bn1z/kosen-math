### (1)

$$x^2 y'' + xy' + y = x$$

$x = e^t$ とおくと  $y'' + y = e^t$

特性方程式は $s^2 + 1 = 0$ $\therefore s = \pm i$

微分演算子 D を使って $(D^2 + 1)y_1 = e^t$  $y_1 = \frac{1}{D^2+1}e^t = \frac{e^t}{2}$  これから

$$y = A\sin t + B\cos t + \frac{e^t}{2}$$  元に戻して

$$y = A\sin(\log x) + B\cos(\log x) + \frac{x}{2}$$  （A,B は任意定数）

### (2)

$$x^2 y'' - 2xy' + 2y = -2x + 2$$   $$y'' - \frac{2}{x}y' + \frac{2}{x^2}y = -\frac{2}{x} + \frac{2}{x^2}$$

$P = -\frac{2}{x}$、$Q = \frac{2}{x^2}$、$R = -\frac{2}{x} + \frac{2}{x^2}$ とおくと  $$y = \exp\left(-\frac{1}{2}\int -\frac{2}{x}dx\right) v = xv$$

$$I = \frac{2}{x^2} - \frac{1}{2}\left(\frac{2}{x^2}\right) - \frac{1}{4}\left(\frac{4}{x^2}\right) = 0$$    $J = -\frac{2}{x^2} + \frac{2}{x^3}$  これから

$$v'' = -\frac{2}{x^2} + \frac{2}{x^3}$$   $$v' = \frac{2}{x} - \frac{1}{x^2} + C_1$$   $$v = 2\log x + \frac{1}{x} + C_1 x + C_2$$

元に戻して  $C_1 = A$、$C_2 = B$ とおくと

$$y = 2x\log x + 1 + Ax^2 + Bx$$  （A,B は任意定数）

### (3)

$$(1 + x^2)y'' - 2xy' + 2y = \frac{1-x^2}{x}$$

$(1 + x^2)y'' - 2xy' + 2y = 0$ の式として考えると

$$m(m-1)(1+x^2) - 2mx^2 + 2x^2 = 0$$   $$(m-1)\{m(1-x^2) - 2x^2\} = 0$$   $m = 1$

これから $y = x$ を解に持つ

$y = xv$ とおくと  $y' = v + xv'$   $y'' = 2v' + xv''$  これから与式は

$(1+x^2)(2v'+xv'') - 2x(v+xv') + 2xv = \frac{1-x^2}{x}$   $x(1-x^2)v'' + 2v' = \frac{1-x^2}{x}$

$v'' + \frac{2}{x(1+x^2)} v' = \frac{1-x^2}{x^2(1+x^2)}$

$v' = P$ とおくと

$P' + \frac{2}{x(1+x^2)} P = \frac{1-x^2}{x^2(1+x^2)}$

$\alpha = \frac{2}{x(1+x^2)}、\beta = \frac{1-x^2}{x^2(1+x^2)}$ とおくと

$$\int \frac{2}{x(1+x^2)} dx = \int \left(\frac{2}{x} - \frac{2x}{1+x^2}\right) dx = 2\log x - \log(1+x^2)$$ これから

$$P = \frac{1+x^2}{x^2} \left\{\int \frac{x^2}{1+x^2} \cdot \frac{1-x^2}{x^2(1+x^2)} dx + C_1\right\} = \frac{1+x^2}{x^2} \left\{\int \frac{1-x^2}{(1+x^2)^2} dx + C_1\right\}$$

$$= \frac{1+x^2}{x^2} \left\{\int \frac{1}{(x^2+1)} dx + \int \frac{-x^2}{(x^2+1)^2} dx + C_1\right\}$$

$$= \frac{1+x^2}{x^2} \left\{\frac{1}{2}\left(\frac{x}{x^2+1} + \tan^{-1} x + \frac{x}{x^2+1} - \tan^{-1} x\right) + C_1\right\}$$

$$= \frac{1+x^2}{x^2}\left(\frac{x}{x^2+1} + C_1\right) = \frac{1}{x} + \frac{1+x^2}{x^2}C_1$$ 元に戻して

$v' = \frac{1}{x} + \frac{1+x^2}{x^2} C_1$  $v = \log x - \left(\frac{1-x}{x}\right) C_1 + C_2$ 元に戻して

$y = x\log x - (1-x^2)C_1 + C_2 x$  $C_1 = B、C_2 = A$ とおくと

$y = x\log x - B(1-x^2) + Ax$ （A,B は任意定数）

### (4)

$x^4 y'' + 2x^3 y' + y = \frac{x+1}{x}$

$t = \frac{1}{x}$ とおくと $t' = -\frac{1}{x^2}$  $\frac{dy}{dx} = \frac{dy}{dt}\frac{dt}{dx} = -t^2\frac{dy}{dt}$

$$\frac{d^2y}{dx^2} = \frac{d}{dt}\left(-t^2\frac{dy}{dt}\right)\frac{dx}{dt} = \left(-2t\frac{dy}{dt} - t^2\frac{d^2y}{dt^2}\right)(-t^2) = t^4\frac{d^2y}{dt^2} + 2t^3\frac{dy}{dt}$$ これから与式は

$$x^4\left(t^4\frac{d^2y}{dt^2} + 2t^3\frac{dy}{dt}\right) + 2x^3\left(-t^2\frac{dy}{dt}\right) + y = \frac{x+1}{x}$$

$$\frac{1}{t^4}\left(t^4\frac{d^2y}{dt^2}+2t^3\frac{dy}{dt}\right)+\frac{2}{t^3}\left(-t^2\frac{dy}{dt}\right)+y=t\left(\frac{1}{t}+1\right)$$

$$\frac{d^2y}{dt^2}+\frac{2}{t}\frac{dy}{dt}+\frac{2}{t}\frac{dy}{dt}+y=1+t \quad \frac{d^2y}{dt^2}+y=1+t$$

特性方程式は $s^2+1=0$ $s=\pm i$

微分演算子Dを使って $(D^2+1)y_1=t+1$ $y_1=\frac{t+1}{D^2+1}=t+1$ これから

$y=A\sin t+B\cos t+t+1$ 元に戻して

$y=A\sin\frac{1}{x}+B\cos\frac{1}{x}+\frac{1}{x}+1$ （$A,B$は任意定数）

### (5)

$xy''-(2x+1)y'+(x+1)y=(x^2+x-1)e^{2x}$

$P=x, Q=-(2x+1), R=x+1$として

$m^2x+m(2x+1)+x+1=0$ $\{mx-(x+1)\}(m-1)=0$ $m=1$

よって$y=e^xy$とおくと $y'=e^xy+e^xy'$ $y''=e^xy+2e^xy'+e^xy''$ これより与式は

$x(e^xy+2e^xy'+e^xy'')-(2x+1)(e^xy+e^xy')+(x+1)e^xy=(x^2+x-1)e^{2x}$

$xy''-y'=(x^2+x-1)e^x$ $y'=Pu$とおくと

$xP'-P=(x^2+x-1)e^x$ $P-\frac{1}{x}P=\frac{x^2+x-1}{x}e^x$

$\alpha=-\frac{1}{x}, \beta=\frac{x^2+x-1}{x}e^x$とおくと $\int\alpha dx=-\log x$ これから

$$P=x\left\{\int\frac{1}{x}\cdot\frac{x^2+x-1}{x}e^xdx+C_1\right\}=x\left\{\int\left[1+\frac{1}{x}-\frac{1}{x^2}\right]e^xdx+C_1\right\}=x\left\{\int e^xdx+\int\left(\frac{1}{x}-\frac{1}{x^2}\right)e^xdx+C_1\right\}$$

ここで$$\int\left(\frac{1}{x}-\frac{1}{x^2}\right)e^xdx=\int\frac{1}{x}e^xdx-\int\frac{1}{x^2}e^xdx=\frac{1}{x}e^x+\int\frac{1}{x^2}e^xdx+\frac{1}{x}e^x-\int\frac{1}{x}e^xdx$$

$$=\frac{2}{x}e^x-\int\left(\frac{1}{x}-\frac{1}{x^2}\right)e^xdx$$

$$\int\left(\frac{1}{x}-\frac{1}{x^2}\right)e^xdx=\frac{1}{x}e^x \quad \text{これから}$$

$P = x\{e^x + \frac{1}{x}e^x + C_1\}$ 元に戻して

$y' = xe^x + e^x + xC_1$ $y = xe^x - \int e^x dx + e^x + \frac{1}{2}C_1 x^2 + C_2 = xe^x + \frac{1}{2}C_1 x^2 + C_2$ 元に戻して

$y = xe^{2x} + e^x(\frac{1}{2}C_1 x^2 + C_2)$ $\frac{1}{2}C_1 = A, C_2 = B$ とおくと

$y = xe^{2x} + e^x(Ax^2 + B)$ ($A,B$ は任意定数)

### (6)

$(x+1)y'' - (3x+4)y' + 3y = (3x+2)e^{3x}$

$P = x+1$、$Q = -(3x+4)$、$R = 3$ とおくと

$m^2(x+1) - m(3x+4) + 3 = 0$ $\{m(x+1) - 1\}(m - 3) = 0$ $m = 3$

これから $y = e^{3x}v$ とおくと $y' = 3e^{3x}v + e^{3x}v'$ $y'' = 9e^{3x}v + 6e^{3x}v' + e^{3x}v''$ これから方程式は

$(x+1)(9e^{3x}v + 6e^{3x}v' + e^{3x}v'') - (3x+4)(3e^{3x}v + e^{3x}v') + 3e^{3x}v = (3x+2)e^{3x}$

$(x+1)v'' + (3x+2)v' = 3x+2$ $v' = P$ とおくと

$(x+1)P' + (3x+2)P = 3x+2$ $P' + \frac{3x+2}{x+1}P = \frac{3x+2}{x+1}$

$\alpha = \frac{3x+2}{x+1}$、$\beta = \frac{3x+2}{x+1}$ とおくと $\int \alpha dx = \int (3 - \frac{1}{x+1})dx = 3x - \log(x+1)$ これから

$$P = (x+1)e^{3x}\{\int \frac{e^{3x}}{x+1} \cdot \frac{3x+2}{x+1}dx + C_1\} = (x+1)e^{3x}\{\int (\frac{3}{x+1} - \frac{1}{(x+1)^2})e^{3x}dx + C_1\}$$

$= (x+1)e^{3x}\{3 \cdot \frac{1}{3} \cdot \frac{e^{3x}}{x+1} - \int \frac{-1}{(x+1)^2}e^{3x}dx - \int \frac{1}{(x+1)^2}e^{3x}dx + C_1\}$

$= (x+1)e^{3x}\{\frac{1}{x+1}e^{3x} + C_1\} = 1 + C_1(x+1)e^{-3x}$ 元に戻して

$v' = 1 + C_1(x+1)e^{-3x}$

$v = x + C_1\{-\frac{1}{3}(x+1)e^{-3x} + \frac{1}{3}\int e^{-3x}dx + C_2\} = x - \frac{C_1}{9}\{3(x+1) + 1\}e^{-3x} + C_1C_2$

$= x - \frac{C_1}{9}(3x+4)e^{-3x} + C_1C_2$

$y = e^{3x}$から

$y = xe^{3x} - \frac{C_1}{9}(3x+4) + C_1C_2e^{3x}$ $-\frac{C_1}{9} = A$、$C_1C_2 = B$と置くと

$y = A(3x+4) + Be^{3x} + xe^{3x}$ $(A,B \text{は任意定数})$
