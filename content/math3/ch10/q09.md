（証明）

$$\frac{dy}{dt} = \frac{dy}{dx} \cdot \frac{dx}{dt} = e^t \frac{dy}{dx} = x \frac{dy}{dx}$$

$$\frac{d^2y}{dt^2} = \frac{d}{dx}\left(\frac{dy}{dt}\right) \cdot \frac{dx}{dt} = \frac{d}{dx}\left(x\frac{dy}{dx}\right) \cdot e^t = e^t\left(\frac{dy}{dx} + x\frac{d^2y}{dx^2}\right) = x\left(\frac{dy}{dx} + x\frac{d^2y}{dx^2}\right) = x^2\frac{d^2y}{dx^2} + x\frac{dy}{dx}$$ これから

$$\frac{d^2y}{dt^2} + (a-1)\frac{dy}{dt} + by = 0$$ となる

### (1)

$$x^2\frac{d^2y}{dx^2} + 4x\frac{dy}{dx} + 2y = 0$$

$x = e^t$ とおくと与式は $y'' + 3y' + 2y = 0$

特性方程式は $s^2 + 3s + 2 = 0$ $(s+2)(s+1) = 0$ $\therefore s = -2, -1$ これから

$$y = Ae^{-t} + Be^{-2t}$$ 元に戻して

$$y = \frac{A}{x} + \frac{B}{x^2}$$ （A, B は任意定数）

### (2)

$$x^2\frac{d^2y}{dx^2} - 4x\frac{dy}{dx} + 6y = 0$$

$x = e^t$ とおくと $y'' - 5y' + 6y = 0$

特性方程式は $s^2 - 5s + 6 = 0$ $(s-3)(s-2) = 0$ $\therefore s = 3, 2$ これから

$$y = Ae^{3t} + Be^{2t}$$ 元に戻して

$$y = Ax^3 + Bx^2$$ （A, B は任意定数）

### (3)

$$x^2 \frac{d^2 y}{dx^2} + 4x\frac{dy}{dx} + 2y = \frac{1}{x}$$

$x = e^t$ おくと $y'' + 3y' + 2y = e^{-t}$

特性方程式は $s^2 + 3s + 2 = 0$ $(s+2)(s+1) = 0$ $\therefore s = -2, -1$

微分演算子 D を使って $(D^2 + 3D + 2)y_1 = e^{-t}$

$$y_1 = \frac{1}{D^2 + 3D + 2} e^{-t}$$ $D = -1$ を代入すると分母が０となるのでロピタルの公式をもちいて

$$= \lim_{k \to 1} \frac{te^{kt}}{2k+3} = te^{-t}$$ これから

$$y = Ae^{-t} + Be^{-2t} + te^{-t}$$ 元に戻して

$$y = \frac{A}{x} + \frac{B}{x^2} + \frac{1}{x}\log x$$ （A,B は任意定数）

### (4)

$$x^2 y'' + 3xy' + y = x$$

$x = e^t$ おくと $y'' + 2y' + y = e^t$

特性方程式は $s^2 + 2s + 1 = 0$ $(s+1)^2 = 0$ $\therefore s = -1$

微分演算子 D を使って $(D^2 + 2D + 1)y_1 = e^t$

$$y_1 = \frac{1}{D^2 + 2D + 1} e^t$$ $D = 1$ を代入して

$$= \frac{1}{1^2 + 2 \cdot 1 + 1} e^t = \frac{1}{4} e^t$$ これから

$$y = Ale^{-t} + Be^{-t} + \frac{1}{4}e^t$$ 元に戻して

$$y = A \frac{1}{x} + B \frac{1}{x} \log x + \frac{1}{4}x$$

（A,B は任意定数）
