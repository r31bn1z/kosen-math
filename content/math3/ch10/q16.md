### (1)

$y'' + 3y' + 2y = 0$  $y(0) = 1, y'(0) = 2$

特性方程式は $s^2 + 3s + 2 = 0$  $(s + 2)(s + 1) = 0$  $\therefore s = -2, -1$  これから

$y = Ae^{-2x} + Be^{-x}$

$y(0) = 1$から $1 = A + B$  ①

$y' = -2Ae^{-2x} - Be^{-x}$

$y'(0) = 2$から $2 = -2A - B$  ②

①、②から $A = -3、B = 4$  これから

$y = -3e^{-2x} + 4e^{-x}$

### (2)

$y'' + 2y' + 5 = 0$  $y(0) = \sqrt{3}, y'(0) = -\sqrt{3} - 2$

特性方程式は $s^2 + 2s + 5 = 0$  $\therefore s = -1 \pm 2i$  これから

$y = e^{-x}(A\sin 2x + B\cos 2x)$

$y(0) = \sqrt{3}$から  $\sqrt{3} = B$  ①

$y' = -e^{-x}(A\sin 2x + B\cos 2x) + e^{-x}(2A\cos x - 2B\sin 2x)$

$y'(0) = -\sqrt{3} - 2$から $-\sqrt{3} - 2 = -B + 2A$  ②

①、②から $A = -1、B = \sqrt{3}$  これから

$y = e^{-x}(-\sin 2x + \sqrt{3}\cos 2x)$

### (3)

$y'' + 3y' + 2y = 1$  $y(0) = 0, y'(0) = 0$

特性方程式は $s^2 + 3s + 2 = 0$  $(s + 2)(s + 1) = 0$  $\therefore s = -2, -1$

微分演算子 D を使って $(D^2 + 3D + 2)y_1 = 1$

$$y_1 = \frac{1}{D^2 + 3D + 2} = \frac{1}{2}$$  これから

$y = Ae^{-2x} + Be^{-x} + \frac{1}{2}$

$y_{(0)} = 0$ から $0 = A + B + \frac{1}{2}$ ①

$y' = -2Ae^{-2x} - Be^{-x}$

$y'_{(0)} = 0$ から $0 = -2A - B$ ②

①、②から、 $A = \frac{1}{2}$、$B = -1$ これから

$y = \frac{1}{2}e^{-2x} - e^{-x} + \frac{1}{2}$

### (4)

$y'' - 4y = \sin x$ $y_{(0)} = 0$、$y'_{(0)} = 3$

特性方程式は $s^2 - 4 = 0$ $\therefore s = \pm 2$

微分演算子 $D$ を使って $(D^2 - 4)y_1 = \sin x$

$y_1 = \text{Im}\left\{\frac{1}{D^2 - 4}e^{ix}\right\}$ $D = i$ を代入して

$= \text{Im}\left\{\frac{1}{-1-4}e^{ix}\right\} = \text{Im}\left\{-\frac{1}{5}(\cos x + i\sin x)\right\} = -\frac{1}{5}\sin x$ これから

$y = Ae^{2x} + Be^{-2x} - \frac{1}{5}\sin x$

$y_{(0)} = 0$ から $0 = A + B$ ①

$y' = 2Ae^{2x} - 2Be^{-2x} - \frac{1}{5}\cos x$

$y'_{(0)} = 3$ から $3 = 2A - 2B - \frac{1}{5}$ ②

①、②から、 $A = \frac{4}{5}$、$B = -\frac{4}{5}$ これから

$y = \frac{1}{5}(4e^{2x} - 4e^{-2x} - \sin x)$
