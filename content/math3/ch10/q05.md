### (1)
$y'' - 5y' + 6y = e^{4x}$

特性方程式は $s^2 - 5s + 6 = 0$ $(s-2)(s-3) = 0$ $\therefore s = 2,3$

微分演算子 D を使って $(D^2 - 5D + 6)y_1 = e^{4x}$

$y_1 = \frac{1}{D^2 - 5D + 6} e^{4x}$ $D = 4$ を代入して

$= \frac{1}{4^2 - 5 \cdot 4 + 6} e^{4x} = \frac{1}{2} e^{4x}$ これから

$y = Ae^{2x} + Be^{3x} + \frac{1}{2}e^{4x}$ （A,B は任意定数）

### (2)
$y'' - 6y' + 9y = e^{3x}$

特性方程式は $s^2 - 6s + 9 = 0$ $(s-3)^2 = 0$ $\therefore s = 3$ （重解）

微分演算子 D を使って $(D^2 - 6D + 9)y_1 = e^{3x}$

$y_1 = \frac{1}{D^2 - 6D + 9} e^{3x}$ $D = 3$ を代入して

$= \frac{1}{3^2 - 6 \cdot 3 + 9} e^{3x} = \frac{1}{0} e^{3x}$ 分母が 0 となってしまうのでロピタルの公式をまわって

$$y_1 = \lim_{D \to 3} \frac{xe^{Dx}}{2D - 6}$$

分母が 0 となってしまうので

$$y_1 = \lim_{D \to 3} \frac{x^2 e^{Dx}}{2} = \frac{x^2}{2} e^{3x}$$

これから

$y = (A + Bx + \frac{x^2}{2})e^{3x}$ （A,B は任意定数）

### (3)
$y'' - 4y' + 13y = 9e^{2x}$

特性方程式は $s^2 - 4s + 13 = 0$ で $s = 2 \pm \sqrt{4-13} = 2 \pm 3i$

微分演算子 $D$ を使って $(D^2 - 4D + 13)y_1 = 9e^{2x}$

$y_1 = \frac{9}{D^2 - 4D + 13} e^{2x}$、$D = 2$を代入して

$= \frac{9}{2^2 - 4 \cdot 2 + 13} e^{2x} = e^{2x}$ これから

$y = e^{2x}(A \sin 3x + B \cos 3x + 1)$（A,B は任意定数）

### (4)
$y'' - 4y' + 3y = 2e^{3x}$

特性方程式は $s^2 - 4s + 3 = 0$ で $(s-3)(s-1) = 0$ $\therefore s = 3,1$

微分演算子 $D$ を使って $(D^2 - 4D + 3)y_1 = 2e^{3x}$

$y_1 = \frac{2}{D^2 - 4D + 3} e^{3x}$、$D = 3$を代入して

$= \frac{2}{3^2 - 4 \cdot 3 + 3} e^{3x} = \frac{2}{0} e^{3x}$

分母が $0$ となってしまうのでロピタルの公式をまねて

$$y_1 = \lim_{t \to 3} \frac{2x}{2t - 4} e^{tx} = xe^{3x}$$

これから

$y = Ae^x + Be^{3x} + xe^{3x}$（A,B は任意定数）

### (5)
$y'' + 6y' - 16y = 8$

特性方程式は $s^2 + 6s - 16 = 0$ で $(s+8)(s-2) = 0$ $\therefore s = 2, -8$

微分演算子 $D$ を使って $(D^2 + 6D - 16)y_1 = 8$、$y_1 = \frac{8}{D^2 + 6D - 16} = -\frac{1}{2}$ これから

$y = Ae^{2x} + Be^{-8x} - \frac{1}{2}$（A,B は任意定数）

### (6)
$$y'' + 6y' + 18y = 9x$$

特性方程式は $s^2 + 6s + 18 = 0$ $s = -3 \pm \sqrt{9-18} = -3 \pm 3i$

微分演算子 D を使って $(D^2 + 6D + 18)y_1 = 9x$

$$y_1 = \frac{9x}{D^2 + 6D + 18} = \frac{1}{2}x - \frac{1}{6}$$ これから

$$y = e^{-3x}(A \sin 3x + B \cos 3x) + \frac{x}{2} + \frac{1}{6}$$ (A,B は任意定数)

### (7)
$$y'' - 2y' + y = (x^2 + x)e^x$$

特性方程式は $s^2 - 2s + 1 = 0$ $(s-1)^2 = 0$ ∴ $s = 1$(重解)

微分演算子 D を使って $(D^2 - 2D + 1)y_1 = (x^2 + x)e^x$

$$y_1 = \frac{1}{D^2 - 2D + 1}(x^2 + x)e^x = \frac{1}{(D-1)^2}(x^2 + x)e^x = e^x \frac{1}{(D+1-1)^2}(x^2 + x) = e^x \frac{1}{D^2}(x^2 + x)$$

$$= e^x \int \int (x^2 + x)\,dx\,dx = e^x \int \left(\frac{1}{3}x^3 + \frac{1}{2}x^2\right) dx = e^x \left(\frac{1}{12}x^4 + \frac{1}{6}x^3\right)$$ これから

$$y = e^x \left(Ax + B + \frac{1}{12}x^4 + \frac{1}{6}x^3\right)$$ (A,B は任意定数)

### (8)
$$y'' + y' + y = 3\cos x$$

特性方程式は $s^2 + s + 1 = 0$ $s = \frac{-1 \pm \sqrt{1-4}}{2} = \frac{-1 \pm \sqrt{3}i}{2}$

微分演算子 D を使って $(D^2 + D + 1)y_1 = 3\cos x$

$$y_1 = \frac{1}{D^2 + D + 1} 3\cos x = \mathrm{Re}\left(\frac{3}{D^2 + D + 1}e^{ix}\right) = \mathrm{Re}\left(\frac{3}{i^2 + i + 1}e^{ix}\right) = \mathrm{Re}\left(\frac{3}{i}e^{ix}\right)$$

$$= -3\mathrm{Re}(ie^{ix}) = -3\mathrm{Re}(i\cos x - \sin x) = 3\sin x$$ これから

$$y = e^{-\frac{1}{2}x}\left(A \sin \frac{\sqrt{3}}{2}x + B \cos \frac{\sqrt{3}}{2}x\right) + 3\sin x$$ (A,B は任意定数)

$$y'' - 2y' + 3y = \sin x$$

特性方程式は $s^2 - 2s + 3 = 0$  $s = 1 \pm \sqrt{-2} = 1 \pm \sqrt{2}i$

微分演算子Dを使って $(D^2 - 2D + 3)y_1 = \sin x$

$$y_1 = \frac{1}{D^2 - 2D + 3} \sin x = \text{Im}\left(\frac{1}{D^2 - 2D + 3} e^{ix}\right) = \text{Im}\left(\frac{1}{i^2 - 2i + 3} e^{ix}\right) = \text{Im}\left(\frac{1}{2 - 2i} e^{ix}\right) = \frac{1}{2} \text{Im}\left(\frac{1+i}{1+1} e^{ix}\right)$$

$$= \frac{1}{4} \text{Im}\{(1+i)(\cos x + i \sin x)\} = \frac{1}{4}(\cos x + \sin x)$$ これから

$$y = e^x(A \sin \sqrt{2}x + B \cos \sqrt{2}x) + \frac{1}{4}(\sin x + \cos x)$$  (A,B は任意定数)

### (10)
$$y'' + 4y = \cos 2x$$

特性方程式は $s^2 + 4 = 0$  $\therefore s = \pm 2i$

微分演算子Dを使って $(D^2 + 4)y_1 = \cos 2x$

$$y_1 = \frac{1}{D^2 + 4} \cos 2x = \text{Re}\left(\frac{1}{D^2 + 4} e^{2ix}\right)$$

$D = 2i$ を代入すると分母が0となるのでロピタルの公式をまわいて

$$= \text{Re}\left(\lim_{s \to 2i} \frac{x e^{ix}}{2}\right) = \text{Re}\left(\frac{x}{4i} e^{2ix}\right) = \text{Re}\left(-\frac{i}{4} x(\cos 2x + i \sin 2x)\right) = \frac{1}{4}x \sin 2x$$ これから

$$y = A \sin 2x + B \cos 2x + \frac{1}{4} x \sin 2x$$  (A,B は任意定数)
