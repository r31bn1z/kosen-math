### (1)
$x^2y'' + xy' - y = 0$

$m(m-1)x^2 + mx^2 - x^2 = m^2x^2 - m^2x^2 + mx^2 - x^2 = x^2(m^2 - 1)$

$m = \pm1$ より、$y = x^{\pm1}$ を解に持つ

$y = xv$ とおくと、$y' = v + xv'$、$y'' = 2v + xv''$ から、与式は

$x^2(2v + xv'') + x(v + xv') - xv = 0$ ⋯ $x^3v'' + 3x^2v' = 0$ ⋯ $v'' + \frac{3}{x}v' = 0$ ⋯ $v' = P$ とおくと

$P' + \frac{3}{x}P = 0$

$\alpha = \frac{3}{x}, \beta = 0$ とおくと $\int\alpha dx = 3\log x$ これから

$P = \frac{1}{x^3}\{\int 0dx + C_1\} = \frac{1}{x^3}C_1$ 元に戻して

$v' = \frac{1}{x^3}C_1$ ⋯ $v = -\frac{1}{2x^2}C_1 + C_2$ 元に戻して

$\frac{y}{x} = -\frac{1}{2x^2}C_1 + C_2$ ⋯ $-\frac{1}{2}C_1 = A, C_2 = B$ とおくと

$y = \frac{1}{x}A + Bx$ （A,B は任意定数）

### (2)
$$(1-x)y'' + xy' - y = 0$$

$$P = 1-x, Q = x, R = -1 \text{ かち}$$

$$m(m-1)(1-x) + mx \cdot x - x^2 = 0 \quad m^2 - m - m^2 x + mx + mx^2 - x^2 = 0$$

$$(x^2 - xm + m)(m-1) = 0 \quad m = 1, \frac{x \pm \sqrt{3ix}}{2x^2} \text{ これらを } y = x \text{ を解に持つ}$$

$$y = xv \text{ とおくと } \quad y' = v + xv' \quad y'' = 2v + xv'' \quad \text{ かつ、\text{与式は}}$$

$$(1-x)(2v + xv'') + x(v + xv') - xv = 0 \quad 2v' + xv'' - 2xv' - x^2v'' + xv + x^2v' - xv = 0$$

$$(x(1-x))v'' + (x^2 - 2x + 2)v' = 0 \quad v' = P \text{ とおくと } \quad v'' = P' \text{ から}$$

$$x(1-x)P' + (x^2 - 2x + 2)P = 0 \quad \frac{1}{P} P' = \frac{x^2 - 2x + 2}{x(1-x)} = -1 - \frac{2}{x} + \frac{1}{x-1}$$

$$\int \frac{1}{P} dP = \int \left(1 - \frac{2}{x} + \frac{1}{x-1}\right)dx \quad \log P = x - 2\log x + \log(x-1) + C_1 \quad e^{C_1} = C_2 \text{ とおくと}$$

$$P = C_2 e^x \frac{x-1}{x^2} \quad \text{元に戻して}$$

$$v' = C_2 \left(-\frac{e^x}{x^2} + \frac{e^x}{x}\right) \quad \int dv = \int C_2 \left(-\frac{e^x}{x^2} + \frac{e^x}{x}\right)dx$$

$$\text{ここで } I = C_2 \int \left(-\frac{e^x}{x^2} + \frac{e^x}{x}\right)dx = C_2 \left(\frac{e^x}{x} - \int \frac{e^x}{x} dx + \frac{e^x}{x} + \int \frac{e^x}{x} dx\right) = \frac{2C_2}{x} e^x - \int C_2 \left(-\frac{e^x}{x^2} + \frac{e^x}{x}\right)dx$$

$$= \frac{2C_2}{x} e^x - I$$

$$I = \frac{C_2}{x} e^x \quad \text{これから}$$

$$v = \frac{C_2}{x} e^x + C_3 \quad \text{元に戻して}$$

$$y = x\left(\frac{C_2}{x} e^x + C_3\right) \quad C_2 = A, C_3 = B \text{ とおくと}$$

$$y = Ae^x + Bx \quad (A,B \text{ は任意定数})$$

### (3)
$(1+x^2)y''+2xy'-2y=0$

$m(m-1)(1+x^2)+mx \cdot 2x-2x^2=0$ $m^2+m^2x^2-m-mx^2+2mx^2-2x^2=0$

$(m+mx^2+2x^2)(m-1)=0$ $m=1$ これかもy=xを解に持つ

$y=xv$とおくと $y'=v+xv'$ $y''=2v'+xv''$  から、与式は

$(1+x^2)(2v+xv'')+2x(v+xv')-2xv=0$ $x(1+x^2)v''+(4x^2+2)=0$

$v'=P$とおくと

$x(1+x^2)P'+(4x^2+2)P=0$ $\frac{1}{P}P'=-\frac{4x^2+2}{x(1+x^2)}=-\frac{2}{x}-\frac{2x}{1+x^2}$

$\int\frac{1}{P}dP=\int\left(-\frac{2}{x}-\frac{2x}{1+x^2}\right)dx$ $\log P=-2\log x-\log(1+x^2)+C_1$ $e^{C_1}=C_2$とおくと

$P=\frac{C_2}{x^2(1+x^2)}$ 元に戻して

$v'=\frac{C_2}{x^2(1+x^2)}=C_2\left(\frac{1}{x^2}-\frac{1}{1+x^2}\right)$

$\int dv=C_2\int\left(\frac{1}{x^2}-\frac{1}{1+x^2}\right)dx$ $v=C_2\left(-\frac{1}{x}-\tan^{-1}x\right)+C_3$ 元に戻して

$y=x\left\{C_2\left(-\frac{1}{x}-\tan^{-1}x\right)+C_3\right\}$ $-C_2=A, C_3=B$とおくと

$y=A(1+x\tan^{-1}x)+Bx$ （A,Bは任意定数）
