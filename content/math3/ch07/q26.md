$$S = \frac{1}{2}a'^2\sin x + \frac{1}{2}a'^2\sin y + \frac{1}{2}a'^2\sin z + \frac{1}{2}a'^2\sin w$$

角度 $x+y+z+w=2\pi$ 条件

$g = x+y+z+w-2\pi$ とおく

$$S_x = \frac{1}{2}a'^2\cos x \qquad S_y = \frac{1}{2}a'^2\cos y$$

$$S_z = \frac{1}{2}a'^2\cos z \qquad S_w = \frac{1}{2}a'^2\cos w$$

直方体頂点が球に接している所で切り

この時の円の半径を$a'$とする

$$g_x = g_y = g_z = g_w = 1$$

ラグランジュの乗数法から

$$
\begin{cases}
\dfrac{1}{2}a'^2\cos x - \lambda = 0 \\
\dfrac{1}{2}a'^2\cos y - \lambda = 0 \\
\dfrac{1}{2}a'^2\cos z - \lambda = 0 \\
\dfrac{1}{2}a'^2\cos w - \lambda = 0
\end{cases}
$$

これから $\cos x = \cos y = \cos z = \cos w$  $\therefore x=y=z=w=\dfrac{\pi}{2}$

よって正方形となる。これは６面全てに言えるので立方体となる

このとき体積は $\dfrac{8}{3\sqrt{3}}a^3$
