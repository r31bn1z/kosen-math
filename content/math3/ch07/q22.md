$x + y + z = a$ 条件

$g = x + y + z - a$ とおく

$f = x^m y^n z^p$

$$g_x = g_y = g_z = 1 \qquad f_x = mx^{m-1}y^n z^p \qquad f_y = nx^m y^{n-1}z^p \qquad f_z = px^m y^n z^{p-1}$$

ラグランジュの乗数法から

$$\begin{cases} mx^{m-1}y^n z^p - \lambda = 0 \\ nx^m y^{n-1}z^p - \lambda = 0 \\ px^m y^n z^{p-1} - \lambda = 0 \end{cases}$$

これから $\lambda = mx^{m-1}y^n z^p = nx^m y^{n-1}z^p = px^m y^n z^{p-1}$

$$y = \frac{n}{m}x \qquad z = \frac{p}{m}x$$

これを条件式に代入して整理すると

$$x = \frac{am}{m+n+p}$$

同様に考えて $y = \dfrac{an}{m+n+p} \qquad z = \dfrac{ap}{m+n+p}$

このとき最大値は $m^m n^n p^p \left( \dfrac{a}{n+m+p} \right)^{m+n+p}$
