### (1)
$$z = x(1-x^2-y^2) = x - x^3 - xy^2$$

$$z_x = 1-3x^2-y^2 \qquad z_y = -2xy \qquad z_{xx} = -6x \qquad z_{yy} = -2x \qquad z_{xy} = -2y$$

$z_x = z_y = 0$ のとき $(x,y) = (0,\pm1), (\pm\dfrac{1}{\sqrt{3}}, 0)$

$$H_{(x,y)} = 12x^2 - 4y^2$$

$(0,\pm1)$のとき $H<0$

$(\pm\dfrac{1}{\sqrt{3}},0)$のとき $H>0$

$z_{xx(\frac{1}{\sqrt{3}},0)} < 0$ 極大  $z_{xx(-\frac{1}{\sqrt{3}},0)} > 0$ 極小

よって$(\dfrac{1}{\sqrt{3}},0)$のとき極大値$\dfrac{2}{3\sqrt{3}}$  $(-\dfrac{1}{\sqrt{3}},0)$のとき極大値$-\dfrac{2}{3\sqrt{3}}$

### (2)
$$z = (x^2+y^2)^2 - 2(x^2-y^2)$$

$$z_x = 4x(x^2+y^2)-4x = 4x(x^2+y^2-1)$$

$$z_y = 4y(x^2+y^2)+4y = 4y(x^2+y^2+1)$$

$$z_{xx} = 4(x^2+y^2-1)+8x^2 = 4(3x^2+y^2-1)$$

$$z_{yy} = 4(x^2+y^2+1)+8y^2 = 4(x^2+3y^2+1)$$

$$z_{xy} = 8xy$$

$z_x = z_y = 0$のとき   $(x,y) = (0,0), (\pm1,0)$

$$H_{(x,y)} = 4(3x^2+y^2-1)\cdot 4(x^2+3y^2+1) - 64x^2y^2$$

$H_{(0,0)} = -16 < 0$

$H_{(\pm1,0)} = 64 > 0$

$z_{xx(\pm1,0)} = 8 > 0$ 極小

よって$(\pm1,0)$のとき極小値$-1$

### (3)

$$z = x^4 + y^2 + 2x^2 - 4xy + 1$$

$$z_x = 4x^3 + 4x - 4y \qquad z_y = 2y - 4x \qquad z_{xx} = 12x^2 + 4 \qquad z_{yy} = 2 \qquad z_{xy} = -4$$

$z_x = z_y = 0$ のとき  $(x,y) = (0,0),(\pm1,\pm2)$

$$H_{(x,y)} = 2(12x^2+4) - 16$$

$(0,0)$ のとき $H_{(0,0)} < 0$

$(\pm1,\pm2)$ のとき $H_{(\pm1,\pm2)} > 0$

$z_{xx(\pm1,\pm2)} > 0$  極小

よって $(\pm1,\pm2)$ のとき極小値 $0$ （複合同順）

### (4)

$$z = (x^2+2y^2)e^{-x^2-y^2}$$

$$z_x = 2xe^{-x^2-y^2} - 2x(x^2+2y^2)e^{-x^2-y^2} = 2xe^{-x^2-y^2}(1-x^2-2y^2)$$

$$z_y = 4ye^{-x^2-y^2} - 2y(x^2+2y^2)e^{-x^2-y^2} = 2ye^{-x^2-y^2}(2-x^2-2y^2)$$

$$z_{xx} = 2e^{-x^2-y^2}(1-x^2-2y^2) - 4x^2e^{-x^2-y^2}(1-x^2-2y^2) - 4x^2e^{-x^2-y^2}$$

$$z_{yy} = 2e^{-x^2-y^2}(2-x^2-2y^2) - 4y^2e^{-x^2-y^2}(2-x^2-2y^2) - 8y^2e^{-x^2-y^2}$$

$$z_{xy} = -4xye^{-x^2-y^2}(1-x^2-2y^2) - 8xye^{-x^2-y^2}$$

$z_x = z_y = 0$ のとき  $(x,y) = (0,0),(0,\pm1),(\pm1,0)$

$H_{(0,0)} = 4 > 0$  $z_{xx(0,0)} > 0$  極小

$H_{(0,\pm1)} > 0$  $z_{xx(0,\pm1)} < 0$  極大

$H_{(\pm1,0)} < 0$

よって $(0,0)$ のとき極小値 $0$  $(0,\pm1)$ のとき極小値 $\dfrac{2}{e}$

### (5)

$$z = xe^{-x^2-y^2}$$

$$z_x = e^{-x^2-y^2} - 2x^2e^{-x^2-y^2} = e^{-x^2-y^2}(1-2x^2) \qquad z_y = -2xye^{-x^2-y^2}$$

$$z_{xx} = -4xe^{-x^2-y^2} + 2x(2x^2-1)e^{-x^2-y^2} = 2xe^{-x^2-y^2}(2x^2-3)$$

$$z_{yy} = -2xe^{-x^2-y^2} + 4xy^2e^{-x^2-y^2} = 2xe^{-x^2-y^2}(2y^2-1)$$

$$z_{xy} = 2y(2x^2-1)e^{-x^2-y^2}$$

$z_x = z_y = 0$ のとき $\qquad (x,y) = (\pm\dfrac{1}{\sqrt2},0)$

$$H_{(\frac{1}{\sqrt2},0)} > 0$$

$$H_{(-\frac{1}{\sqrt2},0)} > 0$$

$$z_{xx(\frac{1}{\sqrt2},0)} = -\frac{1}{\sqrt2}e^{-\frac12} = -\frac{1}{\sqrt{2e}} < 0 \quad \text{極大}$$

$$z_{xx(-\frac{1}{\sqrt2},0)} = \frac{1}{\sqrt{2e}} > 0 \quad \text{極小}$$

よって $(\dfrac{1}{\sqrt2},0)$ のとき極大値 $\dfrac{1}{\sqrt{2e}}$ $\qquad$ $(-\dfrac{1}{\sqrt2},0)$ のとき極小値 $-\dfrac{1}{\sqrt{2e}}$
