$$S = \frac{1}{2}ax + \frac{1}{2}by + \frac{1}{2}cz$$

$$f = xyz$$

$$S_x = \frac{1}{2}a \qquad S_y = \frac{1}{2}b \qquad S_z = \frac{1}{2}c \qquad f_x = yz \qquad f_y = xz \qquad f_z = xy$$

ラグランジュの乗数法から

$$\begin{cases} yz - \dfrac{1}{2}a\lambda = 0 \\ xz - \dfrac{1}{2}b\lambda = 0 \\ xy - \dfrac{1}{2}c\lambda = 0 \end{cases}$$

これから $\lambda = \dfrac{2}{a}yz = \dfrac{2}{b}xz = \dfrac{2}{c}xy$  $x = \dfrac{b}{a}y$  $z = \dfrac{b}{c}y$

これを条件式に代入して $S = \dfrac{3}{2}by$  $y = \dfrac{2S}{3b}$

同様に $x = \dfrac{2S}{3a}$  $z = \dfrac{2S}{3c}$

よって $a,b,c$ までの距離が $\dfrac{2S}{3a}, \dfrac{2S}{3b}, \dfrac{2S}{3c}$ の点
