$x + y + z = 1$ 条件

$g = x + y + z - 1$ とおく

$$H = -\{x \log x + y \log y + z \log z\}$$

$g_x = g_y = g_z = 1$

$$H_x = -\frac{1}{\log 2}(\log x + 1) \qquad H_y = -\frac{1}{\log 2}(\log y + 1) \qquad H_z = -\frac{1}{\log 2}(\log z + 1)$$

ラグランジュの乗数法から

$$
\begin{cases}
-\dfrac{1}{\log 2}(\log x + 1) - \lambda = 0 \\[2mm]
-\dfrac{1}{\log 2}(\log y + 1) - \lambda = 0 \\[2mm]
-\dfrac{1}{\log 2}(\log z + 1) - \lambda = 0
\end{cases}
$$

これから $\log x = \log y = \log z$

よって $x = y = z = \dfrac{1}{3}$

このとき $H = \log_2 3$
