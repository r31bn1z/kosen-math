$x + 2y + 3z = 1$ 条件

$g = x + 2u + 3z - 1$ とおく

$f = x^2 + y^2 + z^2$

$g_x = 1$  $g_y = 2$  $g_z = 3$   $f_x = 2x$  $f_y = 2y$  $f_z = 2z$

ラグランジュの乗数法から

$$
\begin{cases}
2x - \lambda = 0 \\
2y - 2\lambda = 0 \\
2z - 3\lambda = 0
\end{cases}
$$

これから $y = 2x$、$z = 3x$ となる

これを条件式に代入して $x = \dfrac{1}{14}$

同様にして $y = \dfrac{1}{7}$、$z = \dfrac{3}{14}$ を得る

$f$ の式に代入して

$$x^2 + y^2 + z^2 = \dfrac{1}{14}$$

よって $\dfrac{1}{14}$
