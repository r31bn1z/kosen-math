7.12 と同様に

$$S = \frac{1}{2}ax + \frac{1}{2}by + \frac{1}{2}cz$$

$$f = x^2 + y^2 + z^2$$

$$S_x = \frac{1}{2}a \qquad S_y = \frac{1}{2}b \qquad S_z = \frac{1}{2}c \qquad f_x = 2x \qquad f_y = 2y \qquad f_z = 2z$$

ラグランジュの乗数法から

$$\begin{cases} 2x - \dfrac{1}{2}a\lambda = 0 \\ 2y - \dfrac{1}{2}b\lambda = 0 \\ 2z - \dfrac{1}{2}c\lambda = 0 \end{cases}$$

これから $\lambda = \dfrac{4}{a}x = \dfrac{4}{b}y = \dfrac{4}{c}z$  $y = \dfrac{b}{a}x$  $z = \dfrac{c}{a}x$

これを条件式に代入して

$$S = \frac{1}{2}ax + \frac{b^2}{2a}x + \frac{c^2}{2a}x \qquad x = \frac{2aS}{a^2+b^2+c^2}$$

同様に $y = \dfrac{2bS}{a^2+b^2+c^2}$  $z = \dfrac{2cS}{a^2+b^2+c^2}$

よって $a,b,c$ までの距離がそれぞれ $\dfrac{2aS}{a^2+b^2+c^2}, \dfrac{2bS}{a^2+b^2+c^2}, \dfrac{2cS}{a^2+b^2+c^2}$
