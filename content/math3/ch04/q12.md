### (1)
$\tan^{-1}x$

$$\int \tan^{-1}x\,dx = x\tan^{-1}x - \int \frac{x}{1+x^2}dx = x\tan^{-1}x - \int \frac{2x}{1+x^2}\cdot\frac{1}{2}dx$$

$$= x\tan^{-1}x - \frac{1}{2}\log(1+x^2) + C$$

（C は積分定数）

### (2)
$x\tan^{-1}x$

$$\int x\tan^{-1}x\,dx = \frac{1}{2}x^2\tan^{-1}x - \frac{1}{2}\int \frac{x^2}{x^2+1}dx = \frac{1}{2}x^2\tan^{-1}x - \frac{1}{2}\int\left(1-\frac{1}{x^2+1}\right)dx$$

$$= \frac{1}{2}x^2\tan^{-1}x - \frac{1}{2}(x-\tan^{-1}x) + C = \frac{1}{2}(x^2\tan^{-1}x - x + \tan^{-1}x) + C$$
（C は積分定数）

### (3)
$\sin^{-1}x$

$$\int \sin^{-1}x\,dx = x\sin^{-1}x - \int \frac{x}{\sqrt{1-x^2}}dx = x\sin^{-1}x - \sqrt{1-x^2} + C$$

（C は積分定数）

### (4)
$x\sin^{-1}x$

$$\int x\sin^{-1}x\,dx = \frac{1}{2}x^2\sin^{-1}x - \frac{1}{2}\int \frac{x^2}{\sqrt{1-x^2}}dx \qquad x=\sin t \text{ とおくと} \qquad dx=\cos t\,dt \text{ これから}$$

$$= \frac{1}{2}x^2\sin^{-1}x - \frac{1}{2}\int \frac{\sin^2 t}{\cos t}\cdot\cos t\,dt = \frac{1}{2}x^2\sin^{-1}x - \frac{1}{2}\int \sin^2 t\,dt = \frac{1}{2}x^2\sin^{-1}x - \frac{1}{2}\int \frac{1-\cos 2t}{2}dt$$

$$= \frac{1}{2}x^2\sin^{-1}x - \frac{1}{2}\left\{\frac{1}{2}t - \frac{1}{4}\sin 2t\right\} + C \qquad \text{元に戻して}$$

$$= \frac{1}{2}x^2\sin^{-1}x - \frac{1}{2}\left\{\frac{1}{2}\sin^{-1}x - \frac{1}{4}\sin(2\sin^{-1}x)\right\} + C = \frac{1}{4}(2x^2-1)\sin^{-1}x + \frac{1}{8}\sin(\sin^{-1}x+\sin^{-1}x) + C$$

$$= \frac{1}{4}(2x^2-1)\sin^{-1}x + \frac{1}{4}\sin(\sin^{-1}x)\cdot\cos(\sin^{-1}x) + C = \frac{1}{4}\left\{(2x^2-1)\sin^{-1}x + x\sqrt{1-x^2}\right\} + C$$

（C は積分定数）
