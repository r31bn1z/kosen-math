### (1)

$$\int \frac{dx}{x^2-16} = \frac{1}{8}\log\left|\frac{x-4}{x+4}\right| + C$$

（$C$ は積分定数）

### (2)

$$\int \frac{dx}{9x^2-1} = \int \frac{1}{9}\cdot\frac{dx}{x^2-\frac{1}{9}} = \frac{1}{9}\cdot\frac{1}{2\cdot\frac{1}{3}}\log\left|\frac{x-\frac{1}{3}}{x+\frac{1}{3}}\right| + C = \frac{1}{6}\log\left|\frac{3x-1}{3x+1}\right| + C$$

（$C$ は積分定数）

### (3)

$$\int \frac{dx}{x^2+9} = \frac{1}{3}\tan^{-1}\frac{x}{3} + C$$

（$C$ は積分定数）

### (4)

$$\int \frac{dx}{4x^2+9} = \int \frac{1}{4}\cdot\frac{dx}{x^2+\frac{9}{4}} = \frac{1}{4}\cdot\frac{1}{\frac{3}{2}}\tan^{-1}\frac{x}{\frac{3}{2}} + C = \frac{1}{6}\tan^{-1}\frac{2}{3}x + C$$

（$C$ は積分定数）

### (5)

$$\int \frac{dx}{\sqrt{4-x^2}} = \sin^{-1}\frac{x}{2} + C$$

（$C$ は積分定数）

### (6)

$$\int \frac{dx}{\sqrt{9-25x^2}} = \int \frac{1}{5}\cdot\frac{dx}{\sqrt{\frac{9}{25}-x^2}} = \frac{1}{5}\sin^{-1}\frac{x}{\frac{3}{5}} + C = \frac{1}{5}\sin^{-1}\frac{5}{3}x + C$$

（$C$ は積分定数）

### (7)

$$\int \frac{dx}{\sqrt{x^2+7}} = \log\left|x+\sqrt{x^2+7}\right| + C$$

（$C$ は積分定数）

### (8)

$$\int \frac{dx}{\sqrt{2x^2-1}}$$

$\sqrt{2}x = t$ とおくと $\sqrt{2}dx = dt$ $dx = \frac{1}{\sqrt{2}}dt$ よって与式は

$$\int \frac{1}{\sqrt{2}}\cdot\frac{dt}{\sqrt{t^2-1}} = \frac{1}{\sqrt{2}}\log\left|t+\sqrt{t^2-1}\right| + C$$ 元に戻して

$$= \frac{1}{\sqrt{2}}\log\left|\sqrt{2}x+\sqrt{2x^2-1}\right| + C$$

（$C$ は積分定数）
