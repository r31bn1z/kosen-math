### (1)

$$\frac{1}{(x-a)(x-b)} \quad (a \neq b)$$

$$\int \frac{1}{(x-a)(x-b)} dx = \int \frac{1}{a-b}\left(\frac{1}{x-a} - \frac{1}{x-b}\right) dx = \frac{1}{a-b}\log\left|\frac{x-a}{x-b}\right| + C \qquad \text{(C \text{は積分定数})}$$

### (2)

$$\frac{x}{(x-a)(x-b)} \quad (a \neq b)$$

$$\int \frac{x}{(x-a)(x-b)} dx = \int \frac{1}{a-b}\left(\frac{a}{x-a} - \frac{b}{x-b}\right) dx = \frac{1}{a-b}(a\log|x-a| - b\log|x-b|) + C \qquad \text{(C \text{は積分定数})}$$

### (3)

$$\frac{x^2+6x+11}{(x+2)^3}$$

$$\int \frac{x^2+6x+11}{(x+2)^3} dx = \int \left\{\frac{1}{x+2} + \frac{2x+7}{(x+2)^3}\right\} dx = \int \left\{\frac{1}{x+2} + \frac{7}{(x+2)^3} + \frac{2x}{(x+2)^3}\right\} dx$$

$$= \int \left\{\frac{1}{x+2} + \frac{7}{(x+2)^3} + \left(\frac{2}{(x+2)^2} + \frac{-4}{(x+2)^3}\right)\right\} dx$$

$$= \log|x+2| - \frac{7}{2}\cdot\frac{1}{(x+2)^2} - \frac{2}{x+2} + \frac{2}{(x+2)^2} + C = \log|x+2| - \frac{2}{x+2} - \frac{3}{2(x+2)^2} + C$$

(C は積分定数)

### (4)

$$\frac{5x-1}{x^3-3x-2}$$

$$\int \frac{5x-1}{x^3-3x-2} dx = \int \left\{\frac{1}{x-2} + \frac{-x+1}{(x+1)^2}\right\} dx = \int \left\{\frac{1}{x-2} - \frac{1}{2}\cdot\frac{2x+2}{(x+1)^2} + \frac{2}{(x+1)^2}\right\} dx$$

$$= \log|x-2| - \frac{1}{2}\log(x+1)^2 - \frac{2}{x+1} + C = \log\left|\frac{x-2}{x+1}\right| - \frac{2}{x+1} + C \qquad \text{(C \text{は積分定数})}$$

### (5)
$$\frac{5x+2}{x^2+2x+10}$$

$$\int \frac{5x+2}{x^2+2x+10}dx = \int \left\{\frac{5}{2}\cdot\frac{2x+2}{x^2+2x+10} - \frac{3}{x^2+2x+10}\right\}dx = \int \left\{\frac{5}{2}\cdot\frac{2x+2}{x^2+2x+10} - \frac{3}{(x+1)^2+9}\right\}dx$$

$$= \frac{5}{2}\log(x^2+2x+10) - \tan^{-1}\frac{x+1}{3} + C \qquad (\text{C \text{は積分定数}})$$

### (6)
$$\frac{1}{x^3+1}$$

$$\int \frac{1}{x^3+1}dx = \int \frac{1}{(x+1)(x^2-x+1)}dx = \int \frac{1}{3}\left(\frac{1}{x+1} + \frac{-x+2}{x^2-x+1}\right)dx$$

$$= \int \frac{1}{3}\left(\frac{1}{x+1} - \frac{2x-1}{x^2-x+1}\cdot\frac{1}{2} + \frac{\frac{3}{2}}{x^2-x+1}\right)dx = \int \frac{1}{3}\left(\frac{1}{x+1} - \frac{2x-1}{x^2-x+1}\cdot\frac{1}{2} + \frac{3}{2}\cdot\frac{1}{\left(x-\frac{1}{2}\right)^2+\frac{3}{4}}\right)dx$$

$$= \frac{1}{3}\left\{\log|x+1| - \frac{1}{2}\log|x^2-x+1| + \sqrt{3}\tan^{-1}\frac{x-\frac{1}{2}}{\frac{\sqrt{3}}{2}}\right\} + C$$

$$= \frac{1}{6}\log\frac{(x+1)^2}{x^2-x+1} + \frac{1}{\sqrt{3}}\tan^{-1}\frac{2x-1}{\sqrt{3}} + C \qquad (\text{C \text{は積分定数}})$$
